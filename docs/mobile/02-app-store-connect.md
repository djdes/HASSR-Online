# 02. App Store Connect: приложение и ключ для автоматической сборки

App Store Connect (https://appstoreconnect.apple.com) — это «кабинет» приложения в App Store: карточка,
сборки, тестирование, отправка на проверку. Вход — тем же Apple Account, что и в Apple Developer.

**Что понадобится заранее**

- Готовый аккаунт Apple Developer ([01](01-apple-developer.md)), идентификатор `ru.wesetup.app` зарегистрирован.
- Вы — владелец аккаунта (Account Holder): только он может запросить доступ к API.

**Сколько времени** — около 40 минут. Одобрение доступа к API — от нескольких минут до нескольких дней (Apple
рассматривает запросы по одному).

**Сколько стоит** — бесплатно (входит во взнос 99 $).

## Шаг 1. Создать приложение

1. App Store Connect → **Apps** (Приложения) → кнопка **+** → **New App**.
2. Поля:
   - **Platforms** — **iOS**.
   - **Name** — `WeSetup`. Зачем: так приложение называется в App Store (до 30 знаков).
   - **Primary Language** — **Russian**.
   - **Bundle ID** — выберите из списка `WeSetup - ru.wesetup.app`. Если его нет — вернитесь к шагу 4 в [01](01-apple-developer.md).
   - **SKU** — `wesetup-ios`. Это внутренний код, покупатели его не видят.
   - **User Access** — **Full Access**.
3. **Create**.

## Шаг 2. Apple ID приложения (число)

1. В приложении слева **General** → **App Information**.
2. В блоке **General Information** найдите **Apple ID** — это число из 9–10 цифр.
3. Запишите его: это значение `APPLE_APP_ID` для разработчика ([05-handoff.md](05-handoff.md)).
   Зачем: по нему приложение покажет ссылку «Обновить в App Store».

## Шаг 3. Доступ к App Store Connect API (один раз на аккаунт)

1. **Users and Access** (Пользователи и доступ) → вкладка **Integrations** → слева **App Store Connect API**.
2. Нажмите **Request Access**, отметьте согласие с условиями, **Submit**.
3. Дождитесь одобрения (придёт письмо или кнопка сменится на список ключей).

## Шаг 4. Ключ API для автоматической сборки

Зачем: с этим ключом облачная сборка сама подписывает приложение и загружает его в TestFlight — без вашего Mac
и без паролей.

1. **Users and Access** → **Integrations** → **App Store Connect API** → вкладка **Team Keys**.
2. **Generate API Key** (или **+**, если ключи уже есть).
3. Поля:
   - **Name** — `GitHub сборка`.
   - **Access** — **Admin**. Зачем: сборке нужно создавать сертификат подписи и профиль; у роли Admin доступ
     к сертификатам есть по умолчанию. С ролью «Developer» облачная подпись не сработает.
4. **Generate**. Изменить роль ключа потом нельзя — только отозвать и создать новый.
5. Над таблицей ключей скопируйте **Issuer ID** (длинная строка вида `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`).
6. В строке ключа скопируйте **Key ID** (10 символов).
7. Нажмите **Download API Key**. Скачается `AuthKey_XXXXXXXXXX.p8`. **Скачать можно только один раз.**
   Сохраните копию в надёжном месте.
8. Issuer ID, Key ID и файл `.p8` передайте разработчику ([05-handoff.md](05-handoff.md)).

Это другой ключ, не тот, что для push (APNs) из [01](01-apple-developer.md). Путать их нельзя.

## Шаг 5. Информация о приложении

**General** → **App Information**:

| Поле | Что вписать | Зачем |
|---|---|---|
| **Subtitle** | `Журналы СанПиН и ХАССП` | Подзаголовок под названием, до 30 знаков |
| **Category → Primary** | **Business** (Бизнес) | Основная категория |
| **Category → Secondary** | **Productivity** (Производительность) | Вторая категория, по желанию |
| **Content Rights** | Ответить по фактическим материалам и правам | Пользователи могут загружать сторонние документы; подтвердите права |
| **Age Rating** | Анкета — см. [07](07-privacy-forms.md) | Рейтинг рассчитывает Apple |

Нажмите **Save** справа сверху.

## Шаг 6. Цена и страны

**Monetization** → **Pricing and Availability**:

1. **Price** — **Free** (0).
2. **App Availability** — выберите страны, где работают клиенты (как минимум **Russia**).
   Если выбрать страны Евросоюза, App Store Connect попросит статус продавца по закону ЕС о цифровых услугах и
   опубликует адрес и телефон компании. Нашим клиентам это не нужно — страны ЕС можно не выбирать.
3. **Save**.

## Шаг 7. Конфиденциальность

В левом меню приложения — **App Privacy** (Конфиденциальность приложения):

1. **Privacy Policy URL** — `https://wesetup.ru/privacy`.
2. Анкета о собираемых данных — готовые ответы в [07-privacy-forms.md](07-privacy-forms.md).

## Частые ошибки

- Кнопки **Request Access** нет — вы вошли не владельцем аккаунта. Запрос делает только Account Holder.
- Ключ API создан с ролью **Developer** или **App Manager** без доступа к сертификатам — сборка падает на подписи.
  Создайте новый ключ с ролью **Admin**, старый отзовите.
- Файл `.p8` не скачан сразу — второй раз не дадут. Отзовите ключ (**Revoke**) и создайте новый.
- В списке **Bundle ID** нет `ru.wesetup.app` — идентификатор не зарегистрирован ([01](01-apple-developer.md), шаг 4).
- Путают **Apple ID приложения** (число в App Information) с вашим Apple Account (почта).
