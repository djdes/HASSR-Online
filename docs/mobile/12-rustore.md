# 12. Публикация в RuStore (`WeSetup` и «Сетап помощник»)

Полное пошаговое руководство по публикации обоих наших Android-приложений в российский магазин **RuStore** (`https://console.rustore.ru`):
1. **«Сетап помощник: этикетки» (`ru.wesetup.helper`, версия `1.6.0`, код `9`)** — автономное приложение печати кухонных этикеток по Bluetooth (TSPL).
2. **«WeSetup: журналы ХАССП» (`ru.wesetup.app`, версия `1.1.0`, код `3`)** — основное приложение ХАССП-журналов, температур, чек-листов и QR-маркировки.

---

## 1. Регистрация аккаунта разработчика в RuStore

1. Откройте [console.rustore.ru](https://console.rustore.ru) и войдите через **VK ID** (рекомендуется корпоративный VK ID или VK ID руководителя).
2. Выберите тип аккаунта:
   - **Юридическое лицо / ИП (рекомендуется для ООО «БФС»):** в карточке приложения в магазине будет официально отображаться разработчик `ООО «БФС»`.
     - Понадобится подтверждённый аккаунт организации на **Госуслугах** и **УКЭП** (усиленная квалифицированная электронная подпись руководителя на USB-токене Рутокен/JaCarta с плагином Госуслуг / КриптоПро в браузере).
     - Проверка занимает от нескольких минут до 1 рабочего дня.
   - **Физическое лицо (быстрый старт, если нужно выложить без УКЭП):** верификация проходит за 15–30 минут по паспорту РФ / Госуслугам. Бесплатные приложения без встроенных покупок можно публиковать и с аккаунта физлица, но в графе «Разработчик» в RuStore будет указано ФИО владельца аккаунта.
3. **Стоимость:** регистрация в RuStore и публикация бесплатных приложений — **бесплатно (0 ₽)**. Подключать монетизацию не нужно, так как оба приложения бесплатные и не содержат встроенных платежей внутри APK.

---

## 2. Важное отличие RuStore: загружаем `.APK`, а не `.AAB`

RuStore принимает и `.apk`, и `.aab`, но **для обоих наших приложений в RuStore нужно загружать именно подписанный `.apk`**:

- **При загрузке `.APK`:** RuStore проверяет вашу цифровую подпись и раздаёт пользователям файл с вашей оригинальной подписью разработчика. Никакие закрытые ключи в консоль RuStore загружать не нужно.
  - Для `WeSetup` (`ru.wesetup.app`) это гарантирует, что отпечаток сертификата (`F6:B0:8A:6D:42:D2:1D:F8:55:26:A2:19:91:24:1E:98:C9:B6:64:03:29:9F:E3:98:98:29:B6:E5:1C:4C:F2:89`), зашитый в `https://wesetup.ru/.well-known/assetlinks.json`, сразу совпадёт, и QR-коды журналов/входа будут открываться прямо в приложении без браузера.
  - Кроме того, телефон спокойно обновит приложение поверх APK, скачанного напрямую с сайта `wesetup.ru`, так как ключ подписи один и тот же.
- **При загрузке `.AAB`:** RuStore заставляет вручную упаковать приватный ключ из `.jks` через утилиту `PEPK` в `.zip` вместе с `certificate.pem` и отдать приватный ключ на серверы RuStore. В этом нет никакой необходимости, когда есть готовый универсальный подписанный `.apk`.

|---|---|---|

## 4. Приложение №1: «Сетап помощник: этикетки» (`ru.wesetup.helper`)

Это приложение проще всего отправить первым — **оно работает полностью офлайн без логина и пароля**, поэтому модератор проверяет его за один проход без тестового аккаунта.

### Шаг 4.1. Создание приложения в Консоли
1. В [console.rustore.ru](https://console.rustore.ru) нажмите **«Добавить приложение»**.
2. Тип: **Бесплатное приложение**.
3. Загрузите файл **`app-play-release.apk`** (из CI-артефакта `setup-helper-play-apk-N` или из готовой папки `01-setup-helper-print/setup-helper-1.6.0-rustore.apk`).
   > **Важно:** загружайте именно сборку `play` (`app-play-release.apk`), а **не** `site` (`app-site-release.apk`). В сборке `play` вырезан механизм самообновления (`REQUEST_INSTALL_PACKAGES`) и разрешение `INTERNET`, поэтому модерация RuStore проходит без вопросов.

### Шаг 4.2. Заполнение карточки
Все тексты для копирования в один клик лежат в [`mobile/setup-helper/store/rustore/listing-ru.md`](../../mobile/setup-helper/store/rustore/listing-ru.md):
- **Название:** `Сетап помощник: этикетки`
- **Краткое описание:** `Этикетки для кухни на Bluetooth-принтер: шаблоны, сроки годности, история печати`
- **Категория:** `Бизнес` (дополнительная: `Инструменты`)
- **Возрастной рейтинг:** `0+`
- **Политика конфиденциальности:** `https://wesetup.ru/setup-helper/privacy`
- **Email:** `admin@wesetup.ru`, **Сайт:** `https://wesetup.ru`
- **Иконка:** `mobile/setup-helper/store/google-play/graphics/icon-512.png`
- **Скриншоты телефона (6 шт.):** `mobile/setup-helper/store/google-play/graphics/screenshots/phone/1-start.png` … `6-editor.png`
- **Комментарий для модератора (159 символов из 180):**
  ```text
  Вход не нужен. Все 9 шаблонов, редактор макетов, расчёт срока годности и предпросмотр этикетки 58×40 мм работают сразу без принтера; печать — по Bluetooth TSPL
  ```

## 5. Приложение №2: «WeSetup: журналы ХАССП» (`ru.wesetup.app`)

### Шаг 5.1. Подготовка демо-аккаунта перед отправкой на модерацию
Поскольку `WeSetup` требует входа (а кнопка «Автономный режим» открывает только офлайн-заготовку), модератор RuStore обязательно проверит вход по логину и паролю.
Перед нажатием кнопки «Отправить на модерацию» убедитесь, что на боевом сервере `https://wesetup.ru` активен демо-аккаунт для проверяющих (см. [08-review.md](08-review.md)):
- Вход работает напрямую по номеру телефона и паролю (без SMS и без Telegram).
- Внутри заполнена демо-компания «Кафе «Демо»» с несколькими журналами и записями.

### Шаг 5.2. Создание приложения и загрузка APK
1. В [console.rustore.ru](https://console.rustore.ru) нажмите **«Добавить приложение»** → **Бесплатное приложение**.
2. Загрузите подписанный **`app-release.apk`** (`versionName = 1.1.0`, `versionCode = 3`, подписан ключом `wesetup-upload.jks`).

### Шаг 5.3. Заполнение карточки
Все проверенные тексты лежат в [`docs/mobile/store-listing.md`](store-listing.md) (разделы `RuStore`):
- **Название:** `WeSetup: журналы ХАССП`
- **Краткое описание:** `Журналы ХАССП, температура, чек-листы и маркировка для общепита`
- **Категория:** `Бизнес` (дополнительная: `Инструменты` или `Производительность`)
- **Возрастной рейтинг:** `0+` (или `6+`)
- **Политика конфиденциальности:** `https://wesetup.ru/privacy`
- **Email:** `admin@wesetup.ru`, **Сайт:** `https://wesetup.ru`
- **Иконка:** `docs/mobile/store-graphics/icon-512.png` (24-bit RGB без прозрачности)
- **Скриншоты телефона (6 шт.):** `docs/mobile/screenshots/android/01-dashboard.png` … `06-print-center.png`
- **Комментарий для модератора (до 180 символов):**
  Вставьте в поле «Комментарий для модератора» текст из `store-listing.md`, подставив реальный телефон и пароль демо-аккаунта:


## 6. Как выкладывать следующие обновления в RuStore

1. **Для «Сетап помощник» (`ru.wesetup.helper`):**
   - Поднимите `versionCode` и `versionName` в `mobile/setup-helper/app/build.gradle`.
   - После пуша в `master` скачайте артефакт `setup-helper-play-apk-<N>` (`app-play-release.apk`) из GitHub Actions (`Проверка Сетап помощника`).
   - В Консоли RuStore → приложение «Сетап помощник» → **Версии** → **Загрузить версию** → прикрепите новый `app-play-release.apk` и заполните «Что нового».
2. **Для «WeSetup» (`ru.wesetup.app`):**
   - Поднимите `version` в `mobile/package.json` и `build` в `mobile/site-apk.json`.
   - Скачайте подписанный `app-release.apk` из артефактов GitHub Actions (`APK на сайт` или `Выпуск приложений`).
   - Загрузите его в Консоль RuStore → **Версии** → **Загрузить версию**.
   - Кроме того, можно автоматизировать загрузку через **RuStore Public API** (в Консоли RuStore → Компания → API → выпустить ключ и добавить шаг загрузки в `.github/workflows/mobile-release.yml`).
