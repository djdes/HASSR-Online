# 06. Карточки приложений в магазинах

Карточка — то, что человек видит в App Store и Google Play: название, описание, картинки. Все готовые тексты —
в [store-listing.md](store-listing.md): копируйте оттуда после проверки соответствия фактическому релизу.

**Что понадобится заранее**

- Созданные приложения в App Store Connect ([02](02-app-store-connect.md)) и Play Console ([03](03-google-play-console.md)).
- Скриншоты, значок 512×512 и баннер 1024×500 — их готовит разработчик (размеры ниже).

**Сколько времени** — около 1 часа на оба магазина.

**Сколько стоит** — бесплатно.

## App Store: страница версии 1.0

App Store Connect → **Apps** → WeSetup → слева в блоке **iOS App** → **1.0 Prepare for Submission**.

| Поле | Что вписать | Зачем |
|---|---|---|
| **iPhone screenshots (6.9" Display)** | 3–6 скриншотов от разработчика | Обязательны; для остальных размеров iPhone App Store уменьшит эти |
| **Promotional Text** | из [store-listing.md](store-listing.md) | Можно менять в любой момент без проверки |
| **Description** | полное описание из [store-listing.md](store-listing.md) | |
| **Keywords** | ключевые слова из [store-listing.md](store-listing.md) | Для поиска; без пробелов после запятых |
| **Support URL** | `https://wesetup.ru` | Обязательное поле: там указана почта поддержки |
| **Marketing URL** | `https://wesetup.ru` | По желанию |
| **Version** | `1.0.0` | Должно совпадать со сборкой — проверит разработчик |
| **Copyright** | `2026 ООО «БФС»` | Год и владелец прав |
| **Build** | выбирается после загрузки сборки ([09](09-release.md)) | |
| **App Review Information** | см. [08-review.md](08-review.md) | Вход и заметка для проверяющих |
| **Version Release** | **Manually release this version** | Выпустите сами, когда будете готовы |

iPad-скриншоты не нужны: сборка собирается только под iPhone (`TARGETED_DEVICE_FAMILY = 1`), в App Store Connect
блока «iPad screenshots» для такой сборки просто не будет.

Поле «What's New in This Version» у первой версии не показывается — оно появится с версии 1.1 ([11](11-updates.md)).

Нажмите **Save** справа сверху.

## Google Play: основная страница карточки

Play Console → WeSetup → **Рост пользователей (Grow users)** → **Присутствие в магазине** → **Основная страница
приложения в Google Play** (Main store listing).

| Поле | Что вписать |
|---|---|
| **Название приложения** | из [store-listing.md](store-listing.md) (до 30 знаков) |
| **Краткое описание** | из [store-listing.md](store-listing.md) (до 80 знаков) |
| **Полное описание** | из [store-listing.md](store-listing.md) (до 4000 знаков) |
| **Значок приложения** | PNG 512×512 от разработчика |
| **Графический баннер** (Feature graphic) | 1024×500 от разработчика |
| **Скриншоты телефона** | 4–8 скриншотов от разработчика |
| **Скриншоты планшета** 7" и 10" | по желанию |
| **Видео** | не нужно |

Нажмите **Сохранить**.

## Требования к картинкам (для разработчика)

**App Store**

- Формат PNG или JPEG, без прозрачности (без альфа-канала), от 1 до 10 штук на размер.
- iPhone 6.9": **1320×2868** (также принимаются 1290×2796 и 1260×2736), вертикально.
- iPad-скриншоты не нужны: сборка iOS собирается только под iPhone (`TARGETED_DEVICE_FAMILY = 1`), приложение
  на iPad не ставится.
- Только интерфейс приложения; без рамок устройств с чужими логотипами и без слов «Android», «Google Play».

**Google Play**

- Значок: PNG 32-bit, **512×512**, до 1 МБ.
- Баннер (Feature graphic): JPEG или PNG 24-bit без прозрачности, **1024×500**. Не повторять значок крупно,
  не рисовать значки магазинов.
- Скриншоты телефона: JPEG или PNG 24-bit без прозрачности; сторона от 320 до 3840 px; **длинная сторона не больше
  двух коротких**. Для показа в подборках Google нужно не меньше 4 вертикальных скриншотов 9:16 от 1080 px:
  **1080×1920**. Размер 1080×2400 (соотношение 2,22) Google не примет.
- Надписи на скриншотах — не больше 20% площади.

## Частые ошибки

- Скриншоты с прозрачностью (PNG с альфа-каналом) — App Store Connect их не принимает.
- В описании для App Store упоминаются Android, Google Play или другие платформы — Apple возвращает на доработку (правило 2.3.10).
- Эмодзи, «★», повторы знаков «!!!» и КАПС в названии или кратком описании Google Play — нарушение правил карточки.
- В описании обещаны функции, которых нет в приложении, — отказ по правилу 2.3.1 (Apple) и правилам о вводящих в заблуждение карточках (Google).
- Пустое поле **Support URL** — App Store Connect не даст отправить на проверку.
