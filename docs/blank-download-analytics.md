# Окно скачивания шаблона: цели Метрики и сравнение «до/после»

Окно «Куда прислать шаблон?» на страницах журналов (`/journals-info/*`, `/blanki`) шлёт в Яндекс Метрику
цели через `ymGoal` (`src/lib/signup-source.ts`, код — `src/components/public/blank-download-client.tsx`).

| Цель | Когда | Параметры |
|------|-------|-----------|
| `blank_download_click` | нажали «Скачать PDF / Word» (открылось окно или пошло скачивание по запомненной почте) | `place`, `format` |
| `blank_download_challenge` | сервер попросил «Я не робот» (с 21.11.2026) | `place`, `format`, `remembered: "1"` — в коротком окне запомненной почты |
| `blank_download_done` | файл отдан | `place`, `format`, `phone`, `extras`, `remembered` |
| `blank_quick_register_done` | по галке «Быстрая регистрация» создан кабинет | `place`, `format` |

## Сравнить долю скачиваний до и после отмены капчи

С 20.11.2026 ≈ 21:20 UTC (выкат #280) reCAPTCHA больше не стоит в окне: человек скачивает по
невидимой подписанной отметке, проверка появляется только у подозрительных.

1. Метрика → «Конверсии»: цели `blank_download_click` и `blank_download_done`.
2. Два периода одинаковой длины и с теми же днями недели: например, 06.11–19.11.2026 и 21.11–04.12.2026
   (20.11 не берём — день выката).
3. Доля = `blank_download_done` / `blank_download_click` в каждом периоде. Рост доли — скачивания,
   которые вернула отмена капчи.
4. `blank_download_challenge` / `blank_download_click` — сколько людей всё же видят проверку. Больше
   нескольких процентов — повод разобрать правила «подозрительности» (`blank-challenge-gate.server.ts`).
