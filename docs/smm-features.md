# СММ-планировщик: общий список фич (WeSetup, Magday, OrdersFlow, Yesbeat)

25.11.2026. Список составлен двумя моделями: Fable дал основу A/B, Opus добавил
правила плана (80/20, тихие часы, обрезка первой строки) и свёл с кодом.
Ядро проверок — `src/lib/smm/quality.ts` (без зависимостей, копируется в
TS-проекты как есть; в Yesbeat — порт на PHP с теми же id проверок).
Отличия проектов — только в `BrandProfile` (`src/lib/smm/brand-profile.ts`).

## A. Обязательные (есть у всех СММ-планировщиков)

| id | Фича | Как у нас |
|----|------|-----------|
| A01 | Мультипроектность | у каждого проекта свой планировщик и свой профиль бренда |
| A02 | Подключение каналов Telegram и MAX | бот-админ канала, проверка прав |
| A03 | Редактор: жирный, курсив, ссылки | markdown MAX → HTML Telegram |
| A04 | Предпросмотр поста | превью в окне редактора |
| A05 | Отложенная публикация | дата/время МСК, крон раз в минуту |
| A06 | Календарь контента | вид «неделя» + список, пробелы плана |
| A07 | Слоты расписания | сетка времён, «в ближайший свободный слот» |
| A08 | Кросспостинг | один пост → несколько каналов TG и MAX |
| A09 | Черновики с автосохранением | черновик в БД + автосохранение в браузере |
| A10 | Правка опубликованного | editMessage TG / PUT /messages MAX |
| A11 | Удаление и автоудаление | вручную или по сроку `deleteAt` |
| A12 | Медиа и лимиты площадок | до 10 фото, подпись TG ≤ 1024, текст ≤ 4000 |
| A13 | Медиатека | загруженные и сгенерированные картинки — повторно |
| A14 | Кнопка-ссылка | inline-кнопка под постом |
| A15 | UTM-конструктор | utm_source=канал, utm_medium=social, campaign |
| A16 | Короткие ссылки и клики | свой редирект, счётчик переходов по посту |
| A17 | Шаблоны текстов | заготовки с заглушками [дата]/[выгода] |
| A18 | Рубрики | рубрика поста, цвет и хэштег рубрики |
| A19 | Повторяющиеся посты | правило «каждую неделю в день X» |
| A20 | Массовая загрузка | импорт CSV (дата;текст;кнопка;ссылка) |
| A21 | ИИ-генерация текста | автопост дня через Codex-шлюз ProjectsFlow |
| A22 | ИИ-переписывание | «переписать по замечаниям» через шлюз |
| A23 | Картинка из шаблона бренда | 4 шаблона: фото с плашкой, рамка, карточка, акция |
| A24 | Согласование | статус «на согласовании» → «утверждён» |
| A25 | История изменений | версии текста поста |
| A26 | Статусы и повторы | очередь, 3 попытки, текст ошибки |
| A27 | Уведомления | сбой публикации → администратору |
| A28 | Аналитика постов | клики по коротким ссылкам, балл качества |
| A29 | Лучшее время | часы с наибольшими кликами |
| A30 | Параметры отправки | без звука, закрепить, без превью ссылки, защита от копирования |

## B. Уникальные (контроль качества перед публикацией)

Все детерминированные, кроме помеченных «ИИ».

| id | Проверка |
|----|----------|
| B01 | Итоговый балл 0–100 с разбивкой по группам |
| B02 | Шлюз публикации: балл ниже порога / блокирующая ошибка → только с подтверждением |
| B03 | Профиль бренда как правила (жирный заголовок, коридор длины, окно публикаций) |
| B04 | Стоп-слова бренда (по началу слова) |
| B05 | Словарь замен (написание бренда и терминов) |
| B06 | Эмодзи: количество, три подряд |
| B07 | Длина по рубрике + лимиты сети |
| B08 | Читаемость: длина предложений, стена текста, длинные слова |
| B09 | Канцелярит и штампы |
| B10 | Соответствие тону — ИИ-рецензия |
| B11 | «вы/ты» и их смешение |
| B12 | Чек-лист: фото, кнопка, сайт, хэштеги, заглушки шаблона |
| B13 | Контакты: телефон сверяется с эталоном, чужой блокирует |
| B14 | UTM и ссылки на чужие сайты |
| B15 | Живость ссылок (HTTP-проверка перед публикацией) |
| B16 | Упоминание бренда (нет / перебор) |
| B17 | Капс и «!!!» |
| B18 | Спам-слова с весами |
| B19 | Повторы слов и предложений |
| B20 | Дубль прошлых постов (шинглы) |
| B21 | Частота, интервал, тихие часы |
| B22 | Баланс рубрик (продающих ≤ доли бренда, не 3 подряд) |
| B23 | Призыв к действию |
| B24 | Оффер и выгода (+ ИИ-оценка в рецензии) |
| B25 | Конкретика в цифрах против «выгодно/быстро» |
| B26 | Даты и дедлайны: срок не в прошлом |
| B27 | Социальное доказательство |
| B28 | Первая строка: без приветствия, ≤ 90 знаков, крючок |
| B29 | Картинки: размер, пропорции, вес, сделана по шаблону бренда |
| B30 | Автоисправления: по одному и «починить всё» (+ ИИ-переписывание) |

Индексы в отчёте: `spamIndex` (0–100, ≥ 70 блокирует) и `salesIndex`
(сила продажи 0–100).
