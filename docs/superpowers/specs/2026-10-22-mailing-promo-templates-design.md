# Рассылка «Акция»: пять шаблонов промо-писем

Дата: 2026-10-22. Запрос владельца: «подготовь несколько вариантов шаблонов для рассылки клиентам — очень
привлекательные оферы, современные HTML-письма с эффектами. Акции вроде: 30 дней, скидка 15 % на тариф.
Промокод в ссылке — нажали, перешли куда нужно со скидкой на оплату».

## Как встроено

Новый вид письма `promo` («Акция») в рассылке `/root/mailing` (точка расширения `registerMailingTemplate`, рядом
с «Сообщение» и «КП»). ROOT выбирает вид «Акция», один из пяти дизайнов, задаёт скидку, срок, название тарифа и
текст — видит предпросмотр и шлёт себе тест.

- **Промокод.** По умолчанию — персональный каждому получателю (`createPersonalPromoCodes`, как в «КП»): скидка
  `discountPercent` %, срок = `durationDays` (до 23:59 МСК дня «сегодня + N»), одно использование, привязка к
  организации получателя. Вариант «Выбрать код» — общий действующий код из «Промокодов».
- **Ссылка.** Кнопка ведёт на `/promo/<КОД>` (через учёт кликов `ctx.trackUrl`): руководитель попадает в оплату
  подписки с применённым кодом, сотрудник — в заказ, новый клиент — в регистрацию и затем в оплату со скидкой.
- **Тариф.** Название тарифа — поле письма, по умолчанию «PRO»: так владелец называет платный тариф за 1 990 ₽
  (в `PlatformTariff` он «Подписка»); цена «было» — цена этого тарифа.

## Пять дизайнов

Общее: ширина 600, вёрстка таблицами, стили инлайн + один `<style>` (мобильная ≤ 480 px и тёмная тема),
`<meta name="color-scheme" content="light dark">`, шрифт Manrope (Google Fonts) с системным запасом, картинки —
только абсолютные адреса `https://wesetup.ru/…` с `alt`, кнопка «пуленепробиваемая» (VML для Outlook),
скрытый прехедер, подвал с отпиской (не через учёт кликов) и строкой «Почему вы получили это письмо».
Эффекты — прогрессивные: анимации CSS видны в Apple Mail / iOS; Яндекс, Mail.ru и Gmail показывают статичную
версию (градиенты с запасным цветом фона). Живой эффект, видимый везде, — GIF-таймер.

1. **Северное сияние** (`aurora`) — тёмная премиальная: фон `#0b1024` со свечением индиго/фиолетового
   (radial-gradient + цвет-запас), огромное «−15 %» (мятный `#7cf5c0`, в Apple Mail — градиентный текст),
   заголовок, строка цен «1 990 ₽ → 1 692 ₽/мес», кнопка-градиент с бегущим бликом (анимация), чип промокода,
   три выгоды.
2. **Купон** (`coupon`) — светлая «тактильная»: билет из двух частей (слева индиго «−15 %», справа белое поле
   с промокодом крупно, моноширинно, в пунктирной рамке), перфорация с полукруглыми вырезами, срок «до
   21 ноября», кнопка «Применить промокод», «Как это работает» в три шага.
3. **Обратный отсчёт** (`countdown`) — срочность: шапка с живым GIF-таймером «дни : часы : минуты : секунды»
   до конца кода, полоса оставшихся дней, мини-сравнение цен, кнопка «Успеть со скидкой», пульсирующая точка
   «Акция идёт» (анимация).
4. **Было / стало** (`compare`) — рациональная: две колонки цены, «Экономия N ₽ в месяц», что входит в тариф
   (галочки), кнопка.
5. **Личное письмо** (`letter`) — минималистичная, как письмо от команды: обращение по имени, «персональная
   скидка для {{company}}», маркер-выделение «−15 % на 30 дней» (в Apple Mail — проявление маркера), подпись,
   P.S. со сроком. Лучшая доставляемость.

## GIF-таймер

`GET /api/mailing/countdown.gif?until=<ISO>&theme=dark|light` — публичный, без входа: анимированный GIF 600×150,
60 кадров по секунде (обратный отсчёт от текущего момента), Manrope, палитра до 32 цветов, после конца —
кадр «Акция завершилась». Свой кодировщик GIF89a (LZW) — библиотек в проекте нет. Кэш в памяти по
`(until, theme, секунда)`, `Cache-Control: public, max-age=30`. Gmail кэширует картинки — у него таймер
покажет момент первого открытия; это ожидаемо.

## Критерии приёмки

- **AC1.** В форме рассылки есть вид «Акция», пять дизайнов с карточками-превью, предпросмотр и тест себе.
- **AC2.** Персональный промокод на `durationDays` дней создаётся каждому получателю; кнопка ведёт на
  `/promo/<КОД>` через учёт кликов; без кода в живой отправке письмо не уходит.
- **AC3.** HTML каждого дизайна: < 100 КБ, только абсолютные URL, у картинок `alt`, отписка без учёта кликов,
  прехедер 20–140 знаков, тема ≤ 70 знаков без капса и спам-слов, тёмная тема и мобильная версия, VML-кнопка.
- **AC4.** GIF-таймер отдаётся корректным GIF89a (проверка разбором), неверные параметры — 400.
- **AC5.** Тесты, типы, i18n-проверка, линтер — зелёные; выкладка в прод.
