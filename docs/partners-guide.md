# Партнёрская программа WeSetup — инструкция для партнёра

Для консультантов по ХАССП/СанПиН, интеграторов и поставщиков оборудования.
Партнёр подключает заведения к WeSetup, сопровождает их в своём кабинете и
получает вознаграждение с их платежей.

## 1. Как стать партнёром

1. Откройте `https://wesetup.ru/partners` и нажмите «Стать партнёром». Если у вас
   уже есть аккаунт WeSetup — то же самое в кабинете: **Настройки → Партнёрская
   программа** (`/settings/partner`).
2. Заполните заявку: тип партнёра (консультант / интегратор / поставщик),
   компания, контакты, регионы, сколько заведений ведёте, желаемый адрес
   страницы (`slug`) и согласие с партнёрским соглашением.
3. Заявку рассматривает администрация WeSetup. Решение придёт письмом и в
   Telegram (если бот привязан); статус виден в `/settings/partner`. При отказе
   там же показана причина — данные можно исправить и подать заявку заново.
4. После одобрения в шапке появляется вход в кабинет партнёра `/partner`.
   Первый вход — онбординг из трёх шагов: **логотип и контакты → ссылка для
   клиентов → реквизиты для выплат**. Его можно пройти позже, кабинет открыт сразу.

## 2. Кабинет партнёра `/partner`

| Раздел | Что там |
|---|---|
| **Обзор** | Все клиенты одной таблицей: тариф и срок подписки, заполняемость за 7 дней, просроченные журналы, истекающие медкнижки, последняя активность. Фильтры «внимание / активные / без подписки». Клик по клиенту — карточка. |
| **Карточка клиента** | Сводка по журналам, заметки (видит только ваша команда), уровень доступа, кнопка «Открыть кабинет клиента» — вы входите в его кабинет с пометкой «Вы просматриваете как консультант». |
| **Приглашения** | Ссылка `https://wesetup.ru/p/<slug>`, 6-значный код, готовые тексты для мессенджеров и приглашения по e-mail со статусами (отправлено / зарегистрировался / отказался / истекло). |
| **Брендинг** | Название бренда (≤ 40 символов), логотипы для светлой и тёмной темы (PNG/SVG, ≤ 500 КБ), акцентный цвет (проверяется контраст WCAG AA), контакты для блока «Ваш консультант», подпись в PDF (≤ 120), приветствие на странице входа (≤ 200). Предпросмотр справа. |
| **Вознаграждение** | Начисления по каждому платежу клиента, баланс «начислено / к выплате / выплачено», выгрузка CSV для Excel, реквизиты для выплат. |
| **Команда** | Сотрудники вашей компании с доступом к кабинету партнёра (владелец и участники). |

## 3. Как подключить клиента

- **Новое заведение:** отправьте ссылку `https://wesetup.ru/p/<slug>`. Клиент
  регистрируется на брендированной странице и сразу привязывается к вам.
- **Заведение уже в WeSetup:** клиент открывает **Настройки → Консультант**
  (`/settings/consultant`) и вводит вашу ссылку или 6-значный код.
- **По почте:** раздел «Приглашения» → адрес → «Отправить». Письмо уходит от
  WeSetup с вашим брендом; в нём есть ссылка «Не интересно» — тогда статус
  станет «отказался».

У организации может быть только один партнёр. Свою собственную организацию
подключить как клиента нельзя.

**Уровень доступа** выбирает клиент: *только просмотр* (по умолчанию — вы
видите всё, но ничего не меняете, включая PDF и «Инспектор пришёл») или
*просмотр и редактирование* (как руководитель клиента; ваши правки помечаются
в аудите «партнёр: …»). Деньги, подписка и настройки самой привязки — всегда
только у клиента.

Клиент может в любой момент отключить сопровождение. Тогда ваш доступ
закрывается сразу, брендинг у него снимается, новые начисления по нему не
идут, история и уже начисленное сохраняются, вам приходит уведомление.

## 4. Что видят ваши клиенты (white-label)

Логотип и акцент в кабинете, блок «Ваш консультант» с вашими контактами
(кнопка поддержки ведёт к вам), подпись в подвале каждой страницы PDF-журналов,
ваш бренд в письмах и приветствие бота «Ваш консультант: …». Обязательная
пометка «Работает на платформе WeSetup» остаётся всегда. Изменения брендинга
доходят до клиентов в течение 5 минут. Клиент может переключиться на стандартный
интерфейс — привязка и начисления при этом сохраняются.

## 5. Вознаграждение

Правила версионируются; к платежу применяется версия, действовавшая в момент
оплаты. Действующие значения (версия 2, с 1 ноября 2026 года; до неё — 20 %):

- **30 %** с каждого платежа за подписку клиента в течение **12 месяцев** с его
  первого платежа;
- **15 %** с оборудования в комплекте — после отметки «Отгружено»;
- **бонус 3 000 ₽** за клиента после его **второго** платежа;
- возврат средств клиенту → сторно соответствующего начисления.

Жизненный цикл: **начислено → к выплате** (1-го числа за прошедший месяц) **→
выплачено** (после перевода, вручную отмечает администрация). Минимальная
выплата **1 000 ₽**; меньшие суммы переносятся на следующий месяц. Укажите
реквизиты (ИП / самозанятый / юрлицо) в разделе «Вознаграждение» — без них и
без подписанного договора выплата не производится.
