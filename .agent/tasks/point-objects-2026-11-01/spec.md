# Объекты точки: цеха, помещения, оборудование, планшеты (аудит точек, 2026-11-01)

Источник: детальный аудит изоляции торговых точек (группа «objects»).
Руководитель точки (`pointScope`, фаза 2 «Офис и точки») через API мог менять
чужие точки, а окна справочников показывали цеха, помещения и людей всей
организации.

Правило: руководитель точки правит только объекты своих точек; объект без
точки (общий) — офис, как правка самой точки в `api/settings/buildings/[id]`.
Руководство на всю компанию и организации без точек работают как раньше.

## Критерии приёмки

- **AC1** Оборудование: POST, PUT, DELETE `/api/equipment` → 403 руководителю
  точки для цеха/помещения чужой точки или общего; перенос в цех/помещение
  чужой точки — 403, цех-зеркало чужого помещения не создаётся.
- **AC2** Цеха: POST/PUT/DELETE `/api/areas` — то же; новый цех руководителя
  точки с одной точкой без выбора встаёт на его точку; «без точки» — 403.
- **AC3** Помещения: POST `/api/settings/rooms`, PATCH/DELETE
  `/api/settings/rooms/[id]` — 403 для чужой точки.
- **AC4** `PUT /api/settings/buildings/[id]/staff`: чужая точка — 403; люди
  не его точек — 403; снятие последней своей точки не отпускает человека
  «на все точки компании». `copy-rooms`: цель и источник — только свои точки.
- **AC5** `GET /api/equipment` без `documentId` и `GET /api/areas` — объекты
  точек человека (точка из шапки — только она) и общие.
- **AC6** Окна на страницах «Оборудование», «Цеха», «Точка»: цеха, помещения,
  точки и люди — только точек человека; руководителю точки нет «Без точки» в
  окне цеха и нет кнопок правки у общих цехов/оборудования; датчики и
  подсказка дублей имён — только своих точек.
- **AC7** `GET /api/charts/temperature` — оборудование чужой точки → 404.
- **AC8** «Добавить помещение»: цеха точки, куда встанет помещение, и общие;
  сравнение — с помещениями только этой точки.
- **AC9** Планшет: enroll без точки — точка из шапки / единственная точка
  руководителя точки, чужая или «без точки» руководителю точки — 403;
  pins-bulk — только люди его точек; страница — планшеты и люди его точек;
  PATCH: отвязать — только планшет своей точки, общие настройки — 403;
  `kiosk/unlock` и passkey на планшете точки — только её сотрудники.
- **AC10** «Сетап помощник»: руководитель точки видит и отключает телефоны
  только людей своих точек.
- **AC11** Типы без ошибок, тесты затронутых модулей зелёные.

## Не входит

- Схема БД не меняется. Принтеры (`PrintAgent` без точки), `InspectorToken`
  без точки — отдельные решения.
- `/api/settings/kiosk` целиком в «общих» — решает группа people (proxy).
