На `/zhurnal-uborki` после описания показывались только обязательные поля, без самого журнала. Теперь под описанием отображается существующий образец с таблицей уборок и пометкой о демонстрационных данных. Общий шаблон также показывает готовые образцы остальных поддерживаемых журналов.

Таблица уборок прокручивается по горизонтали на небольшом экране, в том числе в существующей карточке журнала. Сохранены регистрация, email-процесс скачивания PDF, пользовательские ссылки на скачивание и переход к печатным формам для страниц без образца.

Проверено: 320/375/768/1440 px, 26 сценариев для 13 посадочных страниц, загрузка PNG/WebP, прокрутка таблицы и страницы, параметры скачивания; ESLint, `npm run typecheck`, `npm run test:gate`. Повторная проверка и её границы описаны в `.agent/tasks/seo-journal-preview-2026-11-13/evidence.md`. Браузерная проверка использует реальные компоненты и стили с заглушками общих шапки/подвала, Next Link и границы диалога скачивания; полный сервер и доставку email она не запускает. Репозиторный gate не нашёл связанных unit-тестов для изменённых компонентов.

Деплой меняет только отображение публичных страниц. Изменений схемы БД нет.
