# Spec (frozen 2026-11-07): ИИ-отчёт на /reports, чек-лист «Готовы к проверке», отзывы с цифрами, план публикации роликов

Запрос владельца: «сделай 1, 2, 3, 4 и сразу в прод» — четыре предложения после этапа 3 (PR #117/#118):
1) починить карточку ИИ-отчёта на /reports; 2) чек-лист «Готовы ли вы к проверке» на странице СанПиН с
записью на показ; 3) блок отзывов с цифрами на главной и /pricing (нужны 3–5 клиентов, согласных на отзыв);
4) план публикации роликов — по одному в 2–3 дня в VK и Telegram.

## Исходное состояние (master ce5615cc)

- /reports: на локальном стенде (next dev) при первой компиляции страницы в журнале сервера было
  «Failed to call `useTranslations` because the context from `NextIntlClientProvider` was not found» в
  `AiPeriodReportCard`; повторные открытия /reports — без ошибки. Страница обёрнута
  `DomainMessagesBoundary ["reports","reportsUi"]` (`reports/layout.tsx`).
- /sanpin-2-3-2-4-4282-26: факты, 18 журналов каталога с основанием 4282-26, «Если пришла проверка», FAQ,
  кнопка показа. Интерактивной самопроверки нет. `DemoRequestButton` не умеет заранее заполнить «Что
  показать».
- Отзывы уже есть: `CustomerReview` (текст/фото/видео, анонимно, согласие на публикацию), форма в «Баланс и
  бонусы» (/settings/balance) и после оценки 4–5 в опросе NPS, модерация ROOT /root/reviews, баллы на баланс после
  одобрения (300 / 750 / 1 990 ₽). Блок «Что говорят заведения» на главной показывает одобренные отзывы и
  скрыт, когда их нет — на проде сейчас скрыт (одобренных публичных отзывов нет). На /pricing блока нет.
  Попросить конкретного клиента об отзыве из ROOT нельзя; цифр в карточке отзыва нет.
- Ролики (этап 3): 5 вертикальных MP4 + обложки + тексты, отданы владельцу. В ROOT есть «Каналы Telegram и
  MAX» (посты по расписанию: текст, картинки, кнопка, UTM) — видео не поддерживает. Воронка распознаёт
  источники по utm (`signupChannel`: vk, telegram, max…).

## Критерии приёмки

- **AC1. ИИ-отчёт на /reports.** Установить причину ошибки. Если она воспроизводится в production-сборке
  (`next build` + `next start`) — исправить по причине и закрыть тестом; если только при первой компиляции в
  `next dev` — показать это (журнал dev: ошибка один раз на холодной компиляции; production: /reports у
  управляющего без ошибки, карточка ИИ-отчёта в HTML сервера) и код не трогать.
- **AC2. Чек-лист «Готовы ли вы к проверке»** на /sanpin-2-3-2-4-4282-26: 7 вопросов «да/нет» — 6 по
  журналам каталога с основанием СанПиН 2.3/2.4.4282-26 (гигиенический, холодильное оборудование, входной
  контроль, бракераж готовой продукции, уборка, дезсредства) и «показать журналы за любой период за
  минуты». Итог «N из 7» и список пробелов: что фиксировать и ссылка на описание журнала. Кнопки: запись на
  показ (место `sanpin-checklist`, «Что показать» заполнено пробелами) и «Начать бесплатно». Цель Метрики
  `sanpin_checklist` с баллом. Только факты из репозитория (без штрафов и «обязательно»). Тесты: вопросы ↔
  каталог, подсчёт, текст для показа, страница.
- **AC3. Отзывы с цифрами.**
  - a) ROOT /root/reviews — «Кого попросить об отзыве»: до 20 организаций (не демо, не платформа, старше 21
    дня, от 30 записей за 30 дней, без отзыва на проверке или одобренного, не просили 30 дней), сначала с
    оценкой 4–5 в опросе, затем по активности. «Попросить отзыв» — письмо руководителям (кроме стоп-листа):
    ссылка на /settings/balance#review, суммы из `REVIEW_REWARD_RUB`, можно без имени; отметка
    `review.requested` в журнале действий; повтор раньше 30 дней — 409.
  - b) Формы отзыва («Баланс и бонусы», /settings/balance, и опрос): галочка «Показать рядом с отзывом, сколько журналов и
    записей мы ведём в WeSetup» (по умолчанию выключена) → `CustomerReview.showStats` (новая колонка,
    по умолчанию false). Модерация ROOT видит отметку.
  - c) Карточка отзыва показывает цифры только при `showStats`: журналов с записями за 30 дней, записей
    всего (округлённо), «в WeSetup с <месяц год>»; блок отзывов — и на /pricing; нет одобренных — блока нет.
    Тексты ru/en/uz. Тесты: выбор кандидатов, письмо, цифры и округление, согласие.
- **AC4. План публикации роликов.** `docs/clips-publication-plan.md`: 5 роликов, по одному в 2–3 дня
  (пн/ср/пт с 9 ноября 2026), VK Клипы и Telegram-канал (MAX — по желанию), время, тексты под площадку со
  ссылкой с UTM (`utm_source` vk/telegram, `utm_medium=clip`, `utm_campaign=autofill-<сцена>`), как поставить
  отложенную публикацию штатно, что смотреть в «Воронке» и сводке. Тексты и ссылки — из кода
  (`autofillClipCaption` по площадке), `npm run video:render:clips` пишет их рядом с роликами; календарь
  напоминаний .ics. Тест: метки распознаются воронкой как VK/Telegram.
- **AC5. Ворота.** `npm run typecheck`, `npm run test:gate`, `npm run i18n:check`, eslint изменённых —
  зелёные; PR влит в master (squash), выкладка прошла, `/api/build-info` — коммит; прод проверен (страницы,
  отказы API без входа и без данных).

## Вне объёма

Видео в планировщике каналов ROOT (у Telegram и VK своя отложенная публикация). Публикация роликов и
рассылка просьб об отзыве от имени владельца — делает владелец. Придуманные отзывы и цифры — никогда.
