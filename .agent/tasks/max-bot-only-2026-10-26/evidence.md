## AC1 — мини-сайта нет — PASS

- Удалены `src/app/max/page.tsx`, `entry-client.tsx`, `journals/page.tsx`, `open/[code]/route.ts`,
  `src/app/api/max/session/route.ts`, `src/lib/max/browser.ts` (+ тест), `verifyMaxInitData`,
  `createMaxHandoff`/`consumeMaxHandoff`, CSP-фрейм `/max` в `next.config.ts`.
- `grep` по `src`, `scripts`, `next.config.ts`, документации: нет `max#ticket`, `/max/open`,
  `/max/journals`, `api/max/session`, `max-web-app` (кроме теста аналитики, который проверяет
  исключение путей `/max*`).
- Бот не создаёт ссылок входа: единственная ссылка-кнопка — «Подключить на сайте» для
  неподключённого человека (тест `no mini-site: only the unlinked screen carries a site link`,
  шаг 1 прогона). `setup-max.ts` больше не печатает URL мини-приложения, команды:
  `/menu`, `/tasks`, `/journals`, `/help`. `docs/max-integration.md` переписан.
- Таблица `MaxSessionHandoff` оставлена (аддитивный `db push`), код её не создаёт.

## AC2 — меню — PASS

- `menuView`: «Сегодня заполнено N из M», «Осталось: …», первая кнопка — следующий
  незаполненный журнал (не объектный), «Мои задачи», «Все журналы», «Как это работает»,
  «Организация» при нескольких. Руководителю — «Сводка», «Напомнить», «Подключить сотрудника».
  Тесты `employee menu…`, `manager menu…`, `all done and no tasks…`; прогон шаги 2–3.
- «Мои задачи» — обязательства дня (`JournalObligation`), незаполненные сверху, объектные с
  «по наклейке» (тест `today list…`). «Все журналы» — по 8 с листанием (тест `journals list…`),
  только с правом записи и документом на сегодня (`loadFillableJournals`).

## AC3 — заполнение кнопками — PASS

  `optional text…`, `defaults…`.
- «Назад», «Отменить», «Изменить» → поле → снова проверка (тесты `back…`, `edit…`; прогон шаг 4).
- «Выключено / нет показания», норма, быстрые значения, «Что вы сделали?» с готовыми ответами,
  комментарий уходит только при показании вне нормы (тесты `object reading…`, `out-of-norm…`).
- Выбор документа/строки кнопками (тест `document and row choices…`), «Добавить ещё» для
  строчных журналов (прогон шаг 5–6), «Продолжить» незаконченное из меню (прогон шаг 10).
- Устаревшие кнопки: id мастера + `seq` в каждой кнопке; «Сохранить» из старого сообщения
  не записал (прогон шаг 4, `writes() === 0` до свежего нажатия).

## AC4 — запись через ядро — PASS

- `submitJournalFill(..., messenger: { channel: "max", userKey })`: актор — привязанный
  сотрудник без PIN/сессии, лимит `max:<user>:journal:<doc>`, аудит `channel: "max"`,
  уведомление «Выключено» с пометкой «в MAX».
- Прогон: гигиена записана (`journalDocumentEntry` за сегодня: подтверждения `true`,
  `status: healthy`), бракераж — строка «Борщ» в документе, `auditLog.details.channel === "max"`.
- Ошибка ядра возвращает к полю с `badKeys` (или к проверке) с текстом ошибки; сбой записи
  восстанавливает состояние (`saveFill`).

## AC5 — руководитель — PASS

- Сводка: «Заполнено X из Y (Z%)», кто что не заполнил, «(нет в MAX)», руководитель виден, но
  не адресат (тесты `summary…`; прогон шаг 7).
- Напоминание: подтверждение → личное сообщение сотруднику с кнопкой «Заполнить»; повтор раньше
  30 минут — «Следующее — через N мин» (прогон шаг 7; условное обновление `lastReminderAt`).
- Подключение: список без MAX → ссылка-приглашение отдельным сообщением для пересылки → сотрудник
  открывает бота по ссылке → привязан, руководитель уведомлён; повторное использование ссылки
  отклонено (прогон шаги 2–3).

## AC6 — безопасность — PASS

- Приглашение: 24 байта, SHA-256 в базе, одноразовое (атомарный `usedAt`), 7 дней, новая
  отменяет прежнюю, только активный неархивный сотрудник этой организации, занятый MAX или
  другой MAX у сотрудника — отказ (`invite.ts`; прогон: чужой человек по той же ссылке — отказ).
- Каждое действие: `maxContext` (привязка, активность, членство, MAX включён — прогон шаг 11),
  `canWriteJournal`, `journals.fill`, отключённые и объектные журналы (`journalFillCodeBlock`).
  Разделы руководителя сотруднику недоступны (прогон шаг 8). Заполнение — только в своей
  организации (`fillAccess`).
- Двойное «Сохранить» не дублирует запись (CAS `botStateAt`; прогон: `writes()` остаётся 1).
- Остановка бота удаляет привязку (прогон шаг 12). Группы получают только текст.
