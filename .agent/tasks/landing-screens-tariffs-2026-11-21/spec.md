## Критерии приёмки

### Снимки «Кабинета руководителя»
- **AC1.** Все 7 экранов слайдера (Сводка, Мониторинг, Журналы, Журнал, QR-наклейки, Пришла
  проверка, Сотрудники) пересняты с текущего интерфейса кабинета на локальной демо-базе
  (не с прода): ПК 2400×1500, телефон 780×1600, webp, каждый 8–450 КБ.
- **AC2.** Снимки лежат в новой папке с датой (`SHOWCASE_SCREENS_DIR`), чтобы недельный кэш
  `/landing/*` и `next/image` не показывал старые; главная и «О нас» берут их оттуда,
  старые файлы удалены.
- **AC3.** «Сотрудники» — настоящий экран кабинета вымышленной организации («ООО «Пример»»)
  с нейтральными должностями; в кадре нет служебных кнопок (чат, «Сообщить о проблеме»,
  оверлей Next). Порядок съёмки записан в `screens.md`.

### Тарифы
- **AC4.** Заголовок — «Четыре тарифа» (без «Начните с бесплатного»).
- **AC5.** Подсказка про объекты короче, но со всей шкалой скидок (от 5 до 50).
- **AC6.** Подписи тарифов, пункты карточек, примечание о смене тарифа, блок ППК, блок
  оборудования и гарантия возврата — короче и проще; факты (лимиты, цены, сроки) те же.

### Ниже тарифов
- **AC7.** Отзывы — «Отзывы клиентов»; ответы FAQ — по одной-две короткие фразы без потери
  фактов (сроки возврата, PIN, напоминания 12:00/17:00/21:00, блокировка 15 минут, данные в
  России, бэкапы 6 ч); строка про базу знаний короче.
- **AC8.** Финальный блок: заголовок «Начните бесплатно», короче описание и три шага.

### Общее
- **AC9.** Тексты — в `ru`, `en`, `uz`; `npm run i18n:types`, `npm run typecheck`,
  `npm run test:gate` зелёные; главная проверена снимками (телефон и ПК).
- **AC10.** Изменения в `master`, деплой прошёл.

- Тексты таблицы сравнения тарифов (строки и клетки).
