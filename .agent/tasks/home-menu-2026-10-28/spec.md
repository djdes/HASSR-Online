Дата: 2026-10-28. Источник: эскизы руководителя «Отсканированный документ 95.pdf»
(5 листов) и фото 6-го листа («К Вам пришла проверка»). Постановка владельца:
«после регистрации и авторизации основного аккаунта мы должны попадать на 1 страницу
из макета с 4 кнопками меню слева. В „Моя компания“ переносятся торговые точки и т. д.,
как на странице 2, и так по списку». Пояснение по «Торговым точкам»: корень — список
всех точек + создать; «Сотрудники» — все точки с сотрудниками (как сейчас) + новый
сотрудник; «Журналы» — все точки с журналами + добавить/убрать журнал; помещения,
оборудование, QR — так же.

  Консалтинг; «Ещё»: что делать сейчас, журнал посещений, готовность, спецрежим.

## Решения исполнителя

1. Модель — дерево: у раздела `parent`, пункт меню может вести во вложенный раздел
   (`section`). Главное меню — разделы без видимого родителя: если родитель человеку
   закрыт (заведующая, руководитель точки, повар), раздел поднимается в главное меню —
   права не меняются.
2. «‹ Назад» поднимает на уровень вверх (в меню родителя, из корня — в главное) без
   перехода; пункт-родитель подсвечен, пока человек внутри вложенного раздела. То же
   на телефоне и в Mini App (П-3).
3. «Мои точки» пунктами меню убраны: список точек — на странице, как на эскизе.
4. Домашняя `/home` — у кого `admin.full`; остальных уводит на прежнюю домашнюю.
   Вход без адреса возврата и регистрация ведут на `/home`; логотип в меню — тоже.
5. Мониторинг: журналы — доля заполненных сегодня журналов набора точки (тот же счёт,
   что «N/M» на «Сегодня»), «Все точки» — сумма по точкам; чек-листы — доля выполненных
   назначений текущего периода; ППК — готовность блоков (на всю организацию).
6. Контакты главной: телефон 8 (925) 305-80-77; Telegram-ссылки — из переменных
   `WESETUP_TG_SUPPORT_URL`, `WESETUP_TG_SALES_URL`, `WESETUP_TG_CONSULTING_URL`
   (не задана — строки нет).
7. «Избранное» — три слота; человек закрепляет страницы своего меню
   (`User.homeFavorites`, до 3, API принимает только пункты его меню).
8. Мастер-кабинет «доступно в PRO» — метка PRO в меню, доступ тарифом не ограничен
   (ограничение — решение владельца).

## Критерии приёмки

- AC1. Главное меню `owner` — ровно 4 раздела + «Пришла проверка»; у всех стрелка ›.
- AC2. Вложенность: Моя компания → Офис / Торговые точки → Сотрудники / Журналы / ППК;
  Мониторинг → Чек-листы. «‹ Назад» ведёт в меню родителя (сайдбар, телефон, Mini App).
- AC3. Закрытый родитель поднимает раздел в главное меню (заведующая, повар,
  руководитель точки) — видимые страницы не меняются.
- AC4. Каждая страница кабинета принадлежит разделу; правило пункта = guard страницы
  (`app-nav.test.ts` зелёный, тест обходит все `page.tsx`).
- AC5. Шапка меню: логотип до 80 px, под ним краткое юр. наименование.
- AC6. `/home`: знак «сетап», «Ваш электронный ХАССП», контакты, «Начальная настройка»,
  три слота «Избранного» (закрепить/открепить, сохраняется). 390 px без прокрутки вбок.
- AC7. Вход и регистрация руководителя → `/home`; сотрудник → как раньше.
- AC8. `/monitoring`: три кольца с процентом и «N из M», переключатель точек (2+ точки),
  карточки ведут к подробностям.
- AC9. `/journals/points`: все точки с журналами в работе; добавить/убрать журнал на
  одной точке не меняет другие точки.
- AC10. «Пришла проверка»: четыре пункта эскиза сверху; «Нормативные документы» —
  страница раздела, левое меню не переключается.
- AC11. ru/en/uz для новых строк; `npm run i18n:check`, `npm run typecheck`, тесты
  навигации и новые тесты зелёные.
- AC12. «Что нового» и раздел «Меню кабинета» в CLAUDE.md обновлены; выложено на прод.
