Журналы по алфавиту и поиск на странице QR-кодов

Дата: 27 сентября 2026. Просьба начальника: «Давай везде сделаем по алфавиту, должно быть логично».
Формат: что было, затем что стало теперь.

1. Журналы шли в исторической последовательности ХАССП, и в длинном списке найти нужный было трудно. Теперь везде по алфавиту: список «Журналы» (на сайте и в мини-приложении), главная, переключатель журналов в шапке, поиск по сайту, настройки (набор журналов, ответственные, периодичность, баллы, по должностям, доступ, названия, автосоздание, сложность, режим задач, чек-листы, иерархия, нагрузка, первая настройка), отчёты, фильтр журнала действий, доступ сотрудника к журналам, страница проверяющего, бот в Telegram, список для TasksFlow, публичные /blanki и калькулятор журналов. Группы (обязательные, рекомендуемые, отключённые и т. п.) остались, по алфавиту внутри каждой.
2. Переименованный в «Настройки → Названия» журнал вставал на старое место. Теперь он встаёт по своему новому названию. На странице «Названия» порядок по официальному названию, чтобы строка не прыгала при вводе.
3. Не менялось: экраны задач («Сегодня», «Панель контроля», уведомления) - по времени и срочности; строки внутри журналов; печатные бланки. Отдельный QR «Допуск сотрудников к смене» остался как был.
4. На странице «QR-коды» не было поиска. Теперь есть поиск такой же, как в списке журналов: по названию (и своему, и официальному), описанию, коду, документу, объекту и зданию; «Найдено N из M», крестик и Escape очищают; «Ничего не нашли» с кнопкой «Показать все». «Отметить все» при поиске становится «Отметить найденные» и отмечает только найденное; уже отмеченное для печати не теряется. На телефоне и в тёмной теме проверено.
5. На странице «QR-коды» журналы, объекты (холодильники, склады, лампы) и наклейки на оборудование и помещения теперь по алфавиту; универсальные коды «Все журналы» и «Допуск сотрудников к смене» по-прежнему первыми. На карточке журнала видно своё название журнала.
6. На странице, которая открывается по QR «Все журналы» (сотрудник выбирает журнал), журналы шли в случайном порядке и поиска не было. Теперь по алфавиту (объектные журналы - холодильники, склады, лампы - в конце, тоже по алфавиту) и есть поиск, такой же, как при выборе сотрудника: появляется, когда журналов больше шести, ищет по названию и коду, все слова в любом порядке, «ё» как «е»; «Ничего не нашли», Escape очищает.
7. «Допуск сотрудников к смене» был только отдельным QR-плакатом. Теперь он есть и в списке страницы «Все журналы» (когда гигиенический журнал включён): встаёт по алфавиту среди журналов с подписью «Для ответственного за смену». Открывает тот же экран, что и плакат допуска; PIN сотрудника спрашивается как обычно. Отдельный плакат остался.
