# Журналы точки — только своё, без «Пересоздать документы» (2026-10-30)

Партнёр (видео `video1.mp4`): точка «СОШ №5 Одинцовская», журнал температуры
холодильников 16–31 октября — все шкафы организации (67 единиц), у части стоят
температуры. Переписка: «А можно на документы, сотрудников, оборудование…
навесить атрибут и связать с точкой, чтобы ТТ не своё просто не видела?» —
«так и должно работать, где-то баг». Владелец: «исправь как надо, сам проверь».

## Причина

С 29.10 новые документы точки собираются из справочников точки. Документы
текущего периода, созданные раньше, остались со строками всей организации; для
них была только подсказка «Пересоздать документы».

## Критерии

- AC1. Активный документ точки (холодильники, поверка, обслуживание, климат,
  уборка) теряет строки оборудования / помещений других точек; свои, общие
  (цех без точки), ручные и удалённые строки остаются. Закрытые не трогаем.
- AC2. Гигиена и журнал здоровья активного документа точки показывают строки
  сотрудников этой точки, «Все точки», уволенных/неизвестных и тех, у кого в
  документе есть отметка человека (QR, подтверждение, правка). Записи в БД не
  удаляются.
- AC3. Исправление само: при открытии документа, при печати PDF, при любом
  заходе в кабинет (раз в 10 минут на организацию, без ожидания) и часовым
  кроном по всем организациям с точками.
- AC4. Юнит-тесты чистых функций; typecheck; проверка в браузере на e2e-БД:
  шкаф и сотрудник точки Б не видны в документах точки А.
- AC5. «Что нового».
