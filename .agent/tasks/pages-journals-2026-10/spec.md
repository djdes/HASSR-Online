## Критерии приёмки

### AC1. Страницы наборов
1. Статические сегменты `src/app/(dashboard)/journals/sets/{standard,haccp,extra}/page.tsx` (или общий компонент на три страницы), guard — `hasFullWorkspaceAccess(` (как у API наборов); пункты `access: FULL_ACCESS`. `/journals/[code]` и прочие страницы журналов не ломаются.
2. Заголовок — название набора, пояснение — описание из `JOURNAL_SETS`; у стандартного — «по СанПиН …» как на эскизе («Журналы в соответствии с принципами ХАССП и СанПиН»).
3. Список журналов набора в порядке `JOURNAL_SETS` (у стандартного — нумерация 1–11 эскиза), у каждого: название, статус «включён / выключен», статус «заполнен сегодня / не заполнен / не требуется сегодня» (тот же расчёт, что «Сегодня», — `today-compliance` или его функция), связанные пункты (например журнал здоровья у гигиенического), ссылка «Открыть журнал» (для включённых).
4. Итог в шапке: «Включено N из M», «Заполнено сегодня K из N» — пилюлями (не больше двух).

### AC2. «Включить весь набор»
1. Кнопка на наборах с `bulkEnable` (стандартный, ХАССП), когда есть выключенные; `ConfirmDialog` перечисляет журналы, которые включатся.
2. Нажатие → `POST /api/settings/journals/sets { set }`; тост «Включено журналов: N»; список обновлён; повторное нажатие не нужно (кнопка пропадает, когда всё включено).
3. У «Дополнительных» массового включения нет: у каждого выключенного журнала — «Включить» по одному (существующий API включения журнала), или ссылка на «Настройку журналов».
4. Заведующая, если API ей разрешает, видит кнопку; если нет — видит статус без кнопки (по ответу API `canManage`/правам).

### AC3. Меню и права
1. `menuShape("journals")` с группой `sets`; подписи RU/EN/UZ; иконки.
2. Повар раздела наборов не видит; прямой заход — редирект/404.
3. Тесты `app-nav.test.ts` и соседние — зелёные; тест, что страницы не содержат зашитых кодов журналов (берут из `JOURNAL_SETS`).

### AC4. Проверка
1. Общие проверки `00-common.md`; Playwright: стандартный набор с частью выключенных → «Включить весь набор» → все включены; статус «заполнен сегодня» после записи в журнал; ХАССП; дополнительные; 1440 и 390; Mini App; скриншоты.
2. Предложение текста «Что нового» в `evidence.md`.
