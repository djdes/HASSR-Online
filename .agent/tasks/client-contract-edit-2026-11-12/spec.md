# Договор клиента: рыба, правка реквизитов клиента, персональная редакция текста

Страница: `/root/organizations/[id]#client-contract` (карточка `ClientContractCard`).

## Запрос владельца
«Дай возможность просто скачать рыбу договора, а также менять реквизиты
пользователя и редактировать персонально договор на случай нюансов и редакций
от клиента. Скачивать в docx и pdf, необязательных данных быть не должно.»

## Решения
- «Рыба» — договор без данных клиента: реквизиты ООО «БФС» заполнены, номер,
  дата и все данные Заказчика — линии для ручного заполнения; без пометки
  «Проект»; без факсимиле. Не требует ИНН клиента.
- Реквизиты клиента правятся в карточке и уходят в снимок договора (данные
  организации не меняются): наименования, ИНН, КПП, ОГРН, адреса, телефон,
  почта, банк/БИК/р/с/к/с. Пустое поле = данные организации / линия.
- Персональная редакция текста: разделы (заголовок + пункты построчно,
  «а) …» — подпункт) правятся, удаляются, добавляются; хранятся в
  `params.customSections` снимка (без изменения схемы БД). Раздел реквизитов
  добавляется последним автоматически.
- «Необязательных данных быть не должно»: необязательные строки реквизитов
  (телефон, фактический адрес) попадают в документ, только если заполнены —
  без пустых линий. Почта остаётся (на неё ссылается текст, разд. 11).

## Acceptance criteria
- AC1: `GET /api/root/organizations/[id]/contracts/blank?format=pdf|docx`
  (ROOT) отдаёт рыбу; в ней нет данных клиента и пометки «Проект», номер и
  дата — линии; работает у клиента без ИНН. В карточке — кнопки «Рыба PDF» и
  «Рыба Word».
- AC2: Проект договора по данным формы скачивается и в PDF, и в DOCX
  (`POST …/contracts/preview?format=pdf|docx`). Проект без валидного ИНН
  скачивается (линии); выпуск по-прежнему требует валидный ИНН.
- AC3: Форма содержит блок «Реквизиты клиента» с полями из AC-решений;
  значения из формы попадают в снимок (`buyer`) при выпуске и в проект;
  ИНН из 12 цифр → ИП (без КПП/должности). Банк клиента, если указан,
  выводится в реквизитах вместо линий.
- AC4: Редактор текста: включить «Изменить текст под клиента», править
  заголовки и пункты, удалить/добавить раздел, вернуть стандартный текст.
  Изменённый текст попадает в проект и в выпущенный договор (снимок), и
  выпущенный договор перерисовывается с ним (PDF/DOCX).
- AC5: Пустые телефон/фактический адрес не дают строк в реквизитах обеих
  сторон; все оставшиеся строки непустые.
- AC6: Новые тексты UI — в `ru/en/uz` + `npm run i18n:types`;
  `npm run typecheck` и `npm run test:changed` зелёные; юнит-тесты на
  рыбу, свой текст, реквизиты клиента, отсутствие пустого телефона.
