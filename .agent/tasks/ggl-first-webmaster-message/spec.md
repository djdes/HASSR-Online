# First contact with a GoGetLinks webmaster

- AC1. An administrator can open a first-message composer from a prepared donor slot, see which donor will receive the message, and send the text for the slot's WeSetup campaign. The text and all feedback are translated in Russian, English, and Uzbek.
- AC2. The server resolves the campaign and recipient from the slot, binds the request to the same donor shown in the composer, and only sends through a GoGetLinks form that makes the exact recipient available. It neither submits a placement nor moves funds. When GoGetLinks declines to open a conversation, WeSetup explains this without claiming delivery. Concurrent submissions and ambiguous results must not cause a repeated send.
- AC3. A confirmed first message can be followed in the existing chat view using the GoGetLinks synchronization. Ordinary replies keep working.
- AC4. Targeted tests, type checking and a fresh verification pass pass. Live verification may inspect composer availability without sending an unsolicited probe message.
