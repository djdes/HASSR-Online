# Spec (frozen 2026-11-10): APK приложения WeSetup по ссылке с сайта

Запрос владельца: «ты можешь апк выложить на сайт чтобы он был доступен для всех и я его скачал по ссылке сразу
в андроид планшет?»

## Исходное состояние (master 8738309e)

Подписанный APK получается только ручным запуском «Выпуска приложений» и лежит в артефактах запуска: нужен вход
в GitHub, архив zip, срок хранения. Запустить workflow из среды агента нельзя (403). Публичной ссылки нет.

## Критерии приёмки

- **AC1.** Workflow «APK на сайт» собирает APK тем же способом, что «Выпуск приложений» (ключ загрузки, боевой
  Firebase, проверка перед выпуском, apksigner, проверка пакета/номера/версии), и публикует его в выпуске GitHub
  с постоянной меткой `wesetup-app-latest`, файл `wesetup.apk`. Запускается изменением `mobile/site-apk.json` в
  master и вручную. Ключи в репозиторий и в выпуск не попадают, с раннера удаляются.
- **AC2.** `https://wesetup.ru/download/android` без входа отвечает 302 на файл выпуска; тест сверяет метку и имя
  файла в коде сайта и в workflow.
- **AC3.** После слияния workflow отработал, файл скачивается по ссылке — либо владельцу точно названо, чего не
  хватает (например, секретов).
- **AC4.** `npm run typecheck`, `npm run test:gate` зелёные; в `mobile/README.md` описано, как обновлять файл.

## Что НЕ входит

Кнопка скачивания на страницах сайта, автообновление приложения, iPhone, публикация в магазинах.

## Что меняет выкат

Новый маршрут `/download/android` (перенаправление). База и переменные сервера не меняются.

## Дополнение (2026-11-10, решение владельца: «делай тестовую на сайт»)

Первый запуск упал: в GitHub нет ни одного из пяти секретов подписи. Владелец выбрал тестовую сборку.

- **AC5.** Без секретов workflow не падает, а собирает тестовую сборку (как отладочный APK «Проверки приложений»,
  номер сборки из `mobile/site-apk.json`) и публикует её под той же меткой и именем файла; в названии и описании
  выпуска прямо сказано, что сборка тестовая и чем она ограничена. С секретами — прежний подписанный путь.
- **AC6.** `https://wesetup.ru/download/android` отдаёт файл APK (200 после перенаправлений).
