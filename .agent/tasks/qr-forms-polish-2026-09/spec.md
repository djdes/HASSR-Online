# Spec (frozen 2026-09-25): QR-формы — «обсл»/«рем» у холодильников, подсказки кнопки, комментарий, экран PIN, камера для приказов

Правки владельца (скриншоты QR-формы холодильника и экрана PIN):
1. **Холодильники** (журнал `cold_equipment_control`; QR-наклейка оборудования — `src/app/equipment-fill/[equipmentId]/equipment-fill-client.tsx` и связанные API/HTML; ячейки документа на сайте; печать): вместо температуры можно указать «обсл» (обслуживание) или «рем» (ремонт). В QR-форме — две кнопки «Обслуживание» и «Ремонт» рядом с вводом температуры; при выборе норма не проверяется, блок «Температура вне нормы» не нужен. В документе на сайте и в печати в ячейке температуры — «обсл» / «рем». Ячейку на сайте тоже можно заполнить «обсл»/«рем». Хранение — в данных записи (без изменения схемы БД), совместимо с существующими отчётами/автозаполнением (автозаполнение «как вчера» НЕ переносит «обсл»/«рем» на другой день — это событие дня).
2. **Под кнопкой сохранения** (QR-формы холодильника/склада/УФ и др. с неактивной кнопкой): если кнопка неактивна — под ней написано, чего не хватает: «Не выбран сотрудник», «Не указана температура», «Опишите, что сделали» и т. п. (как на экране задачи).
3. **Комментарий при отклонении** (`src/components/qr-fill/deviation-correction.tsx`, HTML-версия в `src/app/journal-fill/[orgId]/[code]/route.ts` и `journal-fill-html.ts`): по умолчанию выбран вариант «Повторю через 30 минут.» (сейчас «Сообщил руководителю»); текст варианта — «Повторю через 30 минут.» (единообразно в обеих версиях; тесты поправить).
4. **Экран PIN** (React: `equipment-fill-client.tsx`, `room-fill-client.tsx`, `src/components/qr-fill/qr-pin-step.tsx`; HTML: `journal-fill-html.ts`):
   - «Запомнили с прошлого раза — введите свой PIN.» показывать ТОЛЬКО когда при входе на страницу выбор сотрудника действительно восстановлен из памяти; после ручного выбора/смены сотрудника — не показывать.
   - Кнопка «Сменить» крупнее и по центру по вертикали в карточке «Кто снимает показания/заполняет».
   - «Запомнить выбор на этом оборудовании» — одинаковые отступы сверху и снизу (симметрично между карточкой сотрудника и карточкой PIN).
   - Кнопка «Продолжить» на шаге PIN → «Войти».
5. **Камера для приказов**: в блоке «Приказы к журналу» (`src/components/journals/journal-order-scans-panel.tsx`) на телефоне — кнопка «Камера» (фото сразу с камеры: input файла с accept image и capture environment), рядом с обычной загрузкой; фото загружается как скан (JPG). То же — при входе по QR: на QR-странице гигиенического журнала и БЖГП ответственный (у кого есть права на приказы) может сфотографировать и загрузить приказ; права и API — те же, что на сайте (найти, как QR-страница аутентифицирует пользователя, и не открыть загрузку тем, у кого прав нет).
