# Окно «Куда прислать шаблон?»: телефон, быстрая регистрация, невидимая проверка от ботов

Дата: 2026-11-12. Владелец сформулировал задачу в чате:

> При скачивании PDF добавить поле телефона для отправки в Telegram, MAX или СМС — необязательное,
> но текст «необязательно» не писать, компактно иконками, куда вышлем. В уведомлении «📥 Скачивание
> шаблона журнала» после почты — телефон, если указан. В окне по умолчанию — галка «Быстрая
> регистрация и полный доступ к сайту на N дней». Ненавязчиво, без лишних слов, крупно и удобно для
> телефона. Простая проверка от ботов, которую человек не видит. Скачал с галкой — на почту логин,
> пароль и ссылку автовхода. Письмо после регистрации (общий шаблон) — кратко о преимуществах.

## Решения

- **Срок доступа.** В тексте галки и в письме — `TRIAL_DAYS` из `lib/tariff-plans.ts` (сейчас 14), тот
  же срок, что обещают витрина и регистрация. Владелец назвал «10 дней» как пример текста; отдельного
  срока для этого канала не вводим.
- **Телефон.** В платформе нет отправки по номеру (ни СМС-провайдера, ни бота, который пишет первым по
  номеру в Telegram/MAX). Номер сохраняется вместе со скачиванием (AuditLog, CRM, маркетинговый контакт,
  профиль созданного аккаунта) и приходит в уведомление продажам — дальше отправка руками или будущей
  интеграцией. Иконки Telegram · MAX · СМС в поле — подсказка о каналах, без слов «необязательно».
- **Оферта.** Создание кабинета делает человека пользователем сервиса, поэтому в подписи галки ссылки
  на оферту и соглашение. Галка обязательного согласия на обработку ПДн остаётся как была (снята).
  При регистрации пишется `LegalConsent` с `LEGAL_CONSENT_TEXT`, источник `blank-register`.
- **Боты.** Невидимое поле-ловушка `website` (как у регистрации) и минимальное время заполнения окна.
  Заполнена ловушка — ответ выглядит успешным, но ничего не пишется и не отправляется. Окно отправлено
  быстрее 1,5 с после открытия (или без замера времени) — мягкая ошибка «обновите страницу и повторите».
  Повторное скачивание по запомненной почте окна не показывает и время не замеряет.
- **Регистрация.** Только из окна (не при скачивании по запомненной почте). Создание организации и
  пользователя — общий модуль с мгновенной регистрацией (`lib/instant-account.server.ts`). Существующая
  почта — кабинет не создаём, окно предлагает «Войти». Лимит регистраций с IP общий с мгновенной
  регистрацией; упёрлись — шаблон всё равно скачивается.
- **Автовход.** Ссылка `/api/auth/magic/<токен>`: одноразовая, живёт 7 дней (как ссылки на шаблон).
- **Письма.** Копия шаблона уходит как раньше (без блока «зарегистрируйтесь», если кабинет создан).
  Письмо с паролем (`sendAccountPasswordEmail`, общее для всех быстрых регистраций) получает блок
  преимуществ и строку про пробный срок; для регистрации из окна — кнопка автовхода вместо «Открыть
  кабинет» и текст без «вы уже вошли».

## Критерии приёмки

- **AC1.** В окне есть поле телефона (`type=tel`, маска `+7`) с иконками Telegram, MAX, СМС; слов
  «необязательно» нет; без номера скачивание работает. Неверный номер — ошибка у поля, запрос не уходит;
  сервер тоже отклоняет мусор (`invalid_phone`).
- **AC2.** Уведомление продажам: строка `Телефон: …` сразу после строки `Почта: …`, если номер указан;
  при созданном кабинете — строка о регистрации. Уведомление о созданном кабинете уходит, даже если
  почта скачивала шаблоны раньше.
- **AC3.** Галка «Быстрая регистрация — полный доступ на {TRIAL_DAYS} дней» отмечена по умолчанию;
  снятая — регистрации нет. Подпись ссылается на оферту и соглашение.
- **AC4.** Отмеченная галка и новая почта → создаются организация и пользователь (телефон в профиле,
  журнал шаблона включён), пишется `LegalConsent` `blank-register`, уходит письмо с логином, паролем и
  ссылкой автовхода (7 дней, одноразовая). Ответ `account: "created"`; окно говорит, что доступ в письме.
  Почта уже зарегистрирована → `account: "exists"`, окно предлагает войти.
- **AC5.** Ловушка `website` заполнена → ответ успешный, но нет записей согласия, лида, уведомления,
  писем и регистрации. Окно отправлено быстрее 1,5 с → ошибка `too_fast`, без побочных эффектов.
- **AC6.** Письмо после быстрой регистрации содержит блок преимуществ платформы и пробный срок; тексты
  во всех словарях (ru/en/uz), `message-contract.d.ts` перегенерирован.
- **AC7.** Окно удобно на телефоне: поля и кнопка 52px, текст полей 16px, крупные галки.
- **AC8.** `npm run typecheck`, `npm run lint` по изменённым файлам и `npm run test:changed` зелёные.
