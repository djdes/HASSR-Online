# Настройка кабинета за 3 минуты: вид деятельности + 5 вопросов → готовый кабинет

- **Task ID:** `quick-setup-3-minutes-2026-11-21`
- **Base:** `origin/master` `fd6c6bca2`
- **Branch:** `claude/hopeful-euler-lb6cie`
- **Frozen:** 2026-11-21, before implementation.

## Запрос владельца (21.11.2026)

«Сделай все кроме 6,7» — пункт 1 предложений: «Автонастройка кабинета по виду деятельности: выбрал вид и ответил
на 5 вопросов — журналы, должности, оборудование, графики уборки и QR-плакаты готовы за 3 минуты».

## Что уже есть (разбор)

- «Шаблоны заведений» (`/settings/onboarding-template`, `src/lib/onboarding-templates.ts`,
  `POST /api/settings/onboarding-template`): 5 видов (прилавок, кафе, ресторан, школьная столовая,
  производство); применяет должности, точку, помещения (зеркала Room ↔ Area — по ним идёт уборка), оборудование,
  журналы. Количество оборудования и помещения — фиксированные; всё оборудование — в первое помещение.
- Ошибки шаблонов: холодильники заводятся с типом `fridge` (справочник оборудования знает `refrigerator`),
  металлодетектор, магнитоулавливатель и весы — с типом `thermometer`.
- Медцентра и отеля (виды на главной) нет. «Быстрый старт» (`/settings/onboarding`) на шаблоны не ведёт.
- QR-плакаты — `/settings/qr-posters` (строятся по оборудованию и помещениям).

## Решения

- Р1. «Шаблоны заведений» → мастер «Настройка за 3 минуты»: шаг 1 — вид деятельности (7 видов), шаг 2 — 5 вопросов,
  заполненных по виду: холодильники, морозильники, УФ-лампы (числа), фритюрница (да/нет), помещения (набор);
  итог «будет создано»; шаг 3 — результат и что дальше: QR-плакаты, сотрудники, журналы.
- Р2. `customizeTemplate(template, answers)` — чистая функция (её же считает мастер для итога):
  оборудование по числам (имена шаблона, дальше «Холодильник №k», «Морозильник №k», «УФ-лампа №k»), фритюр —
  по ответу; помещения — по набору (только из шаблона и каталога помещений); каждое оборудование — в подходящее
  помещение (холод — склад/камера, УФ — цеха и кабинеты по кругу, фритюр — горячий цех); журналы по ответам:
  фритюр → `fryer_oil`, УФ-лампы → `uv_lamp_runtime`, холодильники/морозильники → `cold_equipment_control`,
  бассейн → `pool_water_control`, стерилизационная → `instrument_sterilization`, комната отходов →
  `medical_waste_b` — включить, если есть, выключить, если нет.
- Р3. API принимает необязательные `answers` (zod); без них — как раньше. Журналы: у шаблона с явным набором —
  набор с поправками; у шаблона «все» — текущий набор организации с теми же поправками. Лимит тарифа — до записей.
- Р4. Новые виды: «Медицинский центр» и «Отель с завтраками»; типы оборудования шаблонов — как в справочнике
  (`refrigerator`, `scale`, `other`).
- Р5. Тексты мастера, названия и описания видов — через словари ru/en/uz (названия должностей, помещений и
  оборудования, которые пишутся в кабинет, остаются русскими, как сейчас).
- Р6. «Быстрый старт»: пока кабинет не настроен — карточка «Настроить за 3 минуты» → мастер.

## Критерии приёмки

- **AC1.** `customizeTemplate` (тест): числа → оборудование с именами шаблона и «№k»; 0 — нет такого
  оборудования; фритюр по ответу; помещения только допустимые; размещение по помещениям; поправки журналов по
  ответам; без ответов — шаблон как есть.
- **AC2.** API: `answers` проверяются (zod), неизвестное помещение — отказ; без `answers` — прежнее поведение;
  медцентр и отель применяются; журналы шаблона «все» = набор организации ± поправки (тест на чистой функции
  плана журналов).
- **AC3.** Мастер: 3 шага, ответы заполнены по виду, итог совпадает с `customizeTemplate`, экран результата со
  ссылками на QR-плакаты, сотрудников и журналы; ru/en/uz; снимки 1440 и 390 px.
- **AC4.** «Быстрый старт» показывает карточку «Настроить за 3 минуты», пока основные этапы не закрыты.
- **AC5.** `npm run i18n:types`, typecheck, test:changed / test:gate, eslint, палитра «Новой» — зелёные.
