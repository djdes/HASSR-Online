## Сделать
1. **Стрелка у раскрывающихся пунктов.** У каждого пункта главного меню с собственным меню раздела — постоянная стрелка › (сайдбар, лист бургера, лист Mini App, `/mini/sections`); у «Остального» — нет. В листах телефона и Mini App нажатие на такой пункт раскрывает меню раздела прямо в листе (стрелка обещает именно это), «‹ Главное меню» возвращает список; заголовок раздела в листе — ссылка на корень раздела.
2. **Центр шапки — точка, не компания.** Чистая функция выбора подписи (`src/lib/header-point.ts`) + тесты; `CurrentPointSwitcher` показывает подпись «Точка»/«Точки» над названием. Правила: точек нет → руководителю (полный доступ) «+ Добавить точку» на «Торговые точки», остальным — ничего; одна точка → её название, а если оно совпадает с названием компании (без учёта регистра, кавычек, пробелов) — адрес, без адреса — «Основная точка»; точка без названия → адрес, иначе «Точка без названия»; несколько точек и журналы по точкам → переключатель (активная точка по тем же правилам, в списке — название + адрес); несколько точек без разделения журналов → «Все точки · N» без переключения.
3. **«Пришла проверка» — отдельное действие.** В покое — контурная кнопка (белый фон, рамка, индиго-текст, щит), заливка — только когда раздел открыт. То же в листе телефона и Mini App.
4. **Без дублей заголовков.** `SectionPageHeader` без надстрочной подписи раздела (раздел уже назван в меню слева) и с той же разметкой, что `PageHeader`. Обзор ППК: шапка через `SectionPageHeader`, без монограммы и названия компании, прогресс — под заголовком. Mini App: кнопка меню раздела называет раздел («Меню раздела» + название раздела), а не пункт.
5. **Общий проход.** «Сегодня» — видимый h1 «Сегодня» с пояснением; действия шапки (`PageHeader`/`SectionPageHeader`) переносятся, не выходя за край; новые элементы — hover/focus по дизайн-системе (`ring-[#5566f6]/15`, 150–200 мс).
6. Тексты RU/EN/UZ, `node scripts/i18n-types.mjs`; «Что нового» — категория «Интерфейс».
