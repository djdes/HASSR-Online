# Лендинг: проход по тексту — хиро + слияние «Автоматизации» с главой «Датчики»

Дата: 2026-09-24. Продолжение qr-player-simplify-2026-09 (одобрено владельцем:
«давай», «чисто по лендингу»). Исходное: master a43bd523.

## Замечание-первоисточник

«Опус прям заметно разговорчивый… упростить эту страницу особенно по тексту».
QR-блок уже сжат; этот заход — остальная страница, без смены структуры,
кроме одного одобренного слияния секций.

## Изменения

1. **Хиро: карточка цен → строка-пилюля.** Сейчас между буллетами и CTA
   стоит карточка ~150px с тремя строками тарифов — она дублирует
   секцию #pricing и отжимает кнопку регистрации под сгиб на телефоне.
   Вместо неё одна строка «До 3 сотрудников — бесплатно · дальше от
   N ₽/мес →» той же ссылкой на #pricing. Числа — из тех же констант.

2. **Секция «Автоматизация / Температура пишется сама» удаляется.**
   Глава «Датчики» QR-ролика рассказывает тот же сюжет (датчик пишет
   сам, уведомление при нарушении); FEATURES-карточки «Автозаполнение»
   и «Алерты», тариф «IoT-датчики» держат тему автоматизации вне ролика.
   Вместе с секцией удаляются: компонент automation-scene.tsx
   (использовался только здесь), его CSS-блок в globals.css
   (`automation-*`, только его классы), иконка Wifi из импорта page.tsx.
   Что теряем: подпись «сканер на приёмке работает так же» — остаётся
   в FAQ (iiko/1С) и на /features/sync-iiko-1c.

3. **Точечные срезы текста** (без изменения смысла, только дубли):
   - «Так выглядит заполнение журнала на планшете»: абзац 3 предложения
     → 1 (буллеты под ним остаются — в них конкретика).
   - «Заполните журнал прямо здесь»: абзац 2 предложения → 1.
   - Блог: вторая фраза «Короткие тексты — читать можно в перерыве…»
     удаляется.

Не трогаю: H1, 4 буллета хиро (короткие, сканируются), абзацы «Какие
журналы внутри» и тарифов (несут уникальную информацию), FAQ, баннер.

## Acceptance criteria

- AC1: в хиро между буллетами и CTA — одна строка-ссылка на #pricing
  с теми же числами из констант; карточки нет.
- AC2: секции «Температура пишется сама» нет; automation-scene.tsx и
  его CSS удалены; `npm run typecheck` чист (нет висячих импортов).
- AC3: страница по-прежнему упоминает датчики/автозаполнение вне ролика
  (FEATURES, тарифы) — grep по «датчик» на отрендеренной странице ≥ 2.
- AC4: полная высота лендинга на 390px сокращается ≥ 1000px.
- AC5: `npm test` зелёный; прод после деплоя отдаёт новую пилюлю и не
  отдаёт «Температура пишется сама».
