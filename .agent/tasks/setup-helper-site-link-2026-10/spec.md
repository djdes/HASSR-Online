# «Сетап помощник» ↔ сайт: справочники в приложении и журнал маркировки (2026-10-31)

Заморожено 31.10.2026. Запрос владельца (идея № 1 «Маркировка заготовок»): «у нас разработано приложение
помощник сетап для печати этикеток и там же маркировка — свяжи с сайтом, если ещё не сделано».

## Что уже связано
Вход в приложение по почте и паролю сайта, ключ телефона; события о принтерах (`printer_connected`,
`printer_printed`, `printer_removed`) → «Онлайн-принтер → Принтеры этикеток»; фирменная шапка этикеток
(`/api/setup-helper/branding`); автообновление APK с сайта.

## Чего нет
- Поля этикеток («Продукт», «Блюдо», «Поставщик», «Изготовил») набираются руками: справочник продуктов
  сайта (срок годности, условия хранения), блюда бракеражного журнала и сотрудники в приложение не попадают.
- Что именно промаркировано, сайт не знает: от печати остаётся только «последняя печать: шаблон» у
  принтера. Нет журнала маркировки и контроля сроков по этикеткам.

## Решение
1. **Справочники для приложения** — `GET /api/setup-helper/catalog` (ключ телефона, как у остальных
   методов): продукты из справочника продуктов (срок годности в часах из `shelfLifeDays`, условия хранения,
   поставщик) и из списков бракеража скоропортящейся продукции, блюда из бракеражного журнала, поставщики,
   имена работающих сотрудников. Только своя организация. `version` — хеш содержимого; `?version=<та же>` →
   `{ version, unchanged: true }` без тела.
2. **Приложение**: хранит копию справочников (как шапку: при входе, открытии и появлении сети; без сети —
   последняя копия; выход из аккаунта стирает). Поля шаблонов с `source` (`products`, `dishes`,
   `suppliers`, `staff`) подсказывают значения из справочника вместе с прежними вариантами; выбор продукта
   подставляет срок годности (`fillFrom: "shelfLife"`) и условия хранения (`fillFrom: "storage"`).
3. **Событие `label_printed`** — у шаблонов маркировки (`record` в JSON шаблона): что (продукт или блюдо),
   изготовлено / начало, «годен до» (та же дата, что на этикетке), кто, остальные поля этикетки (подпись +
   значение), шаблон, копии, принтер. Пробная этикетка и произвольный текст по-прежнему шлют
   `printer_printed`. Сервер: идемпотентно по id события, организация — из ключа телефона, принтер
   обновляется как при `printer_printed`.
4. **Журнал маркировки** на сайте — `/settings/print-agent/labels` (руководство): этикетки за сегодня /
   7 / 30 дней, «годен до» со статусом (годно, истекает в ближайшие 24 ч, истёк), фильтр «только
   истекающие и истёкшие»; на странице «Онлайн-принтер» — сводка (сегодня напечатано, истекает, истекло)
   и ссылка.
5. **Выпуск 1.4.0** (versionCode 7): подписанный APK собирает CI (`publish`), APK и `version.json` — в
   `resources/setup-helper/`; телефоны обновятся сами.

## Критерии приёмки
- **AC1** — справочник: чистая функция сборки (дубли, пустые, лимиты, сортировка, срок в часах, версия);
  маршрут отдаёт только свою организацию, 401 для отозванного ключа, `unchanged` при той же версии; тесты.
- **AC2** — `label_printed`: разбор (лимиты длин, даты, копии; битая этикетка — в `rejected`, пакет не
  падает), запись `LabelPrint` идемпотентна (повтор пакета не задваивает), принтер обновляется; тесты.
- **AC3** — журнал маркировки и сводка на «Онлайн-принтере»: статусы сроков по часовому поясу организации,
  фильтры, доступ только руководству; скриншоты.
- **AC4** — приложение: разбор `source` / `fillFrom` / `record` в шаблонах, справочник (разбор, поиск
  продукта без учёта регистра), подсказки и автоподстановка на экране печати, `label_printed` в очереди;
  тесты ядра и экранов (Robolectric).
- **AC5** — версии: приложение 1.4.0 (7), заметки к выпуску; `:core:test :app:testSiteDebugUnitTest` и
  тест варианта Play — зелёные; сайт — `typecheck`, `test:gate`, `eslint` по изменённым файлам,
  `i18n:check` — зелёные.
- **AC6** — выпуск: подписанный APK 1.4.0 и `version.json` из CI лежат в `resources/setup-helper/`,
  `route.test.ts` версии проходит, после деплоя `/api/setup-helper/version` отдаёт 1.4.0.

## Вне задачи
QR на этикетке и публичная страница этикетки, автоматические строки в журналах по этикеткам (суточные
пробы, разморозка), выбор точки сети в приложении, вход в приложение поварам.
