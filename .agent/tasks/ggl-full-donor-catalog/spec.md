# Восстановление поиска площадок GoGetLinks

- AC1. Планировщик получает страницы каталога через фактический запрос GoGetLinks. Сохраняются пороги плана, цена, проверка публикаций и резервный источник входящих предложений.
- AC2. Повторные фоновые проходы расширяют выборку для старых слотов, учитывают новые площадки и сохраняют черновик и посадочную. Закупка и сообщения вебмастерам по-прежнему требуют явного подтверждения.
- AC3. Точечные тесты и проверка типов проходят. В продакшене проверяется результат первого слота по существующим критериям.
