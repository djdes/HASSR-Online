# Поддержка → менеджеру; оплаты по счетам из выписки СберБизнес (07.11.2026)

Запрос владельца: (1) всё, что пишут на сайте в поддержку, — в рабочий Telegram и
кабинет менеджера Алексея; (2) Сбер: сайт сам сопоставляет оплаты по выставленным
счетам и активирует аккаунт, доступ — тот же, что у DocsFlow (подключение ScanFlow),
в админке — статус подключения и сертификата.

## Критерии
- AC1. Обращения (форма на сайте, гостевая форма, виджет, онлайн-чат, бот, «без ответа»,
  вложения) уходят администраторам и всем, у кого в панели раздел «Обратная связь»:
  почта + привязанный Telegram; ответ свайпом принимается из их чатов.
- AC2. На /root/me («Почта и Telegram») — карточка привязки рабочего Telegram: статус,
  кнопка в бота с токеном, «Проверить», «Отвязать».
- AC3. Крон /api/cron/sber-payments (и кнопка на /root/sber) читает выписку р/с из
  реквизитов доступом ScanFlow (только SELECT токена, refresh — через ScanFlow),
  находит оплаты наших открытых счетов (номер+сумма или ИНН+сумма) и отмечает их
  через markInvoicePaid; спорные — администраторам, ничего не отмечая; повтор — no-op.
- AC4. /root/sber (раздел «Деньги», доступ billing): состояние сверки, токенов,
  секрета, TLS-сертификата (.p12), последняя сверка, распознанные платежи.
- AC5. Чистые функции сопоставления и разбора выписки покрыты тестами; tsc без новых ошибок.
