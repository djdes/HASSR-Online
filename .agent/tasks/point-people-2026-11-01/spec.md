# Люди и права руководителя точки — только своя точка (2026-11-01)

Источник: детальный аудит «точка видит только своё» (5 проверок, 2026-11-01),
группа «people». Руководитель точки = `pointScope` в сессии (организация с офисом,
человек закреплён только за торговыми точками). Выбранная в шапке точка —
`getViewedPointId`.

## Критерии приёмки

- **AC1. Общие API офиса закрыты руководителю точки (proxy, `point-scope.ts`).**
  Изменения (не GET) запрещены: права (`/api/organizations/permissions`),
  справочник продукции (`/api/products`), быстрая настройка (`/api/onboarding/apply`),
  удаление всех документов, подключения ЭДО/iiko (`/api/settings/supply`), 1С
  (`/api/settings/hr1c`), Меркурий, Max (`/api/max/organization`), общие действия
  TasksFlow (подключение/отключение, cleanup-pending/completed,
  reset-negative-balances, sync-users, sync-hierarchy), ссылка проверяющего
  (`/api/settings/inspector-tokens`); переименовать/удалить/переставить должность
  (`/api/positions/*`). Остаются открыты: `POST /api/positions` (новая должность при
  добавлении сотрудника), задачи точки TasksFlow (`bulk-assign-today`,
  `sync-room-photo-policy` и др.). Страница `/settings/inspector-portal` — офису.
- **AC2. Чтение на всю компанию закрыто руководителю точки на уровне маршрута:**
  `/api/settings/export-journals`, `GET /api/audit`, `/api/settings/audit/export` → 403.
- **AC3. Графики людей:** увольнение и его отмена, отпуск/больничный и их удаление,
  выходные (bulk), смены (`/api/organizations/schedule` GET/PUT/DELETE) — только
  люди своих точек (403 / не видны).
- **AC4. Кадровые данные:** импорт в режиме обновления не трогает людей других точек;
  премии (лента, выгрузка, отзыв), навыки (страница, API GET — только руководству —
  и POST), выгрузка сотрудников, карточка доступа (страница и GET API) — только люди
  своих точек.
- **AC5. Запросы PIN с QR:** список в «Сотрудниках» — только люди своих точек;
  одобрить/отклонить чужого — 403; сигнал о запросе — руководителям точки
  сотрудника и офису, не руководителю другой точки.
- **AC6. Ссылка-приглашение (join)**, выданная руководителем точки, заводит человека
  на точки руководителя, а не «на все точки».
- **AC7. Поиск (⌘K):** люди, документы и оборудование — выбранной точки (и общие),
  у руководителя точки — его точек; «Вся организация» — всё.
- **AC8. Ленты кабинета:** медкнижки, обучение, лента отметок — люди выбранной точки
  (руководитель точки — своих).
- **AC9. ППК «Ознакомление»:** сводки на страницах политики и группы ХАССП, счётчики
  и напоминание — только люди выбранной точки (руководитель точки — своих).
- **AC10. «Пришла проверка»:** руководителю точки ссылка проверяющего не
  показывается и не выдаётся (она открывает журналы всех точек).
- **AC11.** Проверка типов — 0 ошибок; тесты затронутых модулей зелёные.

## Ограничения

- Без изменений схемы Prisma. `InspectorToken` без точки — вопрос владельцу.
- Организации без офиса: `pointScope` там не задаётся (правило фазы 2) — проверки
  AC1–AC6 на них не действуют; AC7–AC9 (выбранная точка) действуют.
