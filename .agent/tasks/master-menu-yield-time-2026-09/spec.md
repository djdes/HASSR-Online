# Spec (frozen 2026-09-24): мастер-кабинет — меню списком «Наименование — Выход — Время», как «Добавить списком» в БЖГП

Запрос владельца: «В мастер-кабинете необходимо сделать загрузку списком так же, как сделали в БЖГП. Наименование — выход — время и т. п.»

## Как сейчас
- Мастер-кабинет (`/master`, `src/components/master/master-directory-client.tsx`, API `src/app/api/master/directory/*`, логика `src/lib/master-directory.ts`, раздача `src/lib/master-directory-push.ts`): меню — только названия; «Вставить списком» — текстовое поле «одна позиция в строке».
- БЖГП «Добавить списком» (`src/components/journals/finished-product-document-client.tsx` ~L780–870, разбор `src/lib/finished-product-bulk.ts`): таблица «Наименование | Выход, г» до 50 строк, вставка столбцов из Excel/текста прямо в таблицу (распознаёт шапку, нумерацию, выход «150», «150 г», «200/10», «0,5», «1 шт.», «200 мл»), общее «Дата и время изготовления» для всех строк.
- Память подсказок: `NameSuggestion.meta` = `NameSuggestionMeta` (`src/lib/name-suggestions.ts`, сейчас только `productTemp`), формы подставляют её при выборе названия (QR — JS в `src/lib/journal-fill-html.ts` ~L239, сайт — клиент БЖГП).

## Что сделать
1. **Данные.** `SharedDirectoryItem` + необязательные `portion String?` (выход, как вводят: «200», «200/10», «1 шт.») и `time String?` (время изготовления по меню, «HH:MM»). Только добавление полей (prisma db push). `SharedItem` + `portion`, `time` (для сырья — не используются). Нормализация: выход — как `cleanYield` из `finished-product-bulk.ts`; время — «8:0», «08.00», «8-30» → «08:00»/«08:30», мусор → пусто.
2. **Мастер-кабинет, вкладка «Меню → БЖГП».**
   - «Вставить списком» → окно-таблица как в БЖГП «Добавить списком»: столбцы «Наименование | Выход | Время», вставка из Excel/текста прямо в таблицу (переиспользовать/расширить разбор `finished-product-bulk.ts` третьим столбцом времени, с тестами), строки добавляются/удаляются, старт — текущий список мастера (удалил строку — позиция уберётся). Лимит строк — как у меню мастера (5000), а не 50; таблица прокручивается.
   - Загрузка Excel/CSV: `parseSharedItemsFromSheet` узнаёт колонки выхода («Выход», «Вес», «Выход, г», «Вес порции») и времени («Время», «Время изготовления», «Время выдачи») — строгие заголовки, как для названия (тесты).
   - Список на вкладке показывает столбцы «Выход» и «Время»; предпросмотр различий учитывает изменения выхода/времени у той же позиции («Изменится N»).
   - Вкладка сырья — без изменений.
3. **Раздача пищеблокам.**
   - Подсказки блюд пула (`listNameSuggestions` scope `dish`, источник мастера) отдают `meta` с `portionWeight` и `productionTime` из меню мастера (`NameSuggestionMeta` += эти поля, `normalizeSuggestionMeta` их пропускает; своё значение пищеблока приоритетнее мастерского, если уже было).
   - Сайт, БЖГП: при выборе блюда в окне добавления строки пустые «Вес выход» и время изготовления заполняются из `meta` (дату не трогать — только время); в «Добавить списком» пустой выход строки подставляется по названию.
   - QR-форма (`journal-fill-html.ts`): при выборе блюда пустые поля выхода и времени изготовления заполняются из `meta` так же, как сейчас `productTemp`.
   - Названия по-прежнему уходят в `itemsCatalog` активных документов (как сейчас).
4. **Не ломать:** пул без мастера и меню без выхода/времени работают как раньше; вкладка сырья, «Изменится» считается только по полям меню.

## Критерии приёмки
- AC1: в мастер-кабинете меню вводится таблицей «Наименование | Выход | Время» со вставкой из Excel (3 столбца, 2 столбца, с шапкой и без, с нумерацией), сохраняется и показывается в списке; файл Excel/CSV с колонками выхода и времени загружается так же.
- AC2: предпросмотр показывает добавленные, убранные и изменённые (выход/время) позиции.
- AC3: у пищеблока пула при выборе блюда из меню мастера на сайте (окно строки и «Добавить списком») и в QR-форме пустые выход и время подставляются из меню; введённое вручную не перезаписывается.
- AC4: без мастера/без выхода и времени поведение прежнее (тест).
- AC5: typecheck, `npm test` (новые тесты разбора таблицы, заголовков файла, нормализации, meta), `npm run build` — зелёные; e2e на своей базе со скриншотами 1440 и 390.
