# Правки интерфейса по сканам 98 и 99 (2026-10-28)

Источник: распечатки кабинета с пометками ручкой —
«Отсканированный документ 98.pdf» (блок правок по интерфейсу, 7 листов) и
«Отсканированный документ 99.pdf» (мастер-кабинет, 1 лист).

## Что написано на сканах

| Лист | Экран | Пометка |
| --- | --- | --- |
| 98/1 | Главная `/home` | переключатель «Организация · Офис» в шапке — «Именно тут это не нужно» |
| 98/2 | «Информация об организации» | то же — «Именно тут это не нужно» |
| 98/3 | «Точки и помещения» | «Тут должны быть только торг. точки без „офиса"», карточка офиса зачёркнута |
| 98/4 | «Цеха и участки» | дорисованы кнопки «QR-наклейки · Плакаты А4 · Таблички» |
| 98/5 | «Оборудование» | «QR-наклейки» печатает всё оборудование организации, а должно — только этой точки |
| 98/6 | QR-коды | QR «Все журналы» открывает журналы всех точек, а должен — только этой точки |
| 98/7 | QR-коды | «Наклейки на оборудование (72)» и «на склады (19)» — по всей организации, нужно только этой точки |
| 99/1 | Мастер-кабинет | переключатель точки не нужен; «Код справочника» непонятен; нет кабинета «Школы»; нужно: какие кабинеты есть, добавить торговую точку, добавить внешнего сотрудника — оператора МК |

## Решения исполнителя (владелец сказал «реализуй сам»)

- Переключатель точки скрыт на страницах про всю компанию, где выбор точки
  ничего не меняет: главная, разделы «Моя компания» (реквизиты, мастер-кабинет),
  «Офис», «Подписки», «Настройки и оформление» и список всех точек.
  На страницах точки (журналы, цеха, оборудование, QR, сотрудники, ППК) — остаётся.
- «Точка» на QR-странице и в кнопках печати — точка из шапки (cookie
  `wesetup.building`). Журналы не по точкам (точка в шапке не выбрана) — как раньше,
  вся организация.
- Кнопки на «Цехах» печатают оборудование цехов этой точки (таблички нумеруются по
  цехам) — те же три кнопки, что на «Оборудовании».
- Оборудование «этой точки» = как список на странице «Оборудование»: цеха точки и
  цеха без точки.
- QR «Все журналы» точки — токен `<org>:all:b~<buildingId>`: в списке журналы
  набора точки, документы — этой точки и общие. Старые плакаты `<org>:all`
  работают как раньше.
- Мастер-кабинет: страница — список кабинетов, связанных с организацией (кабинеты
  аккаунта и кабинеты, к которым подключена организация или её точки). В каждом:
  точки организации с «Отключить», «+ Добавить точку», операторы. Код справочника
  с главного экрана убран (он нужен только оператору; объяснение — в «Как это работает»).

## Критерии приёмки

- AC1. `headerPointHidden(path)` — true для `/home`, путей разделов company,
  office, billing, settings и `/settings/buildings`; false для журналов, цехов,
  оборудования, QR, сотрудников, страницы точки. Переключатель в шапке на скрытых
  путях не рисуется. Тест.
- AC2. На «Точках и помещениях» нет офиса; переключатель «Вести журналы отдельно
  по точкам» виден, как раньше (по числу всех точек, включая офис).
- AC3. На «Цехах и участках» кнопки «QR-наклейки», «Плакаты А4», «Таблички» (как
  на «Оборудовании»), если у точки есть оборудование и человек может управлять.
- AC4. Экран наклеек (`?kind=equipment|rooms` без `ids=`) при выбранной точке —
  только объекты этой точки (оборудование её цехов и цехов без точки; помещения
  этой точки). С `ids=` — ровно отмеченные, как раньше.
- AC5. Общий экран QR при выбранной точке: «Все журналы» — QR этой точки;
  счётчики «Наклейки на оборудование / помещения» — по точке; список журналов —
  набор журналов точки. Наклейки журнала объектов (без `doc=`) — объекты точки.
- AC6. `verifyJournalFillToken` принимает `<org>:all:b~<id>` как хаб с точкой;
  хаб точки показывает журналы с документами этой точки (и общими), набор точки;
  переход в журнал из хаба — документы точки; статус журнала объектов — объекты
  точки. Слитая организация: старый хаб ведёт в хаб её точки. Тесты токена и слияния.
- AC7. Мастер-кабинет: все кабинеты аккаунта и подключённые; у каждого — точки
  этой организации, «Отключить» (ConfirmDialog), «+ Добавить точку» (точки, уже
  подключённые к другому кабинету, — недоступны с подписью), операторы: владелец
  аккаунта — пригласить по почте / дать доступ / убрать; остальные — список и
  приглашение по почте в подключённый кабинет. Подключение и отключение — общая
  логика с вкладкой «Подключённые объекты» самого кабинета.
- AC8. Переключателя точки на странице мастер-кабинета нет (AC1); страница и её
  API закрыты руководителю точки (как вся «Моя компания»).
- AC9. Тексты ru/en/uz, `npm run i18n:types`, «Что нового», typecheck, тесты.
