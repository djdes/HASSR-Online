# Окно скачивания шаблона: «Дополнительно», гео по IP, без галки рассылки

Task ID: `blank-download-extras-2026-11` · заморожено 2026-11-17 до реализации.

## Запрос владельца (коротко)
1. Убрать галку «Присылать полезные материалы и новости WeSetup» — в окне две галки, «Быстрая регистрация» отмечена по умолчанию.
2. При вводе почты окно не «прыгает», подсказки короче.
3. Под полем «Название компании» — кнопка «Дополнительно»; раскрывает поля под конкретный журнал (сотрудники, оборудование, помещения, ответственный). Данные попадают в скачанный файл и — при быстрой регистрации — в кабинет. QR в скачанном журнале при автоРеге ведёт на QR журнала кабинета (запись сотрудника по PIN); без автоРега — на регистрацию (`/qb`, как сейчас).
4. Страна (флаг) по IP и местное время клиента — в Telegram-уведомлении и на сайте (карточка клиента в /root).
5. В Telegram — общее число введённых доп. данных.

## Решения
- Доп. данные хранятся без смены схемы: `AuditLog.details.extras` записи `blank.download` (её `entityId` = id согласия). Подписанный токен ссылки несёт `k` (id согласия) — роут файла достаёт данные; `o` (id организации) — только если кабинет создан этим же запросом.
- Набор полей по журналу — чистая функция `blankExtrasSections(code)`; сервер отбрасывает разделы, не положенные журналу; лимиты: до 10 строк в разделе, до 80 символов в поле.
- В кабинет: сотрудники → `createStaffMember` (должность — upsert JobPosition «staff»), ответственный → сотрудник с должностью категории «management»; помещения → `Area`; оборудование → `Equipment` (холодильник +2…+6, морозильник −24…−18) в первом цехе (создаётся «Основной цех», если цехов нет). Ошибки не ломают скачивание.
- Часовой пояс: браузер присылает `tz` (IANA); при быстрой регистрации он пишется в `Organization.timezone`. Страна/город — `lookupIpGeo(ip)` (заголовки прокси `cf-ipcountry`/`x-geoip-country`, иначе HTTPS-запрос к `IP_GEO_URL`, по умолчанию ipwho.is; таймаут 1,5 с, кеш 24 ч; приватные IP не спрашиваем). Поиск — в `after()`, скачивание не ждёт.

## Критерии приёмки
- AC1: в окне нет галки рассылки (`blank-download-marketing` отсутствует), есть ровно две галки; «Быстрая регистрация» отмечена по умолчанию; запрос не шлёт `marketing`. Сервер по-прежнему принимает `marketing` от старых клиентов.
- AC2: поле почты не меняет высоту окна во время ввода: структурные ошибки показываются только после ухода с поля/отправки; подсказка опечатки — кнопка внутри поля справа (`{домен}?`), проверка домена — значок внутри поля. Текст ошибок короткий, одна строка.
- AC3: кнопка «Дополнительно» под полем компании раскрывает поля по журналу: hygiene/health_check/med_books/staff_training/ppe_issuance — сотрудники (ФИО, должность); cold_equipment_control — холодильное оборудование (название, холодильник/морозильник); fryer_oil/equipment_* /uv_lamp_runtime/breakdown_history — оборудование (название); cleaning/general_cleaning/climate_control/cleaning_ventilation_checklist/sanitary_day_control/disinfectant_usage/pest_control — помещения; всем — ответственный (ФИО, должность). Тексты — во всех трёх словарях.
- AC4: `normalizeBlankExtras` чистит и ограничивает ввод, отбрасывает чужие журналу разделы; `countBlankExtras` считает введённое; покрыто тестами.
- AC5: доп. данные попадают в скачанный файл (PDF и Word): сотрудники — строки гигиенического/журнала здоровья, оборудование — холодильники, помещения — уборка/климат; ответственный — в шапке. Проверено генерацией файла в тесте.
- AC6: при созданном кабинете доп. данные заводятся в кабинет (сотрудники, ответственный, помещения, оборудование), часовой пояс — в организацию; QR в файле — `/qj/<org>/<code>/<sig>`. Без кабинета QR — `/qb/<токен>` как раньше.
- AC7: Telegram-уведомление содержит строку с флагом страны (и городом, если известен) и местным временем клиента, и строку «Доп. данные: N (…)», если что-то вводили. Покрыто тестом `buildBlankDownloadAdminText`.
- AC8: карточка клиента `/root/organizations/[id]` показывает флаг/страну по IP регистрации и местное время по часовому поясу организации (тексты в ru/en/uz).
- AC9: `npm run typecheck` и `npm run test:changed` зелёные; `npm run i18n:types` перегенерирован.
