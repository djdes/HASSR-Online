# План: фирменный QR — ч/б минималистичный знак, полоса с одним словом

Спека: `spec.md` (заморожена 2026-09-27). База — master 495c4fc4 (ветка `feat/bwqr-2026-09-27`).

0. **База «до»** (код ещё не тронут): `baseline.ts` — по всем наборам бланков (`journal-qr-header-2026-09/pages.ts`:
   samples, blanks, long, paper, variants, portrait) число страниц, места QR, ячейка QR в шапке (ширина/высота по
   странице), модуль → `raw/baseline-master.json`; шаблоны Word (6 журналов, DOCX → PDF через LibreOffice) — число
   страниц → `raw/docx-master.json`. Всё тяжёлое — в `D:/wt-build/tmp-bwqr`.
1. **Знак** (`brand-qr.ts`): плоский ч/б по мотивам иконки — чёрная обложка блокнота, кольца слева, белая «C»;
   только чёрный и белый, векторные примитивы (скруглённые прямоугольники, круги) — одна геометрия для SVG,
   PNG (@napi-rs/canvas) и jsPDF. Подложка и вырез модулей под ней — как сейчас (H, ≤ 20 %). `icon.png`
   больше не нужен.
2. **Плитка** (`brand-qr.ts` + `brand-qr-shared.ts`): чёрный блок со скруглением ≈ плашке, тонкая рамка
   (доля ширины), белое окно с кодом и тихой зоной 2 модуля, снизу утолщение — полоса с «Отсканировать»
   белым жирным, кегль по ширине. Без градиента, без «wesetup.ru». Пропорция высота/ширина — постоянная
   (`BRAND_QR_CAPTION_ASPECT`), клиенту — из shared. `caption: false` (наклейка лендинга) — без рамки и
   полосы, знак новый. Вариант `compact` (последний пользователь — Word) — убрать.
3. **Шапка журнала** (`pdf-journal-qr.ts`): в ячейке шапки рамка кода — сами линии ячейки (0,2 мм), плитка
   заполняет ячейку: окно + полоса снизу во всю ширину ячейки, углы прямые (ячейка таблицы). Ширина ячейки
   = окно + линия: окно под модуль 0,365 мм, но не уже 16,7 мм (ячейка как у прежней плитки без роста
   шапки) и не шире 20,1 мм (ячейка 20,3 мм — как у прежней самой плотной плитки); модуль ≥ 0,35 мм →
   предел 53 модуля (как был: токены /qb не меняются). Высота ячейки = окно + полоса + линия ≤ master.
   Страница без шапки / бумажный бланк — отдельная плитка (скруглённый блок с рамкой). `document-pdf.ts` —
   только комментарий у шапки (параллельная задача bwprint).
4. **Word** (`document-docx.ts`): подвал — новая плитка PNG (H, знак, полоса) вместо `compact`; размер —
   модуль ≥ 0,35 мм у самого плотного адреса /qb; отступ подвала — чтобы область текста не уменьшилась
   (страниц не больше).
5. Комментарии (плашка/градиент/две строки/wesetup.ru) и тесты: `brand-qr`, `pdf-journal-qr`,
   `blank-qr-token`, `pdf-journal-sheet`, `journal-order-scans`.
6. **Проверка** (скрипты в папке задачи, декодеры — в `D:/wt-build/verify-bwqr`):
   - распознавание jsQR + zxing-cpp: 150/300 dpi × чистый / ч/б / ч/б-принтер / телефон / ч/б + телефон —
     шапки всех бланков (первая страница + повтор), бумажные бланки, плакат A4/A5, наклейка (самая узкая,
     самый длинный адрес), Word (DOCX → PDF LibreOffice), PNG окон (экран ×1/×2), сертификат;
   - цвет: операторы PDF плитки (rg/RG/k/K, картинки), пиксели PNG, цвета SVG;
   - `check-qr-overlap.ts` (под новую раскладку: окно кода), страницы master → после, ячейка шапки
     master → после;
   - скриншоты: шапка (альбомный), плакат A4, наклейка, диалог QR на сайте, Word.
