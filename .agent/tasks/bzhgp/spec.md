# Spec (frozen 2026-09-30): БЖГП — время подписи бракеражной комиссии по умолчанию = время бракеража + 1 минута

Правка владельца: «сделать в БЖГП по умолчанию время для подписи бракеражной комиссией +1 минута к установленному
времени бракеража».

Ветка `feat/bzhgp-sign-time-2026-09-30`, рабочая копия `d:/wt/bzhgp`, порт 3195, база `wesetup_wt_bzhgp`.

Что уже есть:
- Журнал бракеража готовой продукции (БЖГП) — клиент `src/components/journals/finished-product-document-client.tsx`
  (подпись: «подписал · <время>» из `member.signedAt`, ~стр. 1126).
- Комиссия — `src/app/api/settings/brakerage-commission/[code]/members/*`.
- Печать — `src/lib/document-pdf.ts`, Word — `src/lib/document-docx.ts`.
- Найти все места, где задаётся и показывается время подписи членов комиссии: экран, печать, Word, QR-заполнение,
  мини-приложение, автозаполнение.

## Сделать
- Время подписи члена комиссии в строке журнала по умолчанию = время бракеража этой строки + 1 минута.
  - Пример: бракераж 12:30 → подпись 12:31.
  - Переход через полночь — корректно.
  - Если у строки нет времени бракеража — как сейчас.
- Где время подписи редактируется — это значение подставляется по умолчанию, человек может поменять. Где не
  редактируется — показывать и печатать это значение.
- Реальный момент нажатия «подписать» сохраняется для аудита как есть: лог и журнал действий. Меняем только время,
  которое стоит в журнале.
- Уже подписанные строки — решить и описать в отчёте.
  - Вариант по умолчанию: при показе и печати время подписи = время бракеража + 1 минута, если сохранённое время
    подписи раньше времени бракеража или отстоит от него больше чем на X — выбрать разумное X и обосновать.
  - Иначе оставить как есть.
  - Данные в БД массово не переписывать.
- Логи на ключевых переходах.

## Проверка
- **Юнит:** расчёт +1 минута, полночь, нет времени бракеража, правка вручную.
- **E2E** (390 и 1280): строка с бракеражем 12:30 → подпись комиссии показывает 12:31 на экране, в PDF и Word.
  Скриншоты.
- `npm run typecheck`, `npm test`.

## Критерии приёмки
- AC1: новая подпись комиссии по умолчанию на минуту позже времени бракеража — на экране, в печати и Word.
- AC2: реальное время нажатия есть в аудите; старые записи не испорчены.
