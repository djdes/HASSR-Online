## Решения до кода
- **Секция без карточки.** В `DashboardSection` вместо режима `centered` (он был только у этой секции) — режим
  `flat`: `<details>` без рамки/фона/тени прямо на фоне страницы; строка-заголовок `summary` = название + счётчик
  N/M (бейдж как сейчас) + тихая иконка настройки без квадрата-рамки + шеврон. Иконки в скруглённом квадрате слева
  нет. По умолчанию открыта.
- **Кнопки «Автозаполнить» / «QR-коды» — в содержимое секции**, панелью с поиском: на телефоне кнопки строкой
  (2 колонки), под ними поиск; на компьютере поиск слева, кнопки справа — одна строка. В свёрнутом виде остаётся
  одна строка заголовка. `CloseDayCard` больше не в `summary` — гашение клика (`preventDefault` обёртки) убрать.
- **Запоминание без мигания.** `DashboardSectionPersistScript` остаётся механизмом: ставит сохранённое
  состояние сразу при появлении секции в DOM (MutationObserver — до первой отрисовки, в т.ч. при потоковой
  отдаче), а не на `DOMContentLoaded`. Для перехода на главную внутри приложения (скрипт, вставленный React,
  не исполняется) — маленький клиентский помощник в секции (layout-effect, до отрисовки). `suppressHydrationWarning`
  на `<details>`: состояние меняется до гидратации намеренно.
- **Строка журнала** — без заливки и рамки: превью бланка 4:3 (телефон 64×48, компьютер крупнее) + название до
  2 строк 16px + отметка состояния. Заполнено сегодня — зелёная галочка в круге; нет — пустой кружок (без
  красного). Тонкие линии между строками — одна система. Превью: образцы `public/journal-samples` — через
  `next/image` (сервер отдаёт уменьшенные, на телефоне это ~5 КБ вместо ~40 КБ на строку); живые снимки
  `/api/journal-previews/…` (приватные, с версией в URL) — `unoptimized`. Нет превью — нейтральная заглушка.
- **Три варианта строки** (на время подбора — временный переключатель `?rowv=a|b|c` в `page.tsx`, в коммит не
  идёт): A — галочка-бейдж в углу превью; B — чекбокс слева от превью (чек-лист); C — превью, справа пилюля
  статуса. Скриншоты 390 и 1280, светлая и тёмная; выбранный остаётся в коде, остальные — патчами в папке задачи.
- **Бумажные** — те же строки с превью `paper_<id>` (и на телефоне), вместо отметки — значок принтера, над ними
  тихая подпись «Бумажные журналы» вместо пилюли «Бумажный · распечатать» в каждой строке.
  **Отключённые** (только в результатах поиска) — те же строки, приглушённые, с кнопкой «Включить».
- **Компьютер** — та же секция во всю ширину, строки сеткой: 2 колонки с `md`, 3 с `lg` (превью 80×60).
- Скелет загрузки — под новый вид. Логика (набор, статус, ссылки, автозаполнение, поиск, отключённые) не меняется.
