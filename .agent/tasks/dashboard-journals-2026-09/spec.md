# Spec (frozen 2026-09-27): главная — «Обязательные журналы» во всю ширину, строки с превью журналов

Правка владельца (скрин главной на телефоне): «В дашборде „Обязательные журналы“ сделать во всю ширину, чтобы без
блока-кругляшка и с возможностью свернуть, пусть будет открыто, а то прямоугольник в прямоугольнике и текста много,
только щас понял, что не нравилось. Слева у названий вернуть маленькие прямоугольные скрины журналов с понятным
чекбоксом-галочкой, что тут всё ок. В минималистичном виде. Opus пусть предложит варианты. Бумажный вид так же,
слева фотки в мобильном. На ПК как ты думаешь лучше, так и сделай». Решения оркестратора — ниже.

Сейчас: `src/app/(dashboard)/dashboard/page.tsx` → карточка `DashboardSection`
(`src/components/dashboard/dashboard-section.tsx`: белая скруглённая рамка, слева в заголовке значок в
скруглённом квадрате) → кнопки `CloseDayCard` («Автозаполнить», «QR-коды») → `DashboardJournalsGrid`
(`src/components/dashboard/dashboard-journals-grid.tsx`: поиск «Найти журнал, даже отключённый», строки —
залитые красные/зелёные прямоугольники с иконкой ✓/✕ и стрелкой; ниже бумажные журналы с крупной картинкой
бланка). Скелет — `src/app/(dashboard)/dashboard/loading.tsx`. Превью бланков уже есть:
`public/journal-samples/<код>.webp|png` и `paper_<id>.webp|png` (перерисованы сегодня: серые выходные, ч/б QR).

## Сделать
- Секция «Обязательные журналы» — БЕЗ карточки-обёртки: на фоне страницы, во всю ширину контента, без значка в
  скруглённом квадрате слева от заголовка. Заголовок: «Обязательные журналы» + счётчик (как сейчас «1/3») +
  шеврон; нажатие на строку заголовка сворачивает/разворачивает; по умолчанию РАЗВЁРНУТО; запоминание на
  устройстве — как сейчас (`DashboardSectionPersistScript`), без мигания при загрузке. Кнопки «Автозаполнить» /
  «QR-коды» и поиск — остаются.
- Строка журнала — минималистичная, без залитых цветных прямоугольников и без рамки-в-рамке: слева маленькое
  прямоугольное превью бланка (из `public/journal-samples`, `next/image` или `<img loading="lazy">`, фикс.
  пропорции ~4:3 или 3:4 — выбрать по виду; нет превью — нейтральная заглушка того же размера), на превью или
  рядом — понятная отметка состояния: заполнено сегодня — зелёная галочка в круге; не заполнено — пустой
  кружок/контур (без красной паники; «просрочено» если в данных есть — мягкий акцент). Название — до 2 строк,
  крупно; лишний текст убрать. Тап по строке — как сейчас (переход в журнал). Разделители — тонкие линии или
  отступы, одна система.
- **Варианты**: сделать 3 варианта строки (например: A — галочка-бейдж в углу превью; B — чекбокс слева от
  превью; C — превью + справа статус-пилюля/галочка), снять скриншоты каждого (телефон 390 и компьютер 1280,
  светлая и тёмная тема), выбрать лучший (обосновать в evidence) и оставить его в коде; остальные — только
  скриншоты (+ патчи в папке задачи, чтобы можно было быстро переключить).
- Бумажные журналы (тот же список ниже) — тот же вид строк: на телефоне слева маленькие превью `paper_<id>`
  вместо крупной картинки.
- Компьютер: как лучше (решение оркестратора: та же секция во всю ширину; строки — сетка 2–3 колонки с превью
  чуть крупнее, если так чище; обосновать скриншотами).
- Тёмная тема, скелет загрузки — соответствуют новому виду. Логику (какие журналы обязательные, статус,
  ссылки, автозаполнение, поиск, отключённые) не менять.

## Проверка (обязательно)
- E2E (Playwright, headless, Chromium из `%LOCALAPPDATA%\ms-playwright`) на локальном dev с посеянной
  организацией (обязательные журналы: часть заполнена, часть нет; бумажные журналы): телефон 390×844 (touch) и
  1280×800, светлая и тёмная; сворачивание/разворачивание и запоминание после перезагрузки; тап по строке ведёт
  в журнал; поиск работает; превью грузятся (нет 404). Скриншоты «до/после» и трёх вариантов.
- `npm run typecheck` и `npm test` зелёные; тест на ключевое (секция без карточки, развёрнута по умолчанию,
  у строк есть превью и отметка состояния).

## Критерии приёмки
- AC1: секция без карточки, во всю ширину, сворачивается, по умолчанию открыта, состояние запоминается.
- AC2: строки — превью + понятная галочка, без цветных прямоугольников; бумажные — так же, с превью.
- AC3: 3 варианта со скриншотами, выбран и внедрён один (обоснование); компьютер — решение со скриншотами.
- AC4: e2e, typecheck, тесты зелёные.
