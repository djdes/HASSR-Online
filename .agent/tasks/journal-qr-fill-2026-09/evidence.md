## Круг 5 (2026-09-20): QR-форма переписана на серверный HTML

Причина: на iPhone владельца страница открывалась ~10 с. По логу nginx все файлы React-версии приходили за секунду, но клиентские скрипты (≈300 КБ gz: Next runtime + React + общие чанки) оживляли страницу через 12–19 с; при эмуляции slow-4G — 10 с. Решение: `/journal-fill/[orgId]/[code]/route.ts` отдаёт готовый HTML (~13 КБ, инлайн-стили, без шрифтов и общих чанков), все шаги — ссылки и `<form method="post">`, инлайн-скрипт необязателен. Общее ядро записи `lib/journal-fill-submit.ts` используется и JSON-API.

| Проверка | Результат |
|---|---|
| public с JS (`results-html-public.json`) | хаб 8 журналов; сотрудник → форма → «Отметка записана», PRG (`done=` в адресе), «Сегодня у вас» + «Дальше»; повтор — обновление; бракераж: «Строка добавлена», «Добавить ещё», чипы оценки (4) и времени, температура по блюду (73 + подсказка), отклонение блокируется до комментария, 150 °C отбивает валидатор понятной ошибкой; пустые состояния холодильников/уборки; плакат документа — сразу список сотрудников (8) |
| public без JS (`results-html-public-nojs.json`) | те же шаги ссылками и формами: отметка, повтор, строка бракеража, «Добавить ещё», отклонение блокируется сервером |
| pin (`results-html-pin.json`) | шаг PIN, «Неверный PIN.» при 9999, верный → cookie-пропуск на 15 минут, запись |
| auth (`results-html-auth.json`) | без сессии → `/login?next=…`; с сессией руководителя — «Вы» сверху списка, запись подписана аккаунтом |

## Круг 9 (2026-09-20): значения за сегодня, быстрый ввод по норме, отступы чипов

Запрос владельца по скриншотам HTML-формы холодильников: если за сегодня уже записано — показывать эти значения для правки; под полем кнопки быстрого ввода со «средним по норме»; отступы у чипов отклонения кривые.

Что сделано:
- `getTaskForm` адаптеров получает `todayKey`; холодильники и климат подставляют записанные сегодня значения (своя запись сотрудника важнее чужой; климат — по сроку замера из rowKey) как `defaultValue` и плашку `notice` «Сегодня уже записано: N из M…». QR-маршрут передаёт день организации.
- `lib/quick-values.ts` + `components/qr-fill/quick-values.tsx`: под полем с нормой три кнопки — нижняя, середина, верхняя граница (перевёрнутая норма «-18…-20» упорядочивается); в HTML-форме — `.chips.qv` в карточках объектов и под простыми полями с нормой, подсветка текущего значения при вводе; на `/room-fill` и `/equipment-fill` — те же кнопки под температурой и влажностью.
- `normRange` упорядочивает границы: раньше «норма -18…-20» считала -19 «ниже нормы».
- `/room-fill`, `/equipment-fill`: сегодняшние показания текущего объекта (`values` в `QuickSwitchItem`) подставляются в поля с плашкой «Сегодня уже записано»; текущий чип полосы прокручивается в центр.
- Блок отклонения: чипы с отступом 8px от поля, gap 6px, высота 32px; ± и пилюля центрируются по полю, а не по обёртке с чипами.
