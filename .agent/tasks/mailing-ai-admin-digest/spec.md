# ИИ-сводка администратору в «Рассылке» (2026-11-23)

Запрос: «В рассылках Wesetup создать кампанию с ИИ, которая каждое воскресенье
в 23:59 отправляет администратору с пользователем root полную сводку на почту и
сильно сокращённую — в Telegram и Макс. Включить сведения о рассылках и
продажах, сравнение с прошлой неделей, изменение среднего чека и рекомендации
по его повышению; предусмотреть редактирование шаблона».

## Критерии

- AC1 — В ROOT → «Рассылка» есть вкладка «ИИ-сводка» (только владельцу
  платформы): расписание, каналы, получатели, шаблон, предпросмотр,
  «Отправить сейчас», история.
- AC2 — По умолчанию расписание — воскресенье 23:59 МСК; слот проверяет
  cron `/api/cron/mailing` (раз в минуту), каждый слот уходит не больше одного
  раза, пропущенный дольше 3 ч — не досылается.
- AC3 — Получатели — все активные пользователи `isRoot`: почта — полная
  сводка, Telegram и MAX — короткий текст.
- AC4 — В сводке: продажи (выручка, оплаты, средний чек, тарифы), рассылки
  (кампании, охват, клики, отписки) — против прошлой недели; изменение
  среднего чека и рекомендации по его повышению.
- AC5 — Текст пишет ИИ через очередь диспетчера (`wesetup_admin_weekly_digest`);
  ИИ недоступен — сводка уходит с рекомендациями по правилам и пометкой.
- AC6 — Шаблон редактируется: тема, вступление, разделы, указания ИИ,
  число рекомендаций, короткий текст с переменными; проверка неизвестных
  переменных; «Шаблон по умолчанию».
