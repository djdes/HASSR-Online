# Spec (frozen 2026-11-10): автоподбор ответственного — только руководящая должность, свои люди точки первыми

Тикет 57187T (#fb_cmwb3gzfv0093e0ts5w57187t): «Во многих журналах появляется ответственной мадам Абдулкадирова».
Решение владельца: вариант 3 — свои сотрудники точки по должности, а если подходящей должности нет — никого;
«должность должна быть не рядовой, а руководящей: шеф или заведующий, или хотя бы старший или бригадир».

## Исходное состояние (master dbb2f17a)

- Слот журнала не настроен в «Ответственных за журналы» → при создании документа и каскаде слот подбирается сам
  (`rankRosterForSlot`): должность по ключевым словам слота → первый по алфавиту рядовой сотрудник → руководство.
  В большой организации первым по алфавиту оказывается один и тот же человек — он и встаёт ответственным
  во множество журналов.
- Ростер точки (`loadSlotRoster`) — по алфавиту; сотрудник «без точки» (работает везде) стоит наравне со своими
  людьми точки и при имени на «А» обгоняет их.

## Критерии приёмки

- **AC1. Ответственный и проверяющий — только руководящая должность.** Для главного слота журнала и слотов
  проверяющих автоподбор берёт только руководящую должность, в порядке: (1) шеф / заведующий / управляющий /
  руководитель / директор / начальник либо категория или роль руководства; (2) старший / бригадир. Внутри ступени
  первым идёт тот, чья должность подходит по ключевым словам слота. Никого руководящего нет — слот пустой
  («не назначен»), первого по алфавиту не ставим.
- **AC2. Остальные слоты исполнителей — только по должности слота.** Подходящей должности нет — слот пустой.
- **AC3. Свои люди точки первыми.** В ростере точки сотрудники, у которых эта точка указана, идут раньше тех, кто
  «работает везде»; порядок внутри групп прежний (по имени).
- **AC4. Не задето остальное.** Явный выбор в диалоге, сохранённые слоты, выбор по должности из диалога,
  `rankRosterForSlot` у прочих вызовов — без изменений. Уже созданные документы код не меняет.
- **AC5. Проверки.** `npm run typecheck`, `npm run test:gate` — без новых падений; unit-тесты на AC1–AC3.

## Вне задачи

- Исправление уже созданных документов (нужны настройки ответственных или правка данных).
- Легенда «С1/С2» журнала холодильников.

## Дополнение (2026-11-10, после слов владельца «проверь похожие проблемы и исправь по той же логике»)

Проверка всего кода нашла ту же ошибку вне каскада. Добавлены критерии:

- **AC6. Общий выбор по роли.** `pickPrimaryManager` / `pickPrimaryStaff` без подходящей роли возвращают null, а не
  первого по списку; «первый» остаётся только там, где без человека нельзя технически (автор записи датчика,
  преемник задач при увольнении) — явным флагом.
- **AC7. Построители журналов.** Уборка: исполнитель по умолчанию не угадывается, контроль — только руководство.
  Приёмка: ответственный по умолчанию — только руководящая должность. Металлопримеси: без «первого сотрудника».
  Акт забраковки: комиссия по умолчанию — руководство, а не первые двое по списку. План аудитов: второй аудитор —
  не «следующий по имени». Скан-журналы: кнопка «Создать» не выдаёт угаданного человека за выбор пользователя.
  Мойка оборудования: контролёр новой строки — только руководящая должность.

Не менялось (осознанно): подстановка первого сотрудника ПОСЛЕ того, как человек сам выбрал должность в окне;
демо-организации; автозаполнение без ответственного — как и раньше, пропускает документ («no-responsible»).
