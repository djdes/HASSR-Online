# nav-shell-2026-10 — новое меню кабинета (сайдбар из 9 разделов)

Задача ProjectsFlow 3931776f. Дизайн, согласованный с владельцем:
`docs/superpowers/specs/2026-10-16-cabinet-sidebar-nav-design.md`.
План реализации: `docs/superpowers/plans/2026-10-16-cabinet-sidebar-nav.md`.

## Критерии приёмки

- **AC1. Модель навигации.** `src/lib/app-nav.ts` описывает 9 разделов в порядке схемы
  (Моя компания, Сотрудники, Торговые точки, Журналы, Чек-листы, Производственный контроль,
  Оплата, Остальное, Пришла проверка). Каждая страница `src/app/(dashboard)/**/page.tsx`
  относится ровно к одному разделу (`sectionForPath`). Правила доступа вкладок повторяют
  guard'ы страниц и proxy. Покрыто `src/lib/app-nav.test.ts`.
- **AC2. Видимость по ролям.** Управляющая/владелец/root видят 9 разделов. Заведующая
  (head_chef) — без «Моей компании». Повар/уборщица — 0–1 раздел, сайдбара нет.
  Verify-only (повар с пресетом head_chef) видит «Журналы», «Сотрудники», «Пришла проверка».
- **AC3. Каркас.** На ≥1024px слева сайдбар 256px: логотип компании (или монограмма),
  8 пунктов, «Пришла проверка» прижата к низу. В шапке по центру текущая точка
  (с переключателем при ≥2 точках), справа знак WeSetup, колокольчик, выход, аватар.
  Hover-меню, шестерёнка, пилюли заведующей и строка вкладок точек убраны.
- **AC4. Вкладки.** На корневых страницах раздела с ≥2 видимыми вкладками — строка вкладок;
  на глубоких страницах — крошки, первая крошка = раздел. Никогда не вместе.
- **AC5. Телефон.** Меньше 1024px — бургер, лист снизу: точки → разделы → «Выйти».
  На 390px нет горизонтального скролла страницы.
- **AC6. Хаб `/settings`** редиректит по роли (admin.full → `/settings/organization`,
  tasks.verify → `/control-board`, иначе `/journals`). Все 51 бывшая карточка доступна
  внутри своего раздела (вкладка или карточка «Настройки»/«Остальное»). Покрыто
  `src/lib/settings-cards.test.ts`.
- **AC7. Новые страницы.** `/inspection` (QR на экране + печать, ZIP за период,
  готовность для admin.full, «Кто смотрел»), `/production-control` (слоты ППК и
  ХАССП-плана: загрузить/открыть/заменить/заказать), `/more` (сетка карточек с алертами),
  `/settings/sections/{journals,staff,points}`, `/settings/staff-health`.
- **AC8. Логотип** загружается файлом (PNG/JPG/SVG, SVG санитизируется) и показывается
  в сайдбаре; удаление возвращает монограмму.
- **AC9. Журналы с сайдбаром.** Полноширинная подложка `journals/[code]` и панель выделения
  начинаются от края сайдбара; при печати отступа нет.
- **AC10. «Сегодня».** `/dashboard` без вкладок точек, карточек-ссылок и «Разделы и
  настройка»; виджеты переехали по таблице дизайна.
- **AC11. Mini App (П-3).** `/mini/sections` строится из той же модели: 9 групп для
  управляющей, меньше для заведующей.
- **AC12. i18n и WhatsNew.** Новые ключи есть во всех каталогах ru/en/uz
  (`npm run i18n:check` зелёный); в `whats-new-notes.ts` категория «Новое меню кабинета».
- **AC13. Проверки.** `npm run typecheck`, `npm run lint` (без новых ошибок),
  `npm run test:gate`, сборка — зелёные. E2E-сценарии из дизайна пройдены на e2e-БД,
  скриншоты в `raw/`.
