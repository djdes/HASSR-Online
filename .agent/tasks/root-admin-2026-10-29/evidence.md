## Найдено по ходу

- Вход выдаёт сессию своим кодом (`issue-session.ts`), без jwt-callback NextAuth, и токен не обновляется сам
  (`refetchInterval=0`). Поэтому разделы кладутся в токен при входе, а ссылка «Панель платформы» идёт через
  `/api/me/platform-panel`, который обновляет токен из БД. `requireRoot()` всегда сверяет разделы с БД.
- Проверка SMTP-сервера по имени была недостаточной: имя может указывать на 127.0.0.1 (а это локальный почтовый
  relay сервера). Теперь имя разрешается заранее, внутренние адреса отклоняются, подключение — к проверенному IP
  с `tls.servername`.
