# Spec: быстрый репорт о проблеме («жучок»)

Status: FROZEN (2026-10-24)

## Запрос владельца
Авторизованный пользователь быстро сообщает о проблеме: справа у края окна
(телефон и ПК) маленький ярлык с иконкой жука. Нажатие — на ПК всплывающее
окно, на телефоне стандартный лист снизу. В окне закреплён скриншот текущей
страницы, можно добавить ещё файлы и написать текст. Отправка — письмо
пользователю и админу «тикет создан», админу в Telegram скриншот и текст.

## Scope
Переиспользуем существующее: `/api/feedback` (FeedbackReport, after()-доставка),
`/api/support/attachments` (подписанные вложения), `useAttachmentUploads`,
`Dialog`, `BottomSheet`, `useIsNarrowViewport`.

## Acceptance criteria
- AC1: В `(dashboard)/layout.tsx` для любого авторизованного пользователя
  смонтирован ярлык: фиксирован у правого края окна, иконка `Bug`, порталится
  в `document.body`, скрыт при печати, имеет aria-label.
- AC2: По нажатию снимается скриншот видимой области страницы
  (`modern-screenshot`), сам ярлык в снимок не попадает. Снимок загружается как
  вложение и показан в форме превью с пометкой «скриншот страницы»; его можно
  убрать. Если снять не удалось — форма всё равно открывается, с подсказкой.
- AC3: На узком экране форма — `BottomSheet` (лист снизу), на широком — `Dialog`.
- AC4: В форме можно добавить файлы (кнопка + Ctrl+V) и ввести текст;
  отправка недоступна, пока файлы грузятся или текст короче 3 символов.
- AC5: Форма шлёт `POST /api/feedback` с `type: "bug"`, текстом, вложениями
  и `pageUrl`. Сервер принимает необязательный `pageUrl` (только тот же
  origin/относительный путь, ≤ 2000), хранит его в `FeedbackReport.pageUrl`
  (nullable) и показывает в письме и Telegram админу.
- AC6: После создания тикета пользователю (если есть email) уходит письмо
  «Обращение #… принято» с текстом обращения; ответ API содержит номер тикета,
  тост показывает его. Отправка письма — в `after()`, ошибки не роняют запрос.
- AC7: Админу в Telegram: текст обращения (как раньше) + скриншот фото с
  подписью, содержащей номер тикета и начало текста (≤ 1024 символа подписи).
- AC8: Строки UI в ru/en/uz каталогах, типы i18n регенерированы
  (`npm run i18n:check` проходит).
- AC9: `npm run typecheck` и `npm run test:gate` проходят; новые чистые функции
  (нормализация pageUrl, подпись Telegram, номер тикета) покрыты unit-тестами.

## Out of scope
Изменение существующей формы в SupportWidget/FeedbackDialog; mini app.
