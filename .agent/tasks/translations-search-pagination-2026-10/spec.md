# Переводы: пагинация, глобальный поиск, телефон (2026-10-24)

## Запрос владельца

> в https://wesetup.ru/translations сократить страницу до 100 и сделать
> пагинацию, добавить глобальный поиск по переводам на всех языках, вводим и
> отображает список совпадений, при клике показывает варианты переводов с
> возможностью изменений, сейчас в телефоне по клику не отображается ничего.
> перепроверь, на телефоне должно быть удобно и переделай

## Что сломано сейчас (воспроизведено, iPhone 13, 390×844)

- Список разделов (~150 кнопок) стоит над строками: на телефоне строки
  начинаются на ~31 500 px. Нажатие на раздел грузит строки, но экран не
  меняется — «ничего не отображается».
- Строки шире экрана (682 px при ширине 390) — горизонтальная прокрутка.
- «Показать ещё» дописывает строки к уже показанным: страница растёт без
  предела.
- Поиск ищет только в выбранном разделе.

## Решения

- Страница — ровно 100 строк. Пагинация: «‹ Назад», номера страниц с
  многоточием (на телефоне — «N из M»), «Вперёд ›». Смена страницы
  прокручивает к началу списка.
- Глобальный поиск — одно поле над редактором. Пока в нём есть текст,
  ищем по всему каталогу (раздел не учитывается) в ключе и в текстах
  ru/en/uz, с учётом правок. Регистр, «ё/е» и варианты апострофа
  узбекской латиницы (ʻ ʼ ‘ ’ `) не важны. Порядок — сначала точное
  совпадение, потом начало строки, начало слова, ключ, вхождение. У
  результата — бейдж раздела, совпадение подсвечено.
- Список — компактные строки-кнопки (ключ, бейджи состояния, тексты трёх
  языков в 2–3 строки). Клик открывает окно строки: все три языка
  полями ввода, «Автоперевод», «Вернуть исходный», «Сохранить»,
  переход к предыдущей/следующей строке страницы. На телефоне окно —
  лист снизу во всю ширину, кнопки сохранения всегда на виду.
- На телефоне вместо колонки разделов — кнопка «Раздел: …», открывающая
  лист со списком разделов и поиском по ним. Колонка разделов на
  компьютере (lg+) остаётся.
- Черновики, автоперевод пачкой и «Сохранить всё» работают как раньше;
  строка с черновиком показывает черновой текст и бейдж «Не сохранено».
- Фильтры «Все / Изменённые / Без перевода» действуют и в поиске.

## Вне объёма

- Изменение прав доступа, API автоперевода, схема БД.
- Поиск по каталогам `pricing/`, `errors/`, `confirm/` (их нет в редакторе).

## Критерии приёмки

- AC1. API `GET /api/translations` отдаёт не больше `limit` (по умолчанию
  100) строк и `total`; клиент запрашивает страницы по 100 через
  `offset`; страница N показывает строки `(N-1)*100+1 … N*100`, а не
  накапливает их.
- AC2. Поиск: без раздела ищет по всем разделам; совпадение в ключе, ru,
  en или uz (с правками); регистронезависимо, «ё»=«е», апострофы
  узбекской латиницы равны `'`; точные совпадения раньше вхождений;
  у строки есть `category`. Unit-тесты на нормализацию и ранжирование.
- AC3. Пагинация: чистая функция окна страниц (1 … 4 5 6 … 20) с
  unit-тестом; кнопки «Назад/Вперёд» блокируются на краях; при смене
  фильтра, раздела или запроса — первая страница.
- AC4. Клик по строке (результат поиска или строка раздела) открывает
  окно с ru/en/uz; правка сохраняется, сброс и автоперевод доступны;
  «следующая/предыдущая» переходят по строкам страницы.
- AC5. Телефон (390×844): нет горизонтальной прокрутки; выбор раздела —
  через лист; после выбора раздела строки видны в первом экране; клик по
  строке открывает лист со всеми тремя языками и видимой кнопкой
  «Сохранить»; правка сохраняется.
- AC6. Тексты UI — в каталогах ru/en/uz (`translationEditor`), типы
  `i18n:types` перегенерированы штатно.
- AC7. `npm run typecheck`, `npm run test:gate`, `npm run i18n:check`
  (часть про типы), eslint по изменённым файлам — зелёные.
- AC8. Сквозная проверка на локальной БД (Playwright, телефон и
  компьютер): поиск находит строку по en/uz тексту, правка через окно
  сохраняется и сбрасывается, пагинация показывает 100 строк и
  переключает страницы. Скриншоты в `raw/`.
