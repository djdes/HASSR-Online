## Критерии приёмки

- **AC1. Ролики медцентра и отеля.** Плеер QR принимает набор глав. Медцентр — УФ-лампа,
  холодильник, «Забыли?»; отель — раздевалка (допуск перед сменой), холодильник, датчики,
  «Забыли?». Кухонной главы (фритюр) в них нет. Вкладки «Медцентр» и «Отель» показывают свой
  ролик с главами, стрелками и «Попробуйте сами» (только примеры своих глав); плашки
  «В разработке» больше нет. Ролик общепита — как был (6 глав, 0:48).
- **AC2. Сравнение тарифов** на главной свёрнуто по умолчанию: кнопка «Сравнить тарифы»
  раскрывает таблицу; содержимое таблицы остаётся в HTML. На /pricing и в кабинете — как было.
- **AC3. FAQ** на главной — 6 вопросов (возврат, приложение и пароль, забыли заполнить,
  подделка записи, нет интернета, безопасность данных); убранные ключи удалены из словарей,
  разметка FAQPage — те же 6 вопросов.
- **AC4. Подвал** на телефоне (< 640 px): группы ссылок свёрнуты и раскрываются по нажатию
  на заголовок; ссылки остаются в HTML; с 640 px — всё открыто, как раньше.
- **AC5. Тёмная тема** главной проверена снимками (телефон и ПК); найденные перекрашенные
  места исправлены.
- **AC6. Рамка телефона** в «Кабинете руководителя»: «чёлка» не закрывает шапку снимка.
- **AC7. Git-хуки** `.husky/pre-commit` и `.husky/pre-push` исполняемые в git (mode 100755).
- **AC8. `npm run screens:landing`** — одна команда съёмки снимков кабинета на локальной
  демо-базе; отказывается работать с нелокальной базой; описана в `screens.md`.
- **AC9.** Строка «Не хотите разбираться сами? Покажем за 15 минут» — в словарях ru/en/uz.
- **AC10.** Счётчик на странице QR-кодов в кабинете проверен; если это ошибка — исправлен.
- **AC11.** `npm run i18n:types`, `npm run typecheck`, `npm run test:gate` зелёные; изменения
  в `master`, деплой прошёл.
