Продолжение `.agent/tasks/setup-helper-app-2026-10` (версия 1.0.0 уже на проде,
PR djdes/HASSR-Online#25).

## Почему 1.0.0 может не находить принтер (разбор кода)

1. **Принтер без имени скрыт.** Классический поиск Android часто отдаёт
   устройство без имени (имя приходит позже отдельным запросом или не
   приходит вовсе), а список по умолчанию прячет устройства без имени.
   Принтер с непрочитанным именем виден только после галочки «Показывать
   устройства без имени».
2. **Похожесть на принтер — только по имени.** Класс устройства Bluetooth
   (Imaging/Printer, `EXTRA_CLASS`) не учитывается.
3. **Короткий поиск.** 15 секунд, классический поиск (~12 с) не
   перезапускается; имена многих устройств не успевают прочитаться.
4. **Ограничение BLE-поиска.** Android 7+ молча (без `onScanFailed`) не
   выдаёт результаты, если приложение запускало BLE-поиск больше 5 раз за
   30 секунд. Каждый показ экрана и «Искать снова» перезапускали BLE-поиск.
5. **`startDiscovery()` сразу после включения Bluetooth** может вернуть
   `false` — повтора не было.
6. **Нет запасного пути.** Если поиск не видит принтер (прошивка телефона,
   принтер «занят» другим телефоном), подсказки и перехода в системные
   настройки Bluetooth для ручного сопряжения нет.
7. **Ошибки подключения одинаковые** — «Принтер не ответил…» и для неверного
   PIN, и для принтера, занятого другим телефоном.

## Как работает самообновление на Android (источник — исходники Android 16, `PackageInstaller.SessionParams#setRequireUserAction`)

- Обновление без участия человека возможно, если у приложения есть
  разрешение «Установка неизвестных приложений» (`REQUEST_INSTALL_PACKAGES`),
  сессия помечена `USER_ACTION_NOT_REQUIRED`, приложение объявляет
  `UPDATE_PACKAGES_WITHOUT_USER_ACTION` (уровень normal), обновляет **само
  себя**, а новая версия нацелена на свежий API (у нас targetSdk 36) —
  работает с Android 12 (API 31).
- На Android 7–11 система всегда показывает окно подтверждения; приложение
  может только скачать обновление заранее и предложить установить в один тап.
- `PendingIntent` для результата установки — изменяемый (`FLAG_MUTABLE`),
  иначе при targetSdk 35+ `commit` бросает исключение.
- Обновление ставится поверх, только если подписано тем же ключом и номер
  сборки больше. 1.0.0 подписан ключом `CN=WeSetup Setup Helper (test)`
  (SHA-256 сертификата `e67c22a2…ce2a`) — 1.1.0 подписывается им же.

## Решения

- **Проверка версии — через сайт.** Сервер отдаёт `GET /api/setup-helper/version`
  из файла `resources/setup-helper/version.json`, который пишет вместе с APK
  задача Gradle `publishRelease`. Приложение сравнивает `versionCode`.
- **Когда проверяем:** при открытии (не чаще раза в 30 минут), при появлении
  сети и фоновым заданием JobScheduler раз в 6 часов с условием «есть сеть»
  (`setPersisted` — переживает перезагрузку). Без сети ничего не
  запрашивается: задание само ждёт сети — «откладывать».
- **Скачивание** — в фоне, в память приложения, с проверкой размера и SHA-256
  из `version.json`; при несовпадении файл удаляется, повтор — позже.
- **Установка** — `PackageInstaller`, без сторонних библиотек. На Android 12+
  с разрешением — сама, когда приложение не на экране и не печатает (сразу,
  если свёрнуто; иначе — как только свернут). Иначе — плашка на главном
  экране «Установить» или «Разрешить автообновление».
- **Ключ подписи** в репозиторий не кладётся (репозиторий публичный).
  Сборка принимает ключ из переменных окружения (путь или base64);
  `publishRelease` отказывается публиковать APK, подписанный другим
  сертификатом. Ключ передаётся владельцу лично (чат), хранение — в README.
- **Шаблоны** остаются JSON в assets. Поле-текст получает варианты
  (`options` — подсказки с ручным вводом), дата — режим «только дата»
  (`dateOnly`).

## Критерии приёмки

- **AC1. Поиск принтера.**
  - Похожесть на принтер учитывает класс устройства Bluetooth: основной
    класс Imaging — «похоже на принтер», Imaging/Printer — выше; список
    имён расширен (BT-принтеры, этикеточные модели).
  - Устройство без имени показывается по умолчанию, если оно похоже на
    принтер по классу или сопряжено; остальные безымянные — под кнопкой
    «Показать все устройства (ещё N)».
  - Поиск идёт 40 секунд: классический поиск перезапускается по
    `ACTION_DISCOVERY_FINISHED` (до 3 кругов), `startDiscovery() == false`
    повторяется до 3 раз через 1,5 с; BLE-поиск не перезапускается чаще
    раза в 6 секунд (не больше 4 запусков за 30 секунд — не попадаем под
    ограничение Android).
  - Если поиск закончился без похожих на принтер устройств — карточка
    помощи: чек-лист (принтер включён, рядом, не подключён к другому
    телефону/компьютеру и не открыт в другом приложении, перезагрузить
    принтер), кнопки «Искать снова», «Показать все устройства», «Настройки
    Bluetooth» (ручное сопряжение; сопряжённые устройства подхватываются при
    возврате); на Android 12+ при выключенной геолокации — строка «на
    некоторых телефонах поиск работает только с геолокацией».
  - Ошибки подключения различаются: сопряжение отклонено/не завершено (PIN
    0000/1234), принтер не отвечает или занят (выключить-включить, отключить
    на другом телефоне), с кнопкой «Настройки Bluetooth».
  - Тесты: классификация (`PrinterNamesTest`), ограничитель BLE
    (`ScanThrottleTest`), экран поиска на Robolectric (безымянный принтер
    виден, карточка помощи после поиска без принтеров).
- **AC2. Шаблоны для пищевого производства.** Новые шаблоны: «Полуфабрикат»,
  «Готовое блюдо», «Разморозка», «Заморозка», «Суточная проба» (хранить
  48 ч при +2…+6 °C), «Приёмка сырья», «Аллергены», «Брак — не
  использовать». Поля: продукт/блюдо, даты с умолчанием «сейчас», сроки с
  вариантами, условия хранения и прочее с вариантами, ответственный — из
  входа. Поле-текст с `options`, дата с `dateOnly`; разбор шаблона проверяет
  варианты по типу поля. Каждый шаблон помещается на 58×40, 58×30, 40×30
  (`LabelPreviewTest`) и рисуется Android Canvas (`ScreensTest`). Порядок:
  пробная, маркировка продукта, шаблоны производства, вскрытая упаковка,
  произвольный текст.
- **AC3. Сервер: версия приложения.** `resources/setup-helper/version.json`
  (`versionCode`, `versionName`, `sha256`, `size`, `publishedAt`, `notes`);
  `GET /api/setup-helper/version` без входа, `Cache-Control: no-cache`,
  отдаёт манифест и абсолютный `downloadUrl`; без файла или с битым файлом —
  503. Разбор манифеста — чистая функция с тестами; тест репозитория:
  `version.json` совпадает с APK (размер, SHA-256). Сайт: у кнопки
  скачивания — номер версии; у телефона со старой версией — пометка, что
  приложение обновится само. Строки ru/en/uz.
- **AC4. Автообновление.** Проверка при открытии (не чаще 30 мин), при
  появлении сети и заданием JobScheduler (6 ч, нужна сеть, переживает
  перезагрузку); без сети — ни одного запроса. Новее — скачать в фоне,
  проверить размер и SHA-256, поставить через `PackageInstaller`:
  Android 12+ с разрешением — без участия человека, когда приложение не на
  экране и не печатает; иначе — плашка на главном экране («Установить»,
  «Разрешить автообновление» → системная настройка). Ошибки скачивания и
  установки — с паузой (1 ч → 4 ч → 12 ч), без бесконечного цикла; текст
  ошибки виден в плашке. После обновления — одно сообщение «Приложение
  обновлено до X». В меню — «Проверить обновления» и номер версии.
  Тесты: правила обновления и разбор манифеста (JVM), задание JobScheduler
  с условием сети и `persisted`, без сети — нет запроса, плашка, параметры
  сессии установки (`USER_ACTION_NOT_REQUIRED` на API 31+).
- **AC5. Выпуск 1.1.0.** `versionCode` 2, `versionName` 1.1.0; APK подписан
  тем же сертификатом, что 1.0.0 (проверка `apksigner`); `publishRelease`
  собирает release, проверяет сертификат, кладёт APK в
  `resources/setup-helper/` и пишет `version.json`; без ключа подписи —
  отказ. Ключ — из `SETUP_HELPER_KEYSTORE` или `SETUP_HELPER_KEYSTORE_BASE64`.
- **AC6. Проверки.** `npm run typecheck`, `npm run test:gate`,
  `npm run i18n:check`, eslint изменённых файлов, Gradle-тесты, lint
  (0 ошибок), `assembleRelease`; сквозная проверка на локальном сервере:
  `/api/setup-helper/version` и скачанный APK совпадает с манифестом,
  прежний сценарий API проходит. Схема БД не меняется.
- **AC7. Документация.** README приложения: почему принтер может не
  находиться и что делать, список шаблонов и их поля, как работает
  автообновление и его ограничения по версиям Android, выпуск новой
  версии, хранение ключа подписи. В PR — что меняет деплой.

## Вне рамок

- Обновление без подтверждения на Android 7–11 (запрещено системой).
- Push-уведомления, Google Play, редактор шаблонов на сайте.
- Проверка на живом принтере и телефоне (в контейнере нет Bluetooth).
