# Spec (frozen 2026-11-23): офис — не объект, «Выберите объект», скрепка, страница офиса, меню-список, избранное звёздочкой

## Запрос владельца (2026-11-23, два скриншота)

1. Сверху убрать «Организация · Офис», писать просто «Выберите объект».
2. Страница офиса (`/settings/organization/office`): показывать директора, руководителя — тех, кто меняет
   журналы и т. д. Кнопка «Показать всех сотрудников объектов» ведёт на страницу правки всех, где видно, кто к
   какому объекту привязан. Так же — по объектам и оборудованию.
3. Офис — не объект. В офисе при создании журнала его обязательно привязать к объекту, оттуда — ссылка
   «Создать объект».
4. Журнал, уже созданный в офисе без объекта, привязать к единственному или первому по списку объекту.
5. Ручная смена объекта — без оповещения о смене и возможности вернуться.
6. В списке объектов — скрепка: закреплённый встаёт первым.
7. Верхнее меню (3-й уровень): нажатие на «Журналы» не уводит в «Сегодня», а открывает выпадающее меню.
8. При наведении на любое меню — звёздочка: добавить/убрать в «Избранное» на главной. У левого меню — правая
   кнопка мыши, там тоже «В избранное».
9. Скриншот 1: QR в окне «Редактирование оборудования» журнала — «Объект не найден» + «Повторить».
   Скриншот 2: в «Зачем нужны цеха» красной линией перечёркнут пункт «Группировка оборудования».

Ответы владельца в этой сессии:
- «Все объекты» не делать. По умолчанию — «Выберите объект»; по нажатию выпадающий список; если выбирать
  нечего — ссылка «Создать объект». Объект создан, но не выбран — «Выберите объект». Переход в офис или в пункт
  меню без объекта — сверху «Выберите объект». Попали в журналы и туда, где есть объект, — сверху сам, без
  оповещений, включается единственный объект или тот, что был выбран до перехода.
- Остальное — «делай как понял» (предложения исполнителя ниже приняты).

## Исходное состояние (master `6f95d7c6a`)

- Шапка (`lib/header-point.ts`, `components/layout/current-point-switcher.tsx`): офис — первый пункт списка с
  подписью «Организация»; без офиса — виртуальный пункт «Вся организация». Один объект в разделах всей компании
  скрыт; объектов нет — ссылка «+ Добавить объект».
- Смена объекта (`location-switcher.tsx`, `point-section-sync.tsx`, `switch-toast.tsx`): и ручная, и
  автоматическая смена показывают тост «Объект: …» с кнопкой «Вернуться на «…»». Раздел компании переключает на
  офис; уход из него возвращает точку (localStorage `wesetup.point-return`) — тоже с тостом.
- Страница «Офис»: «Сотрудники офиса» — только `buildingIds ∋ офис`; «Журналы офиса» — «Сегодня» на офисе;
  «Объекты компании» — карточки.
- Документы: в офисе `POST /api/journal-documents` создаёт документ на офис (без офиса «вся организация» уже
  требует объект); `buildingTargets` (автосоздание, раздача) включает офис.
- `SectionTopMenu`: у пункта с вложенными название — ссылка в раздел, стрелка — список (решение 2026-11-23).
- «Избранное»: 3 слота на главной, выбор из окна; кандидаты — пункты меню без вложенных разделов и корни
  разделов без меню.
- QR в окне оборудования журнала: строка журнала ссылается на единицу справочника (`sourceEquipmentId`); если её
  нет — `GET /api/qr-fill/equipment/<id>` отвечает 404 «Объект не найден», «Повторить» бесполезен.
- «Зачем нужны цеха» (`/settings/areas`): четыре пункта, третий — «Группировка оборудования».

## Решения исполнителя (владелец может поправить)

- Уровень организации (офис или «вся организация») в данных остаётся как был (cookie, контекст) — меняется
  только показ: «Выберите объект». Офиса и «вся организация» в списке нет. Режим «объектов несколько, журналы
  общие» («Объекты · Все: N») не меняется: выбирать там нечего.
- Один объект: в разделах всей компании — «Выберите объект» (в списке — этот объект), в остальных — его
  название.
- Без оповещений — все смены объекта (ручные и автоматические). Тост смены организации не трогаем.
- Автовыбор: главная, мастер нового объекта и страница объекта — нейтральны (страница объекта сама ставит свой
  объект, как раньше). Явный фильтр `?place=` сильнее автовыбора.
- Создание журнала при «Выберите объект»: общее окно «Создание документа» получает обязательное поле «Объект»
  со ссылкой «Создать объект»; над списком документов журнала — плашка выбора объекта; сервер без объекта
  отвечает понятной ошибкой, которую показывают и остальные окна создания.
- Перенос документов офиса — разовый скрипт на деплое (`PlatformSetting`-ключ), как починка фирменного стиля
  2026-11-21: «первый по списку» = порядок объектов организации (`sortOrder`, название). Переносятся электронные
  и бумажные журналы. Обязательства (ежедневные задачи) не трогаем — они пересобираются сами.
- Скрепка — личная (у каждого свой список), хранится в аккаунте (`User.pinnedBuildingIds`, новая колонка с
  `[]` по умолчанию); закреплённых может быть несколько — первыми в порядке закрепления.
- Страница офиса: «Руководство» = люди офиса + руководство всей компании (роль или должность руководства и без
  закрепления за объектами). «Показать всех сотрудников объектов» → `/settings/users?place=all`, где у
  каждого видна пилюля места работы, нажатие — правка сотрудника («Где работает»). «Показать всё оборудование
  объектов» → `/settings/equipment?place=all` (там уже группы по объектам и правка).
- Верхняя строка: весь пункт с вложенными — одна кнопка списка; корень раздела — первой строкой списка.
- «Избранное» — до 7 страниц (было 3); кандидаты — любой пункт меню человека: корни разделов, пункты, вкладки
  пунктов. Звёздочки — только при наведении мышью (на телефоне их нет), у тех, у кого есть главная.
- «Группировка оборудования» убирается из подсказки (красная линия на скриншоте).

## Критерии приёмки

- **AC1. «Выберите объект» в шапке.** В списке объектов шапки (меню на компьютере, лист на телефоне) нет офиса,
  «Вся организация» и «Все объекты». Выбран уровень организации — на кнопке «Выберите объект» без подписи
  «Организация»; нажатие открывает список объектов. Объектов нет, а человек может их заводить — «Выберите
  объект», в списке «Объектов пока нет» и ссылка «Создать объект» (`/settings/buildings/new`). Один объект — в
  разделах всей компании «Выберите объект», в остальных — его название. Внизу списка у руководителя — «Создать
  объект» и «Настроить объекты». Тесты `header-point`.
- **AC2. Смена объекта без оповещений.** Ручной выбор объекта (компьютер и телефон) и автоматические смены
  (раздел компании, возврат объекта, страница объекта, фильтр `?place=`) не показывают тост «Объект: …» /
  «Вернуться на …»; ошибка смены — тост ошибки, как раньше; тост смены организации не меняется.
- **AC3. Автовыбор объекта.** Раздел или страница всей компании (офис, «Моя компания», подписки, настройки,
  список объектов, «Все журналы», «Журналы точек») — шапка сама встаёт на «Выберите объект», запомнив
  выбранный объект. Другая страница кабинета (журналы, «Сегодня», сотрудники, цеха, оборудование…), кроме
  главной, мастера нового объекта и страницы объекта, при «Выберите объект» тихо включает запомненный объект,
  иначе — единственный; объектов ≥2 и ничего не запомнено — остаётся «Выберите объект». `?place=` сильнее
  автовыбора. Тесты `point-section-sync`.
- **AC4. Журнал создаётся на объекте.** При «Выберите объект» `POST /api/journal-documents` без объекта — 400
  `{ code: "point_required" }`; `buildingId` офиса — 400; объект — документ на нём. Общее окно «Создание
  документа» при «Выберите объект» — обязательное поле «Объект» со ссылкой «Создать объект», без выбора
  создать нельзя, выбранный объект уходит в запрос. Над списком документов журнала — плашка «Документ журнала
  создаётся для объекта» с кнопками объектов (тихий выбор в шапке) и «Создать объект». Окна со своим разбором
  ответа (`readCreatedDocument`) на `point_required` пишут «Выберите объект…», а не «Не удалось создать
  документ».
- **AC5. Журналы офиса — на объекты; на офис больше не создаются.** Разовый скрипт
  `prisma/seed-office-journals-to-points-2026-11.ts` (`--dry-run`, ключ `once:office-journals-to-points:v1`)
  переводит `JournalDocument` и `PaperJournalDocument` с `buildingId` офиса на единственный объект
  организации, при нескольких — на первый (`sortOrder`, название); без объектов — не трогает; пишет журнал
  действий; подключён в деплое с `|| warn`. `buildingTargets` при делении по объектам не возвращает офис
  (автосоздание и раздача — только объекты). Тесты выбора объекта и целей.
- **AC6. Скрепка.** У каждого объекта в списке шапки (компьютер и телефон) и в списке «Объекты»
  (`/settings/buildings`) — закрепить/открепить; закреплённые первыми (в порядке закрепления) и отмечены;
  личное: `User.pinnedBuildingIds`, `POST /api/me/pinned-buildings` (объект чужой организации или офис —
  404/400). Тесты сортировки и разбора запроса.
- **AC7. Страница «Офис».** Блок «Руководство» (люди офиса + руководство всей компании, с должностью) с кнопками
  «Добавить сотрудника в офис» и «Показать всех сотрудников объектов» (`/settings/users?place=all`); блок
  «Журналы ведутся на объектах» — кнопки объектов (открывают журналы объекта) и «Создать объект»; блок
  «Объекты» — как был + «Показать все объекты»; блок «Оборудование объектов» — сколько единиц на каждом
  объекте и «Показать всё оборудование объектов» (`/settings/equipment?place=all`).
- **AC8. Сотрудник и его объект.** В организации с делением по объектам в списке сотрудников у каждого —
  пилюля места работы («Офис», название объекта или объектов, «Все объекты» — без закрепления); нажатие
  открывает правку сотрудника («Где работает»).
- **AC9. Верхняя строка — список.** Пункт с вложенными (Сотрудники, Журналы, ППК…) — одна кнопка: нажатие на
  название или стрелку открывает список (компьютер — панель, телефон — лист снизу), перехода нет; первой
  строкой — сам раздел, если его корня нет среди пунктов.
- **AC10. Избранное звёздочкой.** Наведение на пункт меню (левое меню: разделы и пункты; строка сверху и её
  панели; дерево «Новой» темы) показывает звёздочку: пустая — добавить, закрашенная — убрать; правый клик по
  пункту левого меню — «Добавить в избранное» / «Убрать из избранного» и «Открыть в новой вкладке». Только у
  тех, у кого есть главная; на телефоне звёздочек нет. До 7 страниц, кандидаты — любой пункт меню (корни
  разделов, пункты, вкладки); восьмая — тост с подсказкой убрать одну. Главная — до 7 карточек (компьютер —
  второй ряд; телефон — по 3 в ряд), пустой слот «Добавить» — пока их меньше 7. Тесты `home-page`.
- **AC11. QR оборудования.** Нет связанной единицы справочника — понятный текст «Этого оборудования нет в
  справочнике — нажмите «Сохранить», строка снова получит QR-код» без «Повторить»; «Сохранить» связывает строку
  заново и показывает QR. Ошибки QR — по виду («Оборудование не найдено», «Помещение не найдено», «Документ не
  найден»), без «Объект не найден».
- **AC12. «Зачем нужны цеха»** — три пункта, без «Группировки оборудования».
- **AC13. Проверки.** Тексты — ru/en/uz, `npm run i18n:types`; `npm run typecheck`; `npm run test:gate`
  (схема меняется — полный прогон); `npm run i18n:check`; eslint по изменённым файлам — без новых ошибок;
  стражи дизайна зелёные (`borderless`, `palette:neutral` пересобраны при необходимости); локальный стенд —
  скриншоты шапки, офиса, меню, звёздочек и главной (компьютер и телефон).
