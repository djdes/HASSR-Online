Спецификация: `spec.md` (frozen 2026-11-10, с разделом «Уточнения к спецификации»).
Проверено на локальной production-сборке (`next build --webpack` + `next start`), PostgreSQL 16, демо-организация
`prisma/seed-haccp-demo.ts`, Chromium (Playwright, профиль Pixel 7). Сеть выключалась `context.setOffline(true)`.

Android в среде нет; это проверка владельца (AC19, раздел «Что проверить на планшете»).**

## Что не проверено

- **Настоящий Android-планшет**: запуск APK в авиарежиме, работа service worker внутри WebView, передача ссылки
  от системной камеры. В браузере мост приложения имитировался (`window.Capacitor`).
- **Ежедневная уборка (`cleaning`)** — в демо нет помещений и уборщиков (уточнение 7).
- **Помещения (климат)** — в демо-организации нет помещений; форма и запись используют тот же путь, что
  оборудование, но в браузере не открывались.
- Сервер из нескольких процессов: блокировка слияния — в памяти одного процесса.

## Что проверить на планшете (владелец)

1. Поставить APK, открыть с интернетом, войти. Профиль → строка «Готово к работе без связи».
2. Закрыть приложение, включить авиарежим, открыть — должен появиться экран «Работаем без связи».
3. «Сканировать QR» → наклейка холодильника → выбрать себя → температура → «Сохранено на устройстве».
4. Камерой планшета навести на ту же наклейку (у отладочной сборки сначала: Настройки → Приложения → WeSetup →
   «Открывать по умолчанию» → «Добавить ссылку» → wesetup.ru).
5. Сотрудник с ПИН: неверный ПИН — отказ, верный — форма.
6. Выключить авиарежим → записи уходят; в журнале они стоят со временем, когда сделаны.
