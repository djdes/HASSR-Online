## Решения

- Р1. Окно: заголовок и пояснение прежние; ниже две кнопки во всю ширину столбиком. Сверху — яркая
  основная «Не переходить» (фокус на ней, закрывает окно), снизу — серая неброская «Всё равно перейти»
  (открывает документ в новой вкладке, как прежняя «Да»). Ключи `openYes` / `openNo` остаются, меняются
  тексты: ru «Всё равно перейти» / «Не переходить», en «Open anyway» / «Don't open», uz «Baribir ochish» /
  «Ochmaslik». Работает для обоих документов (оферта, согласие).
- Р2. Строка: «**14 дней** всё бесплатно (до ДД.ММ.ГГГГ). Подробнее» — число дней из `TRIAL_DAYS` с
  правильной формой слова, дата в скобках обычным начертанием. «Далее только 1 журнал» из строки уходит:
  с ним строка не помещается в одну на телефоне, а условия после пробного периода — по «Подробнее»
  (тарифы). Размер шрифта на телефоне подстраивается под ширину, чтобы строка шла одной строкой
  от 360 px.
- Р3. Печать — отдельный SVG-компонент без картинок и шрифтов извне: зубчатый золотой край, двойное
  кольцо, по центру крупно «ХАССП», под ним «СЕРТИФИЦИРОВАНО», лавровые ветви, звёзды, две красные
  ленты снизу. Надписи — из словарей (ru «ХАССП» / «СЕРТИФИЦИРОВАНО», en «HACCP» / «CERTIFIED»,
  uz «HACCP» / «SERTIFIKATLANGAN»); ширина надписей зажата `textLength`, поэтому они не вылезают за
  кольцо ни при каком системном шрифте. Анимация: печать «ставится» при появлении плашки, по ней раз в
  несколько секунд проходит блик, вспыхивает искра. При «Уменьшить движение» и «Без анимации» — без
  анимации. Цвета печати не зависят от темы (ночная, «Новая»).

## Критерии приёмки

- **AC1. Окно «Открыть …?».** Две кнопки во всю ширину столбиком: сверху яркая «Не переходить»
  (`legal-open-no`, автофокус, закрывает окно), снизу серая «Всё равно перейти» (`legal-open-yes`,
  открывает `/oferta` или `/consent` в новой вкладке и закрывает окно). В ночной теме серая кнопка
  тёмная (классы с ночным соответствием).
- **AC2. Строка про пробный период.** На главной под формой: «14 дней всё бесплатно (до <сегодня по
  Москве + 14>). Подробнее», «Подробнее» ведёт к тарифам. На телефоне 360, 375, 390 и 430 px — одна
  строка по центру, без горизонтальной прокрутки; на ПК — одна строка.
- **AC3. Золотая печать.** Вместо синего значка у «Разработан при консультации…» — золотая печать
  «ХАССП / СЕРТИФИЦИРОВАНО» с лентами, заметно крупнее прежнего значка; надписи внутри кольца;
  плашка не ломается на 360 px и на ПК, в светлой и ночной теме.
- **AC4. Анимация.** Печать анимирована (появление, блик, искра); при `prefers-reduced-motion: reduce`
  и `html[data-view-still]` анимации нет.
- **AC5. Переводы.** Все новые и изменённые тексты — в `ru`, `en`, `uz`; `npm run i18n:types` выполнен;
  на en/uz-главной нет кириллицы в печати.
- **AC6. Проверки.** `npm run typecheck`, `npm run test:changed` (или `test:gate`), `npm run lint` по
  изменённым файлам — зелёные; `src/app/neutral-palette.test.ts` не устарел.

## Не входит

- Полная форма согласия (`variant="full"`) — там окна нет.
- Блок тарифов и тексты «Подробнее» про бесплатный тариф.
