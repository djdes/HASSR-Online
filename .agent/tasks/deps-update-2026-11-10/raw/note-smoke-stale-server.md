# Поправка к проверке шага 4а

Боевой проход шагов 4а и 4б (первый запуск) шёл по старому процессу `next-server`, запущенному для эталона:
скрипт останавливал `next start`, а Next переименовывает процесс в `next-server`, и новая сборка не могла занять порт
(EADDRINUSE в step4a-start.log / step4b-start.log). Типы, тесты, линтер и `next build` шагов проверены по-настоящему;
деплой 4а на сервере прошёл свою проверку после перезапуска.

Исправлено: сервер гасится по порту (`fuser -k 3100/tcp`), после запуска проверяется, что CSS новой сборки отдаётся.
Повторный проход на настоящей сборке шага 4б (в ней есть и всё из 4а) совпал с эталоном: step4b-smoke.tsv.
