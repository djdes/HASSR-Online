# Площадки Меркурия → точки; пауза напоминаний Max по точке (2026-11-01)

Решение владельца 2026-11-01 (п. 3 «и т. д.»). PR #90 нашёл: `MercuryEnterprise`
никто не создаёт и не сопоставляет — у ВСД нет точки, приёмка берёт точку из шапки.
Max: одна отметка последнего напоминания на организацию — руководитель точки А на
30 минут блокирует руководителя точки Б.

## Критерии приёмки

- AC1. Настройки Меркурия: площадки можно добавить вручную (GUID площадки,
  необязательный GUID места деятельности, название, адрес, точка), выбрать точку
  («Не сопоставлена» — общий журнал), включить/выключить опрос, удалить
  (ConfirmDialog; ВСД и история гашения остаются).
- AC2. «Загрузить из Меркурия» ставит в очередь заявку `getActivityLocationList`
  по ГУИД хозяйствующего субъекта; ответ (крон очереди) создаёт новые площадки без
  точки и выключенными, у знакомых обновляет название и адрес (точку и опрос не трогает).
- AC3. Выбрали точку площадке без точки — опрос включается сам (явный выбор важнее).
- AC4. Смена точки площадки переносит туда же её ещё не погашенные ВСД
  (`new`, `acknowledged`, `process_failed`, `irrelevant`); погашенные и гасящиеся
  остаются на своей точке — и при повторной синхронизации тоже.
- AC5. API `/api/integrations/mercury/enterprises` (POST), `/[id]` (PATCH, DELETE),
  `/load` (POST): руководство всей компании и тариф с «Меркурием»; руководителю точки — 403.
- AC6. Max: пауза 30 минут — своя у области руководителя (точка / несколько точек /
  «org»), `lastReminderByPoint`; `lastReminderAt` обновляется для совместимости; без
  карты действует старая общая отметка. Решение под блокировкой строки.
- AC7. Тесты правил; typecheck 0 ошибок.
