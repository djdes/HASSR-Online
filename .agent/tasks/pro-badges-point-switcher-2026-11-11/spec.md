# Метки PRO и переключатель точек на всех страницах (2026-11-11)

Запрос владельца: (1) метки PRO у всех разделов максимального тарифа (мастер-кабинет, ППК и т. д.);
(2) переключатель точек в шапке не должен пропадать (например, на «Сотрудниках»); тост смены точки — всегда
короткий, с отсчётом и «вернуться», и не загораживает переключатель.

## Acceptance criteria
- AC1: Раздел «Программа производственного контроля» помечен PRO в меню (сайдбар, строка над страницей и её панели); карточки «Меркурий» и «Подключение Меркурия» на «Ещё» — тоже. Мастер-кабинет — как был.
- AC2: На `/settings/users`, `/settings/areas`, `/settings/equipment`, `/journals/points` переключатель (`kind: switch`) в шапке виден.
- AC3: Без `?place=` фильтр «Где работает» стоит на точке из шапки; офис/«Вся организация» в шапке — «Все».
- AC4: Выбор точки в фильтре переключает шапку на неё; «Все»/офис — на всю организацию; выбор в шапке на вкладке с `?place=` сбрасывает фильтр (без петли).
- AC5: Ручная смена точки показывает короткий тост с кольцом-отсчётом и кнопкой «Вернуться на „…“»; автосмены — тот же вид.
- AC6: Тосты кабинета — под шапкой и по центру колонки контента (не закрывают переключатель).
- AC7: `npm run typecheck` не даёт новых ошибок; `npm run test:changed` зелёный.
