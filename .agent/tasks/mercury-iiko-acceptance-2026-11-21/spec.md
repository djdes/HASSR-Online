«Сделай все кроме 6,7» — пункт 4 («Меркурий до конца: гашение ВСД прямо в журнале приёмки, площадки из

## Что уже есть (разбор, docs/MERCURY.md отстал от кода)

- Меркурий, стадия 0: модели, клиент, мок-шлюз, кроны, экран «Входящие ВСД» (`/mercury`) с оформлением приёмки
  (`POST /api/mercury/documents/[id]/process`: физконтроль → строка журнала входного контроля + гашение в очередь).
- Площадки «Цербера»: «Загрузить площадки из Меркурия», выбор точки и опрос у каждой площадки, ручное добавление —
  в `/settings/integrations/mercury` уже есть (в «Что ещё не сделано» записано устаревшее).
- iiko (iikoServer): накладные → «Входящие» (`/edo`) → «Принять» в журнал приёмки; списания → «Потери»; товары →
  справочник. Но в самом журнале приёмки пункт «Из iiko» — заглушка «обратитесь к разработчикам».
- Прослеживаемость `/journals/traceability/[key]` читает только `JournalEntry`; у ВСД (`MercuryVetDocument.batchKey`,
  строка журнала) и партий (`Batch.code`) — свои записи.
- Стадия 1 (тестовый контур Меркурия) требует тестовых ключей владельца — вне этой задачи.

## Решения

- Р1. Журнал приёмки: если у организации включён Меркурий и он есть в тарифе — полоса «В Меркурии N ВСД ждут
  приёмки (M просрочено)» с кнопкой «Оформить» и пункт «ВСД из Меркурия» в меню «Добавить» → `/mercury`.
  Счёт — как на `/mercury`: статусы `new`/`acknowledged` на точке документа (и общие).
- Р2. Пункт «Из iiko»: подключён iiko — «Накладные из iiko приходят во „Входящие“: откройте и нажмите „Принять“»
  с кнопкой во «Входящие»; не подключён — «Подключите iiko» с кнопкой в настройки интеграции.
- Р3. Прослеживаемость партии: кроме записей журналов — «Приёмка по ВСД» (дата, продукт, объём, поставщик, номер
  ВСД, ссылка на журнал приёмки) и «Партия» (продукт, поставщик, количество, дата, статус) по тому же ключу.
- Р4. docs/MERCURY.md — актуальный список «Что ещё не сделано».

## Критерии приёмки

- **AC1.** Подсказка Меркурия: нет интеграции, выключена или нет в тарифе — `null`; иначе счёт ожидающих и
  просроченных на точке документа (тест на фильтре). Полоса и пункт меню только при подсказке; пусто — без полосы.
- **AC2.** Пункт «Из iiko» ведёт во «Входящие» или в настройки iiko по факту подключения; текста «обратитесь к
  разработчикам» больше нет (тест текстов ru/en/uz).
- **AC3.** Прослеживаемость показывает ВСД и партию по ключу (только своей организации), ссылка на журнал приёмки —
  по коду шаблона документа (тест на чистой функции ссылок/строк).
- **AC4.** Тексты — ru/en/uz, `npm run i18n:types`; docs/MERCURY.md обновлён.
- **AC5.** typecheck, test:changed, eslint, палитра — зелёные.
