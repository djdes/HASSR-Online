# Spec (frozen 2026-09-25): мастер-кабинет v2 — бракераж на дату во все пищеблоки, удобное время, переименование

Отзыв заказчика (гимназия, 2 пищеблока): «В МК должен быть такой же интерфейс загрузки блюд, как в БЖГП конкретной школы, только "размножаться" на все подключённые пищеблоки. Составил, нажал "Сохранить и разослать" — в БЖГП школ ничего не появилось. Нужно обязательно указывать дату, на которую выгружается бракераж. [В БЖГП «Добавить изделия списком»] тут прекрасно всё сделано. Неудобно вносить время — нужно ставить двоеточие; хорошо бы на весь список сразу; пикер на всех устройствах с подсказкой "проставить всем ниже". Этот МК назвал бы "Мастер-кабинет Школы".»

Почему «ничего не появилось»: мастер рассылает справочник (список изделий документа + подсказки), а не строки журнала. Нужны строки.

## 1. «Бракераж на дату» — строки во все пищеблоки
- В `/master` (вкладка «Меню → БЖГП») — главная кнопка **«Добавить в журналы на дату»** (справочник меню остаётся — он для подсказок).
- Окно — ТО ЖЕ, что «Добавить изделия списком» в БЖГП пищеблока (`src/components/journals/finished-product-document-client.tsx` ~L780–870 + `src/lib/finished-product-bulk.ts`): таблица «Наименование | Выход», вставка из Excel, общие поля для всех изделий — дата и время изготовления (**дата выбирается**), органолептическая оценка и остальные общие поля этого окна. Вынести окно в общий компонент и использовать и в БЖГП, и в мастер-кабинете (без поломки БЖГП). Кнопка «Взять меню» заполняет таблицу справочником мастера (названия, выход, время).
- По «Добавить в N пищеблоков»: для каждой организации пула — найти документ БЖГП, покрывающий выбранную дату (если нет — создать тем же путём, что создаются документы журнала, с настройками по умолчанию и засевом), и добавить строки ровно так, как их добавило бы окно «Добавить списком» этого пищеблока (время бракеража/разрешения — по константам времени документа пищеблока). Повторное нажатие не дублирует: та же позиция с тем же временем изготовления в документе уже есть — пропустить. Итог: «Добавлено N строк в M пищеблоках» + по каждому пищеблоку (сколько, пропущено, ошибки). Запись под `withDocumentConfigLock`, `AuditLog`.
- Предпросмотр перед отправкой: сколько строк в какой пищеблок.

## 2. Удобное время (и в таблице меню мастера, и в новом окне)
- Ввод цифрами без двоеточия: «0800», «800», «8» → «08:00»; «0830»/«830» → «08:30» (при уходе с поля). Подсказка про формат ЧЧ:ММ больше не нужна как ошибка для таких вводов.
- Выбор времени (пикер) на всех устройствах; у строки действие «Проставить всем ниже» (это время — всем строкам ниже); поле «Время для всех строк».

## 3. Название мастер-кабинета
- Сейчас имя собирается при создании: `Мастер-кабинет — <организация>` (`src/lib/master-cabinet.ts`). Дать переименование: в шапке `/master` (иконка-карандаш у названия, для пользователей кабинета) и в `/settings/master-cabinet` (владелец). `AuditLog`. (Переименование кабинета гимназии в «Мастер-кабинет Школы» сделает оркестратор на проде после выката — не в коде.)

## Критерии приёмки
- AC1: из `/master` строки меню на выбранную дату попадают в БЖГП всех пищеблоков пула (в существующий документ периода или в новый), с временем бракеража/разрешения по настройкам каждого; повтор не дублирует; итог по пищеблокам.
- AC2: окно в мастер-кабинете то же, что «Добавить изделия списком» в БЖГП; в БЖГП пищеблока окно работает как раньше.
- AC3: время вводится цифрами без двоеточия, есть пикер и «проставить всем ниже»/«для всех».
- AC4: мастер-кабинет переименовывается (шапка и настройки), аудит.
- AC5: typecheck, `npm test`, прежние e2e мастер-кабинета и новый e2e зелёные; скриншоты 1440 и 390.
