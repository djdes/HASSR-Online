## Что сделано
- **Общее окно «Добавить изделия списком»** — `src/components/journals/finished-product-bulk-dialog.tsx`
  (`FinishedProductBulkTable` + `FinishedProductBulkDialog`): таблица «Наименование | Выход [| Время]», вставка из
  Excel в ячейку, «Ещё строка», «Будет добавлено: N», блок «Общие для всех изделий», кнопки. БЖГП пищеблока
  (`finished-product-document-client.tsx`) теперь рисует окно через него (общие поля — те же `rowFields`, новый флаг
  `bare`), колонки времени у пищеблока нет — поведение прежнее. Мастер-кабинет использует тот же компонент.
- **«Добавить в журналы на дату»** (`/master`, вкладка «Меню → БЖГП»): карточка с главной кнопкой над справочником меню;
  окно `src/components/master/master-brakerage-dialog.tsx` — «Взять меню» (названия, выход, время мастера),
  дата изготовления (выбирается), «Время для всех строк» + «Проставить всем строкам», своё время у строки,
  органолептика («Как в журнале пищеблока» по умолчанию или стандартная оценка), разрешение к реализации,
  T° и примечание (ложатся, только если колонка у пищеблока видна). Кнопка «Добавить в N пищеблоков» → предпросмотр
  по пищеблокам (сколько добавится, сколько уже есть, «создадим новый документ», ошибки) → запись → итог по каждому
  пищеблоку + тост «Добавлено N строк в M пищеблоках».
- **Сервер**: `POST /api/master/brakerage` (`dryRun` — предпросмотр), `src/lib/master-brakerage.ts` (по пищеблокам пула:
  активный документ, покрывающий дату, иначе `ensureActiveDocument` — тот же путь создания, что у журналов: период,
  ответственные, засев, списки мастера; сданный период / выключенный журнал — ошибка по пищеблоку; запись под
  `withDocumentConfigLock`; пустая строка-заготовка нового документа убирается; наименования — в подсказки пищеблока),
  чистая часть `src/lib/master-brakerage-plan.ts` (строки как у окна пищеблока: цепочка бракеража/разрешения по
  `timeDefaults` документа, ответственный/проверяющий документа, при комиссии ФИО проверяющего не подставляется;
  дубль = то же наименование без регистра + та же дата-время изготовления → пропуск). AuditLog:
  `master_brakerage.added` у мастера, `master_brakerage.received` у каждого пищеблока, куда легли строки; `console.info`.
- **Удобное время** — `src/components/journals/time-entry-field.tsx` (`TimeEntryField`): цифры без двоеточия
  (`normalizeTypedTime`: «0800»/«800»/«8» → 08:00, «0830»/«830» → 08:30, «1230» → 12:30) при уходе с поля / Enter;
  кнопка-часы — пикер часов и минут (popover, одинаково на телефоне и компьютере); «Проставить всем ниже» (кнопка у поля
  и в пикере); `fillTimeBelow` / `setTimeForAll` не трогают строки без наименования. Подключено в окне мастера и в
  таблице меню мастера (`master-menu-table-dialog.tsx`: + поле «Время для всех строк» / «Проставить всем»;
  ошибка ЧЧ:ММ — только для действительно непонятного времени). Разбор файлов/вставки остался строгим (`normalizeMenuTime`).
- **Переименование кабинета**: `renameMasterCabinet` / `normalizeMasterCabinetName` (`src/lib/master-cabinet.ts`),
  `PATCH /api/master/cabinet` (сотрудник кабинета, карандаш в шапке `/master`) и `PATCH /api/settings/master-cabinet`
  (руководитель пищеблока, карандаш у названия в `/settings/master-cabinet`); окно — `promptAsync`
  (`src/components/master/rename-master-cabinet.ts`); AuditLog `master_cabinet.renamed` (из настроек — и у пищеблока,
  и у кабинета). Схема БД не менялась.
