# «Открытая кухня»: публичная страница по сферам и табличка для зала (2026-10-31)

Заморожено 31.10.2026. Запрос владельца — из списка 20 идей: «сделай … 7 (специально для сфер) … 18».

- № 7 «Страница для родителей»: QR → меню на сегодня с отметкой бракеражной комиссии; «специально для сфер» —
  свой адресат и своё содержание у каждой сферы (родители, гости, пациенты, покупатели, посетители, клиенты).
- № 18 «Знак чистой кухни»: бейдж с QR для зала и сайта, страница с показателями дисциплины без внутренних
  деталей.

## Что уже есть
Публичный бейдж (`src/lib/badge/*`, `/b/<код>`, `/b/<код>/badge.svg`, карточка в «Реквизитах»): SVG «ХАССП ·
WeSetup | N% за 30 дней», код для вставки на сайт, страница с процентом. Включается организацией явно.

## Решение
1. **Блок «Сегодня» на `/b/<код>`** — по сфере организации (`Organization.type`):
   - адресат и заголовок: школа/детсад — «Родителям: питание сегодня», медицина — «Пациентам и родственникам»,
     общепит и отель — «Гостям: кухня сегодня», магазин — «Покупателям», производство — «Покупателям и
     партнёрам», фитнес — «Посетителям», салон — «Клиентам»;
   - отметки по журналам сферы за сегодня и вчера: «осмотр персонала», «температура в холодильниках»,
     «уборка», «суточные пробы», «С-витаминизация», «вода в бассейне», «стерилизация инструментов» и т. п. —
     только журналы, которые организация реально ведёт (есть действующий документ на сегодня);
   - школа/детсад, медицина, столовая, кейтеринг: **список блюд сегодняшнего бракеража** — название, выход,
     время бракеража, оценка, «разрешено к выдаче»; у остальных сфер — только число проверенных блюд;
   - обезличено: ни имён, ни подписей, ни должностей, ни содержимого записей, кроме названия блюда и оценки.
2. **Отдельное согласие**: `Organization.badgeTodayEnabled` (по умолчанию выключено). У уже включённых бейджей
   страница не меняется, пока руководитель сам не включит «Сегодня» — в карточке бейджа, с описанием того, что
   именно увидят по его сфере.
3. **Точки**: если журналы ведутся по точкам и точек 2+, у каждой точки своя страница `/b/<код>?point=<id>`
   с её отметками и блюдами; на общей странице — список точек со ссылками.
4. **Табличка для зала** (№ 18): печатный лист A4 в фирменной рамке — заголовок по сфере («Питание под
   контролем», «Кухня под контролем»…), название организации или точки, крупный QR на страницу, короткое
   пояснение. Открывается из карточки бейджа, точку можно выбрать.

## Критерии приёмки
- **AC1** — чистая функция по сфере выдаёт адресата, заголовок, набор отметок и режим блюд (список/число) для
  всех 16 сфер; тест.
- **AC2** — `/b/<код>` при включённом «Сегодня» показывает отметки за сегодня и вчера только по ведущимся
  журналам и блюда бракеража за сегодня (школа — список); при выключенном — страница как раньше.
- **AC3** — точки: `?point=` показывает отметки и блюда точки; чужая или неизвестная точка — 404; на общей
  странице сети — список точек.
- **AC4** — на странице нет имён, должностей и подписей; есть пояснение, что страница обезличена.
- **AC5** — карточка бейджа: переключатель «Сегодня» с описанием по сфере, ссылка на табличку; права — как у
  бейджа (руководство).
- **AC6** — табличка A4: заголовок по сфере, название, QR на нужную страницу (с точкой), печать в PDF на один
  лист.
- **AC7** — `npm run typecheck`, `npm run test:gate`, `eslint` по изменённым файлам, `npm run i18n:check` —
  зелёные.
- **AC8** — скриншоты: страница школы с блюдами, кафе, общая страница сети, табличка, карточка настроек.

## Вне задачи
Цикличное меню и фото блюд (данных нет), изменение самого SVG-бейджа, уведомления.
