База: `origin/master` 9e810e8. Локально: Postgres 16 (`wesetup_dev`, `prisma db push`), демо-организация,
фикстуры `raw/seed-open-kitchen.ts` (сфера «Школа / Детсад / Лагерь», сеть из 13 точек, у точки `loc-p01`

«Секретно И. И.», оно не должно попасть на страницу).

`buildTodayView`; хранение по журналам (`TODAY_STORAGE`: записи, матрица уборки, строки бракеража, строки
реестров). `src/lib/badge/today.test.ts` — 7 тестов (все сферы, только ведущиеся журналы, блюда по времени,
без имён проверяющих, вчера/сегодня, уборка, реестры) — pass.

## AC3 — точки
`raw/public-network-390.png`: общая страница сети — «Выберите свою точку», 13 точек с адресами (офис не
входит). `?point=loc-p01` — шапка с названием и адресом точки, отметки и блюда точки, ссылка «Все точки».
`?point=unknown-point` → 404 (`raw/pages-school.json` → `unknownPoint: 404`). Точка ищется только среди
зданий этой организации (`getBadgePoints` по `organizationId`).

## AC4 — обезличено
`leaks: false` на всех страницах (поиск «Секретно», «Иванова», «inspector» в тексте страницы). В блюдах —
только название, выход, время, оценка и допуск (`brakerageDishesOn`). Пояснение «Страница обезличена…»
внизу; про названия блюд — только в режиме списка.

## AC5 — карточка бейджа
`raw/settings-badge-card.png`, `raw/pages-school.json → card`: переключатель «Блок «Сегодня» на странице»
(`aria-checked=true`), описание по сфере («Родителям: «Питание сегодня»…»), что именно увидят (6 пунктов),
пояснение про страницы точек; «Табличка для зала» с выбором точки (13 + «Вся организация») и ссылкой
`/settings/organization/badge-sign?point=loc-p01`. API `PATCH /api/settings/badge { todayEnabled }` —
та же проверка `hasFullWorkspaceAccess`, запись в журнал аудита `badge.today.enable/disable`, сброс кеша.
