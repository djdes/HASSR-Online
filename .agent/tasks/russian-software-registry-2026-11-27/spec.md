# Spec: Подготовка сайта WeSetup (wesetup.ru) к включению в Единый реестр российских программ для ЭВМ и баз данных Минцифры России

## Context
Для подачи заявления через Госуслуги на включение программного комплекса **«WeSetup»** (правообладатель — **ООО «БФС»**, ИНН `5018215599`, КПП `501801001`, ОГРН `1235000105306`) в Единый реестр российских программ для ЭВМ и баз данных Минцифры России (`reestr.digital.gov.ru`) в соответствии с Постановлением Правительства РФ от 16.11.2015 № 1236 (п. 5, п. 11(1) Правил) и методическими рекомендациями ФГБУ «ЦКИТ»:
1. На официальном сайте правообладателя (`https://wesetup.ru`) должна быть опубликована страница продукта с круглосуточным открытым доступом (без регистрации, авторизации, оплаты и сбора персональных данных) ко всем обязательным сведениям и 4 комплектам эксплуатационной и технической документации в формате PDF.
2. С публичных страниц сайта должны быть убраны противоречия в тарифах между офертой и прайс-листом, реклама иностранных заблокированных в РФ ИИ-сервисов (`ChatGPT`, `Claude`, `claude.ai`) и привязка к зарубежному облаку `Tuya`, а также лишняя карточка Google Play из текста публичной оферты и агентского договора.

## Acceptance Criteria

- **AC1 (Публичная страница продукта для Реестра российского ПО — `/reestr-po`):**
  - Маршрут `https://wesetup.ru/reestr-po` открывается 24/7 без авторизации и без форм ввода персональных данных, разрешён в `robots.txt` и включён в `sitemap.ts` и индекс поиска по сайту.
  - Содержит все обязательные сведения, проверяемые экспертами Минцифры / ЦКИТ:
    1. Наименование ПО («Программный комплекс ведения электронных журналов санитарного контроля (СанПиН) и системы ХАССП „WeSetup“»), коды классов ПО по классификатору Минцифры России (`05.05`, `05.13`, `04.11`) и коды ОКПД 2 (`62.01.29.000`, `63.11.13.000`).
    2. Полные реквизиты правообладателя ООО «БФС» (ИНН `5018215599`, КПП `501801001`, ОГРН `1235000105306`, адрес: `141065, Московская область, г. Королёв, ул. Ленина, д. 10/6`, контакты `+7 (495) 109-65-43`, `admin@wesetup.ru`), заявление о принадлежности ООО «БФС» исключительных прав на ПО на территории всего мира и на весь срок действия исключительного права.
    3. Сведения о стоимости ПО и порядке её расчёта (бесплатный тариф, тарифы «Стандарт», «Премиум», «ВИП» помесячно и за год, скидки на сеть объектов, прямая ссылка на `/pricing` и `/oferta`).
    4. Описание функциональных характеристик, архитектуры, технологического стека (TypeScript, Node.js, React, Next.js, СУБД PostgreSQL, размещение серверов в РФ в г. Москве), системных требований и совместимости с российскими ОС из Реестра Минцифры (РЕД ОС, Astra Linux, Альт Сервер / Альт Рабочая станция) и браузерами (Яндекс Браузер, Chromium).
    5. Прямые ссылки (скачивание в один клик без регистрации) на 4 обязательных документа в формате PDF и сведения о технической поддержке и жизненном цикле.

- **AC2 (Четыре обязательных PDF-документа по п. 11(1) «ж» Правил ПП РФ № 1236 с подписью и печатью ООО «БФС»):**
  - `GET /reestr-po/functional-characteristics.pdf` — Описание функциональных характеристик ПО «WeSetup» (шифр `БФС-РПО-01`).
  - `GET /reestr-po/installation-guide.pdf` — Информация, необходимая для установки и эксплуатации ПО (Руководство по установке, развёртыванию и администрированию «WeSetup», шифр `БФС-РПО-02`).
  - `GET /reestr-po/user-manual.pdf` — Руководство пользователя (инструкция по эксплуатации) ПО «WeSetup» (шифр `БФС-РПО-03`).
  - `GET /reestr-po/lifecycle-and-support.pdf` — Описание процессов, обеспечивающих поддержание жизненного цикла ПО «WeSetup» (шифр `БФС-РПО-04`).

- **AC3 (Очистка сайта от лишних/рискованных формулировок и синхронизация правовых страниц):**
  - В `src/app/developers/page.tsx` убрана реклама иностранных санкционных ИИ-сервисов (`ChatGPT`, `Claude`, `claude.ai`, `Cursor`) — раздел переведён на нейтральное описание открытого протокола MCP для корпоративных и локальных ИИ-ассистентов.
  - В `src/app/oferta/page.tsx` добавлен п. 2.6 об исключительных правах ООО «БФС» и ссылке на `/reestr-po`, синхронизированы п. 4.2 и 4.3 с актуальной тарифной сеткой `/pricing` (14 дней пробного периода, затем 1 точка / 1 сотрудник / 1 журнал, платные тарифы «Стандарт», «Премиум», «ВИП» по точкам), а в реквизитах `/oferta` и `/partner-agreement` отключён показ посторонней карточки Google Play (`showGooglePlayAuth={false}`).
  - В `src/content/journal-info.ts` убраны упоминания иностранного облака `Tuya` и несуществующего «Расширенного тарифа».
  - В подвале публичных страниц (`PublicFooter`), на страницах `/about` и `/security` добавлены ссылки на `/reestr-po`.

- **AC4 (Проверки и тесты):**
  - `npm run i18n:types`, `npm run typecheck`, `npm run test:changed` проходят без ошибок.
