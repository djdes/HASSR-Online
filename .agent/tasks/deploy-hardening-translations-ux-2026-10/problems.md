# Найдено при проверке и исправлено

Свои находки по ходу:
1. `format.dateTime` в истории без часового пояса — next-intl ругался
   `ENVIRONMENT_FALLBACK` (в dev — «1 Issue»). Исправлено: история рисуется
   только в браузере, время — в поясе того, кто смотрит.
2. Подсказка про клавиши выталкивала кнопки подвала окна строки на вторую
   строку на компьютере — перенесена под кнопки.
3. Тест скриптов: синхронный запуск блокировал заглушку сервера в том же
   процессе; прокси окружения ломали curl к 127.0.0.1. Тест асинхронный,
   прокси для дочернего процесса убраны.
4. Тип окружения для дочернего процесса (в проекте `ProcessEnv` требует
   `NODE_ENV`) — typecheck падал только на тесте; исправлено.

Независимое ревью (субагент) — всё исправлено:
5. «Остановить» выбрасывал уже переведённую пачку, если нажали во время
   запроса. Теперь пачка применяется, остановка — после неё. e2e: после
   остановки черновиков столько же, сколько строк ушло в перевод.
6. Окно строки открывалось снова после закрытия: (а) «Сохранить и далее»
   двигался из старого замыкания, даже если окно уже закрыли; (б) закрытие во
   время перехода на соседнюю страницу не отменяло «открыть первую строку».
   Теперь движение — только если открыта та же строка (ref), закрытие
   сбрасывает отложенное открытие. e2e: окно закрыли во время перехода —
   осталось закрытым.
7. Ctrl/⌘+Enter обходил защиту от повторного сохранения (у кнопки она есть).
8. «Далее» был активен для строки, открытой по ссылке не со своей страницы
   (идти некуда). Теперь листание только для строк страницы.
9. «Push» в историю оставался взведённым, если клик ничего не менял (тот же
   раздел, та же страница), и доставался следующему вводу в поиске.
10. Проверка после рестарта могла идти до ~22 минут при зависших адресах —
    дольше таймаута SSH-шага (15 мин), и откат бы не успел. Теперь общее
    время ограничено `POST_DEPLOY_MAX_SECONDS` (180 с), таймаут адресов —
    15 с; тест на ограничение.
11. Откат после переустановки зависимостей мог поднять старую сборку на
    новых пакетах. Шаг 1 ставит метку `.deps-changed`; при ней шаг 3 откат
    пропускает с понятной причиной (прежняя сборка остаётся в
    `.next-previous` для ручного разбора).
12. На проде прежняя версия захватывается короткой (7 символов), а тест
    отката проверял полный SHA. Тест приведён к реальному случаю.
