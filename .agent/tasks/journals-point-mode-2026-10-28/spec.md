# «Журналы» по выбранной точке и «Вся организация» в шапке

Дата: 2026-10-28. Ветка `feat/journals-point-mode` от `origin/master` 83bffc75.
Источник — сообщение владельца со скриншотом «Журналы точек»:

> По этому разделу, сверху выбрали точку, и должен быть вход как в «Сегодня», т. е.
> пропадать доступ к «Журналы точек» и «Все журналы». Слева в меню должно быть
> «Настройка», снизу наборы журналов. Т. е. слева меню становится меньше, и если мы
> находимся в недоступном разделе — писать ошибку и кнопку «Назад». Руководящее звено,
> заведующая точки, которая авторизовалась, видит как с выбранной точкой.

Решение владельца (вопрос 2026-10-28): в шапке у руководства первым пунктом
«Вся организация»; если офис заведён — эту роль играет офис.

## Решения исполнителя

- От выбранной точки зависят 49 страниц и API (фильтр и создание документов), поэтому
  «Вся организация» не меняет точку данных: офис, а без офиса — первая точка (как было
  без выбора). Меняется только режим раздела «Журналы».
- Режим точки — только у руководящего звена (`hasFullWorkspaceAccess`: руководство,
  заведующая). Линейному сотруднику «Все журналы» — единственный вход в журналы на
  сайте, у него ничего не меняется.
- Без выбора (новый вход, нет запомненной точки) руководство начинает со «Всей
  организации».

## Критерии

- **AC1** У руководства на всю компанию в переключателе точек первым пунктом «Вся
  организация» (без офиса; офис сам и есть этот уровень). Выбор сохраняется (cookie +
  `lastActiveBuildingId`), API `POST /api/me/active-building {buildingId:"organization"}`
  — только руководству на всю компанию (иначе 403). Mini App — тот же пункт (П-3).
- **AC2** Выбрана торговая точка (или человек — руководитель точки): в меню «Журналов»
  нет «Журналов точек» и «Всех журналов»; корень раздела — «Сегодня» (у заведующей —
  панель контроля).
- **AC3** Меню «Журналов»: «Журналы точек», «Сегодня», «Все журналы», «Проверка
  записей», «Настройка журналов», ниже — «Наборы журналов». Группы «Ещё» нет.
- **AC4** На `/journals/points` и `/journals` в режиме точки — экран «Этот раздел — для
  всей организации» с кнопкой «Назад» и (руководству на всю компанию) «Выбрать всю
  организацию», после которой страница открывается на месте.
- **AC5** Заведующая, закреплённая за точкой: в шапке её точка без «Вся организация»,
  меню — как с выбранной точкой.
- **AC6** Мастер-кабинет: у точек свои коды журнала (≠ коду организации); вторая точка
  той же организации подключается; точки разных организаций — отдельные объекты пула;
  выгрузка видит каждую точку.
- **AC7** ru/en/uz, «Что нового», тесты (`building-scope`, `header-point`, `app-nav`),
  `npm run typecheck`, `npm run i18n:check`, `npm run test:gate`; e2e-база, не прод.
