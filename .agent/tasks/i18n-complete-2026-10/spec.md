# Полный перевод интерфейса + защита ручных правок (2026-10-24)

## Запрос владельца

Довести перевод интерфейса (ru/en/uz) до конца: все журналы и кабинет.
Владелец и помощник должны править строки вручную в админке, а сделанное
вручную сайт запоминает и автоматически не меняет.

## Решения

- Волна 1 (сделана): компоненты и страницы журналов -> `journalUi.*`,
  `journals.ui.*`.
- Волна 2: кабинет (не журналы): `src/components/**` кроме landing, mailing,
  partner, root, public, blog; `src/app/(dashboard)/**` кроме журналов;
  `src/app/mini/**`; `src/app/master/**`. Namespace `<area>Ui` по папке
  раздела, подключается в layout раздела через `DomainMessagesBoundary`.
- Вне объёма (отдельные итерации): `src/app/api/**` (сообщения сервера),
  `src/lib/**` (данные, шаблоны, PDF), `/root/**`, лендинги, юридические
  тексты (оферта) — требуют отдельного решения.
- Не переводятся: значения, которые хранятся в БД или сравниваются с
  данными; алиасы импорта.
- Ручные правки (редактор переводов) живут в БД поверх каталогов и
  переживают деплой. Дополнительно:
  - автоперевод не предлагает черновик поверх строки, уже правленной вручную;
  - правка хранит русский исходник на момент сохранения; если исходник
    изменился — строка помечена «исходник изменился», правка продолжает
    действовать;
  - правка с несовпадающими аргументами ICU относительно текущего русского
    исходника не применяется (защита от падения страницы);
  - в редакторе категории по каждому журналу.

## Критерии приёмки

- AC1. Волна 2: в файлах области не остаётся видимых русских литералов,
  кроме перечисленных исключений; `npm run typecheck` чист.
- AC2. Каталоги ru/en/uz полны, аргументы ICU совпадают (`i18n:check`).
- AC3. Автоперевод пропускает ключи с ручной правкой в целевой локали.
- AC4. `TranslationOverride.sourceRu` и пометка устаревшей правки в API и UI.
- AC5. `applyOverrides` пропускает правку с несовпавшими аргументами ICU.
- AC6. Курируемые категории по всем активным журналам; тест, что ключ не
  дублируется между категориями.
- AC7. `npm test` по затронутым областям, `npm run typecheck`,
  `npm run i18n:check` зелёные.
