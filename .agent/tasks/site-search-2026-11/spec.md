# Поиск по сайту и быстрые улучшения страницы журнала

Task ID: `site-search-2026-11` · 2026-11-17.

## Запрос
1. Кнопка поиска на сайте — быстро найти любой журнал, бланк, приказ, статью блога и т. д.
2. Анализ конкурентов (haccp-online.ru — гигиенический журнал, well-clean.online — журнал уборки) против wesetup.ru/journals-info/cleaning: как сделать журнал проще и понятнее, как поднять вовлечение.

## Критерии приёмки
- AC1: в шапке всех публичных страниц и на главной — кнопка «Поиск» (Ctrl/⌘+K, «/»); окно ищет по журналам, посадочным страницам журналов, бумажным бланкам, приказам, базе знаний, глоссарию, возможностям, нишам, сравнениям, разделам сайта и статьям блога.
- AC2: матчер прощает опечатки, падежи и неверную раскладку; точное короткое название — выше; группы по видам; клавиатура (↑↓ Enter Esc); пустой запрос — «Часто ищут».
- AC3: индекс собирается из тех же источников, что страницы (новое попадает в поиск само), ссылки локализуются (en/uz), кеш 10 минут, ответ — публичный JSON.
- AC4: страница журнала: «Скачать PDF» и «Вести с телефона бесплатно» в шапке (первый экран), строка доверия; технический «Код журнала» убран из боковой колонки.
- AC5: тексты в ru/en/uz; typecheck, eslint, затронутые тесты — зелёные.
