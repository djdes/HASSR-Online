# Ссылка проверяющего на одну точку (2026-11-01)

Решение владельца: «исправь ссылки проверяющего на одну точку». Схема — PR #97
(`InspectorToken.buildingId`, null — вся организация, точку удалили — ссылка удаляется).

## Критерии приёмки

- AC1. `POST /api/settings/inspector-tokens` (и QR, и разовая ссылка) принимает
  `buildingId`: не прислали — точка из шапки (в «Вся организация» — вся
  организация); руководителю точки — только своя точка, на всю организацию — 403;
  чужая точка — 400. Точки выключены — всегда вся организация.
- AC2. GET/DELETE: руководитель точки видит и отзывает только ссылки своих точек.
- AC3. Портал проверяющего по ссылке на точку: опись журналов, журнал, листы и PDF
  документов, сводка PDF — документы точки и общие, записи журналов по цехам
  точки; чужой документ — 404. Чек-листы и медкнижки — этой точки. Набор журналов —
  точки, если он у неё свой. Подпись «Точка: …» в шапке портала, журнала, PDF.
- AC4. `/inspection`: QR — на точку из шапки (руководителю точки — его), подпись
  «Для точки … / Для всей организации», руководитель точки может выпустить QR.
- AC5. «Портал инспектора» и его API открыты руководителю точки (убраны из
  company-only), у ссылок — подпись точки, подсказка, для кого выпускаются новые.
- AC6. Лист A4 с QR: человек точки печатает только QR своей точки, на листе — точка.
- AC7. Сертификат: руководителю точки — QR его точки.
- AC8. Тесты правил; typecheck 0 ошибок.
