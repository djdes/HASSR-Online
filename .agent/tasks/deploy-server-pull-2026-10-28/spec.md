# Деплой: сервер сам скачивает коммит с GitHub

## Проблема

2026-10-28 пять выгрузок из семи висели на шаге «Upload tarball via SCP»,
пока job не убивался по таймауту (15 мин). #43 (`7c227c04`) — три попытки
подряд. Удачная выгрузка того же архива (94 МБ, сжатый ~30 МБ) шла 4 минуты:
GitHub → сервер ~130 КБ/с. Обратный путь быстрый: сервер скачал весь
репозиторий коммита с codeload.github.com (286 МБ) за 33 с, ~8,7 МБ/с.
С рабочей машины на сервер 30 МБ — за 3 с. Узкое место — путь GitHub → сервер.

## Решение

1. Список исключений архива — в `scripts/deploy-tarball.sh`, его вызывает и
   GitHub Actions, и сервер.
2. `scripts/deploy-tree-digest.sh` — отпечаток содержимого архива (sha256 по
   путям и содержимому, без `.build-time`; даты файлов не входят).
3. В job «Upload tarball» перед SCP — шаг «Server downloads the commit from
   GitHub»: сервер по SSH скачивает `codeload…/tar.gz/<sha>`, собирает
   deploy.tar тем же скриптом, сверяет отпечаток с архивом из Actions и
   кладёт в каталог приложения. Не вышло (сеть, отпечаток) — SCP, как раньше.
4. `timeout-minutes` job'а 15 → 25: до 6 минут на скачивание + запас на SCP.

## Критерии приёмки

- AC1. Архив из `deploy-tarball.sh` содержит те же файлы, что прежняя
  inline-команда: код со всеми маршрутами журналов, без `node_modules`,
  `.next`, `.agent`, `./docs`, `./mobile`, `./journals` (тест).
- AC2. Отпечаток не зависит от дат файлов и `.build-time`, меняется при
  другом содержимом или пути; архив без файлов — ошибка (тест).
- AC3. Архив из codeload-tar.gz коммита и архив из обычного checkout того же
  коммита дают одинаковый отпечаток (проверка на `7c227c04` локально).
- AC4. SCP запускается, только если шаг сервера не удался; повтор SCP —
  как раньше.
- AC5. Первый деплой после слияния: шаг сервера успешен, отпечаток совпал,
  SCP пропущен, прод отдаёт новый `.build-sha`.

## Не входит

- Шаги deploy 1/3–3/3 на сервере не меняются.
- Если репозиторий станет приватным, codeload без токена не отдаст архив —
  сработает SCP. Тогда шагу понадобится токен только на чтение.
