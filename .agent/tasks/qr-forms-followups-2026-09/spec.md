# Spec (frozen 2026-09-25): доделки QR-форм — «обсл»/«рем» в общей QR-форме холодильников, камера для приказов на планшетах, узкое поле температуры

После выката «обсл»/«рем» (задача `qr-forms-polish-2026-09`) остались дыры:

## 1. «Обслуживание»/«Ремонт» в общей QR-форме журнала холодильников
- Общая QR-форма журнала (`/journal-fill/[orgId]/[code]` для `cold_equipment_control`, HTML — `src/lib/journal-fill-html.ts`, приём — `src/lib/journal-fill-submit.ts`, адаптер — `src/lib/tasksflow-adapters/cold-equipment.ts`) сейчас предлагает у каждого холодильника только «Выключено». Добавить рядом «Обслуживание» и «Ремонт» (взаимоисключающие между собой и с «Выключено»; при выборе поле температуры гаснет, норма не проверяется) — как на QR-наклейке холодильника (`src/app/equipment-fill/*`).
- Сохранение — в тех же данных записи, что и с наклейки (`statuses[slotKey] = "service" | "repair"`, температура `null`), чтобы в документе на сайте и в печати было «обсл»/«рем». Повторный показ формы (ошибка валидации) сохраняет выбор. Снятие отметки и ввод температуры — отметка снимается (как с наклейки).
- Тесты: разбор полей формы, адаптер (статус пишется, «Выключено» и статус не смешиваются, пустое поле не снимает статус с наклейки — текущее поведение сохранить), HTML содержит кнопки только для холодильников.

## 2. Кнопка «Камера» для приказов на планшетах
- В блоке «Приказы к журналу» (`src/components/journals/journal-order-scans-panel.tsx`) и на QR-странице кнопка «Камера» сейчас видна по ширине экрана (< 640 px). Показывать её на устройствах с сенсорным экраном (media `(pointer: coarse)` / `(any-pointer: coarse)`), в том числе на планшетах любой ширины; на компьютере с мышью — не показывать.

## 3. Узкое поле температуры в карточках холодильников
- В карточках холодильников (найти, где поле ~55 px и число не видно из-за «°C» — вероятно, документ журнала на сайте и/или QR) поле должно показывать число целиком (например «-18,5») на 390 и 1440.
