# Смоук-тесты новинок 21.11.2026 и тексты без лишнего

- **Task ID:** `smoke-new-features-2026-11-21`
- **Base:** `origin/master` `41a67df1` (#293)
- **Frozen:** 2026-11-21, before implementation.

## Запрос владельца

«Протестируй смоук тестами всё новое, чтобы не отваливалось, выглядело хорошо и просто без кучи воды в текстах,
насколько это возможно, и скажи, что из скиллов надо установить, чтобы тесты были ещё лучше».

## Решения

- Р1. Смоук на уровне базы — в существующий ночной E2E (`scripts/e2e/run-all.sh`, Postgres в CI): подсказки
  журнала приёмки, загрузка Poster настоящей `syncSupplyConnection` (подменён только Poster), блюда в подсказках
  бракеража, подпись УКЭП настоящего PDF (openssl) с разбором и записью в `JournalDocumentSignature`.
- Р2. Смоук в браузере (iPhone 13, вход руководителя) — `scripts/smoke/new-features.smoke.cjs` + данные
  `scripts/smoke/new-features-setup.ts` (только локальная база): мастер настройки, журнал приёмки (полоса
  Меркурия, меню, iiko), подпись УКЭП целиком через подставной плагин КриптоПро с подписью openssl, «Входящие
  ВСД», история партии, партия, Poster, подсказки блюд; на каждом экране — ошибки страницы, горизонтальная
  прокрутка, скриншот. В CI — отдельной задачей того же ночного workflow.
- Р3. Тексты новинок — короче: убрать повторы и пояснения, которые человек и так видит; ошибки плагина УКЭП —
  из переводов по коду, а не русской строкой из библиотеки.
- Р4. Найденное смоуком — чинить в этой же задаче.

## Критерии приёмки

- **AC1.** Смоук на уровне базы проходит на настоящем Postgres и подключён к `run-all.sh` и фильтру путей CI.
- **AC2.** Смоук в браузере проходит дважды подряд на свежих данных (первый заход нового пользователя).
- **AC3.** Тексты ru/en/uz новинок сокращены, ошибки плагина УКЭП переведены, `i18n:types`.
- **AC4.** typecheck, тесты, eslint — зелёные; задачи CI на PR — зелёные.
