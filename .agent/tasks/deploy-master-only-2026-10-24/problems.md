## 1. AC1: ветку не удалить из этой сессии — решено

Ветку удалил владелец в интерфейсе GitHub. Свежая проверка:
`raw/verify-remote-branches-after.txt`.

`git push origin --delete codex/mobile-first-release-2026-10` вернул HTTP 403.
Прокси сессии пускает push только в её рабочую ветку
`claude/friendly-pasteur-n489ly`. По правилам окружения отказ политики не
повторяем и не обходим.

Минимальное исправление — удалить ветку вручную:
https://github.com/djdes/HASSR-Online/branches, значок корзины у
`codex/mobile-first-release-2026-10`. Коммиты ветки сохранены в
`raw/codex-mobile-first-release-2026-10/`, восстановление описано в README
там же.

## 2. AC7: actionlint не запускался

Скачивать и запускать внешний бинарник в сессии запрещено. Ручной запуск
workflow на рабочей ветке тоже недоступен: интеграции отказано в
`workflow_dispatch` (403).

Чем это заменено:

- разбор YAML и проверка структуры утверждениями;
- имитация обоих скриптов.

Остаётся риск: синтаксическую ошибку в выражениях `${{ }}` найдёт только
GitHub. Выражения короткие и стандартные. Первый прогон после слияния в
master покажет результат: при ошибке файла GitHub не запустит прогон и
напишет «Invalid workflow file».
