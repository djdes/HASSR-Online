## Нераспределённые страницы

без своего места остались `/batches`, `/losses`, `/changes`, `/bonuses` (убраны из меню
2026-09-25, открывались только по адресу) и `/competencies` (только ссылка с карточки
медкнижек). Остальные страницы без пункта — редиректы, подстраницы пунктов (`match`),
`/home`, `/translations` (меню профиля), `/acknowledge` (сотрудникам, ссылки в Mini App).

## Письмо после регистрации

**AC4** `sendWelcomeEmail` (уходит из `POST /api/auth/register/confirm`) — «Ваш план
настройки» из 5 шагов в порядке меню: данные компании (`/settings/organization`) →
торговая точка (`/settings/buildings`) → сотрудники точки (`/settings/users`) →
журналы точки (`/journals/points`) → QR-наклейки (`/settings/qr-posters`). У шага —
номер в круге, заголовок-ссылка со стрелкой →, одна строка пояснения.
**AC5** Кнопка «Начать настройку» → «Быстрая настройка» (`/settings/onboarding`);
внизу телефон поддержки (`HOME_PHONE`).
**AC6** ru/en/uz; имя экранируется; на 390 px без прокрутки вбок; все ссылки ведут на
существующие страницы.
