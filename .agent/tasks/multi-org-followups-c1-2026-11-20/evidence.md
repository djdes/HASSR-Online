## AC2. Старые группы — PASS
Отметка вычисляется под замком обмена до планирования, только для групп без отметки: компаний нет → владелец;
несколько → «смешанная»; одна → кто раньше в группе по времени связей (связи не пересоздаются, время сохраняется);
одновременно (один обмен) — владелец, только если его запись строго старше всех записей компании и запись компании
не пересоздана позже связи; иначе — компания. Сохраняется `updateMany` по пустым; повторный обмен ничего не меняет.
`raw/multi-company-check.log`: 7 старых групп — «O→A», «вместе», «O» → владелец (B получает), «A→O», «A заново»,
цех → A (B не получает), «AB» → «смешанная»; второй прогон — 0 изменений.

## AC3. Меню и сырьё по отдельной галочке — PASS
Запрос: «Меню и сырьё мастер-кабинета» (`withPool`, только для связи, по умолчанию выкл.). Страница подтверждения —
отдельная строка (`poolAllowed`, по умолчанию выкл.). При разрешении — подключение тем же путём, что «Добавить
объект» (`connectPoolObjectByCode`, код на сервере), `poolConnected` в той же транзакции; отказ — пояснение, связь
есть. Выход и отключение снимают только подключение организации, сделанное обменом, и только если оно на пул этого
кабинета; ручное отключение сбрасывает `poolConnected`; точки, подключённые вручную, не трогаются. Замки: обмен →
пул, обратного порядка нет.

`raw/pool-check.log` — 49/49. Вживую (`raw/series-c1-live.log`): галочка выключена по умолчанию в запросе и на
странице подтверждения (`raw/01-request-with-pool.jpg`, `raw/02-confirmation-pool.jpg`); после разрешения у A
`poolConnected` и код пула; B подтверждена второй компанией; у B — продукты владельца, но не A; в карточке владельца —
две компании (`raw/03-owner-two-companies.jpg`).

## Известные ограничения
- Если у компаний A и B есть одноимённые записи, а у владельца нет, организации владельца получают копию A, а запись
  B остаётся пропуском «такое название уже есть» без кандидата для связи (следствие правила «звезда»); доступно только
  «Не переносить».
- Старые группы, где компания и владелец связаны одним обменом и даты записей не читаются (цеха, оборудование),
  считаются группами компании — новые компании их не получают (осторожно).
- Подключённая компания может сама подключать и отключать свои точки в кабинете со своей страницы «Мастер-кабинет»
  (как и при ручном подключении до C1).
