# TG-уведомления: компактный текст, регион и время клиента, ссылка в админку; часовой пояс организации

Task ID: tg-client-location-2026-11 · Заморожено до реализации.

## Цель
Продажи видят в Telegram короткое уведомление с регионом и местным временем
клиента и одной ссылкой «Открыть» на клиента в админке. Время в журналах
организации — по её городу (часовому поясу), который спрашивается при
регистрации с автоподстановкой, а не по Москве.

## Критерии приёмки
- AC1. Строка места компактная: `🇷🇺 Россия, Барнаул · 09:29` (без «местное время» и `(UTC+7)`).
- AC2. Уведомление о скачивании шаблона:
  `📥 Скачивание журнала: <название> (<формат>)`, `Почта:`, `Телефон:`, строка места,
  `✅ Кабинет создан, доступ отправлен`, последней строкой ссылка `Открыть`.
- AC3. Ссылка «Открыть» ведёт на `/root/organizations/<id>`, если организация клиента известна,
  иначе на карточку CRM-контакта по почте/телефону; если ничего нет — ссылки нет.
- AC4. Уведомления о действиях пользователей (регистрации, заявка на показ, обращения с сайта
  и из кабинета, виджет поддержки, онлайн-чат, NPS, отзывы, заполненный профиль, заявки на услуги,
  счета, оплаты/пополнения, обратная связь триала) получают строку места и «Открыть»
  через единый `notifyPlatformAdmin(..., { client })`. Сбой гео/БД не ломает отправку.
- AC5. Карточка организации в /root: рядом с телефоном владельца — текущее местное время клиента
  (пояс по IP последнего входа/регистрации, иначе пояс организации), обновляется без перезагрузки.
- AC6. Организация хранит город и страну (`Organization.city`, `Organization.countryCode`, nullable).
  Регистрация (/register) спрашивает город с подсказками (автозаполнение по IP/поясу браузера);
  выбранный город задаёт `Organization.timezone`. Быстрая регистрация из окна скачивания
  записывает город/страну по IP и пояс браузера.
- AC7. Настройки → Контакты организации: поле «Город» с подсказками, выбор города ставит часовой пояс.
- AC8. Отметки времени в журналах, где пояс был жёстко «Europe/Moscow» при наличии пояса организации,
  берут пояс организации.
- AC9. Все новые тексты UI — в ru/en/uz, `npm run i18n:types`; `npm run typecheck` и тесты гейта зелёные.
