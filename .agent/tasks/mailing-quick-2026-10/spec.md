# Рассылка: простой режим «база + готовое письмо» (2026-10-22)

## Зачем
Команда WeSetup почти ничего не меняет в письмах. Ей нужно только выбрать
базу адресов и готовый шаблон и отправить. Тексты шаблонов пишет Claude.
Сейчас `/root/mailing` открывается конструктором: тема, текст, каналы,
выбор людей поштучно на двух вкладках. Это слишком сложно для команды.

## Решения (мои, пользователь просил решать самому)
- Шаблоны («готовые письма») лежат в коде: `src/lib/mailing/presets.ts`.
  Новый шаблон — коммит Claude с тестом, на прод он попадает деплоем. Пароль
  ROOT для этого не нужен, а история правок остаётся в git.
- «База» бывает двух видов:
  - сегмент клиентов платформы: руководители, все, кто ещё не платит,
    платящие, новые за 30 дней;
  - загруженная база контактов (`MarketingContact.source`, активные адреса).
- Сегменты считаются на сервере. Клиент присылает только `presetId` и `baseIds`.
- Отправка идёт старым путём: черновик `MailingCampaign` → `/test`, `/launch` →
  очередь, стоп-лист, отписка. Новых таблиц нет.
- Конструктор, «Пользователи», «Контакты» и «Стоп-лист» не меняются и
  прячутся за переключателем «Расширенный режим». «История» видна всегда.

## Критерии приёмки
- **AC1.** `/root/mailing` по умолчанию открывает вкладку «Отправить» с тремя
  шагами: «Кому» → «Какое письмо» → «Отправка». Писать ничего не нужно.
- **AC2.** «Кому»: карточки сегментов клиентов и загруженных баз с числом
  адресов. Можно выбрать несколько. «Загрузить новую базу» открывает окно
  загрузки (та же логика импорта). После загрузки база появляется в списке
  и сразу выбрана.
- **AC3.** «Какое письмо»: карточки шаблонов из `presets.ts` с названием,
  пояснением, каналами и подсказкой, кому подходит. У выбранного —
  предпросмотр по каналам шаблона.
- **AC4.** «Отправка»:
  - сводка охвата по каналам шаблона (`planRecipients`);
  - «Тест мне»;
  - «Отправить сейчас» через `ConfirmDialog`;
  - «Запланировать» по Москве.
  Повторные тесты переиспользуют один черновик и не плодят новые. После
  запуска открывается карточка рассылки.
- **AC5.** «Расширенный режим» показывает прежние вкладки без изменений.
  Ссылка `?tab=compose|users|contacts|stoplist` включает его сама. В
  расширенном режиме шаблон можно открыть в конструкторе.
- **AC6.** API `POST /api/root/mailing/quick` доступен только ROOT. Он
  проверяет `presetId` и `baseIds`, разворачивает базы в получателей на
  сервере и возвращает охват; с `save: true` создаёт или обновляет черновик.
  `GET` отдаёт список баз с числами.
- **AC7.** Тесты:
  - каждый шаблон проходит `validate` своего типа, каналы не пустые, ссылки
    безопасные, id уникальны;
  - предикаты сегментов работают верно;
  - `tsc` и eslint по изменённым файлам чистые;
  - тесты рассылки зелёные.

## Не делаем
- Редактор шаблонов в интерфейсе и шаблоны в базе данных.
- Изменение очереди, лимитов, стоп-листа, отписки, типов писем.
