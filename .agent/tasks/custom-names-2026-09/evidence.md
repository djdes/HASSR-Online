# Evidence: свои названия разделов и журналов (custom-names-2026-09)

Ветка `feat/names-2026-09-25` (копия `C:/wt/blanks`, база `wesetup_wt_blanks`), спецификация — `spec.md` в этой папке.

## Что сделано

- **Хранение.** Единственное изменение схемы — `Organization.customNamesJson Json @default("{}")`
  вида `{ "journals": { "<код>": "Своё" }, "sections": { "<ключ>": "Своё" } }`.
  Порядок: `prisma db push` в `wesetup_wt_ui`, `wesetup_wt_pdf`, `wesetup_wt_qrforms`,
  `wesetup_wt_blanks` (строка из `.env`, меняется только имя базы) → после каждого push
  пересоздан частичный индекс `PartnerClient_one_active_per_org` → только потом
  `prisma generate`. Проверка после сбоя диска (см. ниже «Проверки»): во всех четырёх базах
  колонка `customNamesJson='{}'::jsonb`, индекс и `NpsResponse.scale` на месте.
- **Один помощник.** `src/lib/custom-names.ts` — чистые функции (разбор JSON, показ,
  поиск по обоим названиям, проверка ввода 2–80 символов с обрезкой пробелов и запретом
  одинаковых названий, дифф и детали аудита). `src/lib/org-custom-names.ts` — чтение из
  базы `getOrgCustomNames(orgId)` (кэш на один серверный рендер, как у `getJournalCrumbMenu`;
  между запросами не кэшируется — как остальные настройки организации),
  `resolveJournalDisplayName(orgId, code, official)`, `resolveSectionName(orgId, key)`.
- **Один способ передать на клиент.** `CustomNamesProvider` в `(dashboard)/layout.tsx`
  (и в обычной оболочке, и в оболочке мини-приложения) + хуки из
  `src/components/shared/custom-names-provider.tsx`. Меню, крошки, карточки, заголовки
  журналов и поиск берут названия только оттуда.
- **Настройка.** `/settings/names` (права как у «Набора журналов» — `hasFullWorkspaceAccess`),
  карточка в хабе настроек (группа «Журналы»), крошка «Названия». Два списка: «Разделы меню»
  (пункты меню шапки: Журналы, Сотрудники, Производственный план, Нарушения, Отчёты, Идеи;
  «Настройки» и «Выход» не переименовываются) и «Журналы» (поиск по своему и официальному
  названию). У строки — стандартное название серым, поле своего, «Вернуть стандартное».
  Пустое поле = стандартное. Одна кнопка «Сохранить» в липкой панели → `PUT
  /api/settings/custom-names` (логика в `src/lib/custom-names-save.ts`) → `AuditLog`
  `settings.custom_names.update` с «было → стало» по каждому названию («Названия разделов и
  журналов изменены» в «Журнале действий»).
- **Где видно своё название.** Меню шапки (desktop и мобильное) и пилюля «Сотрудники»;
  хлебные крошки (`PageNav`, `JournalPageCrumbs`, переключатель журналов в крошке);
  главная — «Обязательные журналы», лента записей, «Лента заполнений»; список журналов
  (H1 раздела, карточки, подсказка официального в `title`); страница журнала — H1 своим
  названием и под ним «Официальное название: …» (все ~36 клиентов списков через
  `JournalTopBar`/`JournalHeadingName`), окно «Инструкция»; страница документа —
  строка «Своё · Официальное название: …» под заголовком (`DocumentActionsBar`, все клиенты
  документов); QR-формы (`/journal-fill`, хаб «Все журналы», `/task-fill`); мини-приложение
  (вкладка меню, «Разделы», заголовок оболочки, «Сегодня» — `/api/mini/today`, все страницы
  кабинета в оболочке); задачи в кабинете (`/control-board`, `/verifications`,
  «Прогресс по журналам», уведомление о новом периоде по QR); Telegram — общий источник
  `listOpenJournalObligationsForUser` (дайджест, «Сегодня» бота), напоминание крона
  `compliance`, `/edit` и `/missing` бота; H1 разделов (Журналы, Отчёты, План, Нарушения,
  Идеи, Сотрудники); поиск ⌘K (`/api/search` — и по своему, и по официальному; разделы).
- **Где остаётся официальное.** PDF и печать, проверяющий (`/inspector`,
  `/inspector-sheet`), образцы на сайте (`/journals-info`, `/blanki`), отчёты (`/api/reports/*`),
  QR-плакаты, названия новых документов (данные), задачи TasksFlow (данные). Эти модули
  помощник не импортируют — это закреплено тестом `custom-names-official.test.ts`.

## Известные ограничения

- Заголовок документа (H1 бланка) — собственное название документа, это данные: оно
  создаётся из официального названия и печатается, поэтому не переименовывается; своё
  название журнала стоит строкой под ним.
- Настроечные страницы про журналы (набор журналов, ответственные, доступы и т. п.)
  показывают официальные названия.
- Уже созданные уведомления в колокольчике хранят текст на момент создания; новые — со
  своим названием.
- Пилюли заведующей («Доска», «Прогресс», «Команда», «Проверка») — не пункты меню шапки
  руководителя и не переименовываются.
- Локальная база создана с локалью `C`: `ILIKE` там не сравнивает кириллицу без учёта
  регистра. Поиск журналов в `/api/search` теперь идёт общим матчером (`journalMatchesQuery`)
  и от локали не зависит; поиск документов по названию — по-прежнему через базу.
