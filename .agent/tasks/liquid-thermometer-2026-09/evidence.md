# Стеклянный термометр по фото — доказательства (2026-09-27)

Правка владельца: «где фотка с ртутным термометром, там пишется „Не разобрали цифры — введите вручную“ (три
термометра), а с одиночного распозналось 28, а не 32 — попробуй улучшить именно с ртутным».

## Эталон
Фото владельца: настенный спиртовой термометр °C/°F. Верх столбика по растру — на 1,8 деления выше длинной черты
30 °C (подпись «30» напечатана НАД своей чертой), по шкале °F ≈ 89 °F → **31,8 °C ≈ 32**. Три термометра
(рекламное фото, наклон ~25°): столбики бледные, у всех ≈ 22 °C. Прошлые эталоны: табло 8.4, 3.0, −26.3,
стрелочный −18.

## Что сделано
1. `instructions.ts` — стеклянный термометр читается по чертам, а не по цифрам (подпись относится к своей длинной
   черте, часто напечатана над ней), ближайшая длинная черта °C ниже верха + число коротких черт × цена деления,
   сверка со шкалой °F (раньше °F запрещалась), разница в 1 °C — не сомнение (не перечислять варианты через «или» —
   иначе `isHedgedReadingNote` выбрасывает число). В тексте нет эталонных чисел (тест, добавлено «32»).
2. `reading-zoom.ts` — сайт сам находит на фото окрашенный столбик (тонкая длинная почти вертикальная красная /
   розовая / синяя линия; засечки и цифры шкалы, кожа, детали экрана отсекаются по толщине), берёт его узкий
   верхний конец, вырезает квадрат 18 % кадра, увеличивает до ~1000 px и ставит синий треугольник остриём к верху
   столбика. Второе фото задания + строка `READING_ZOOM_NOTE` в инструкции. Нет линии — одно фото, как раньше.
3. `reading.ts` — фрагмент в задание, лог `[ai-vision] reading zoom=0|1`. Квота считает задания — второе фото её не
   тратит.
4. Подсказка у кнопки: «Снимите один термометр или дисплей крупно…».

## Живой исполнитель (очередь ИИ-диспетчера, `eval-live.ts`)

| Фото (верно) | Было (прод) | Инструкция без фрагмента | Итог (инструкция + фрагмент с треугольником) |
|---|---|---|---|
| одиночный стеклянный (32) | 27 | 28 | 33, 32, 33, 34 (без треугольника: 32, 27, 32) |
| три стеклянных (≈22) | −20 | null | null (столбик не найден — «введите вручную») |
| стрелочный (−18) | −25 | −20 | −18 |
| табло 8.4 / 3.0 / −26.3 | верно | верно | верно |

Ручной фрагмент для трёх термометров давал 22 и 21 — поиск столбика там не срабатывает (очень бледный,
сливается с красными засечками ниже 0); это рекламный снимок, на реальном фото одного термометра — работает.

стрелка — без фрагмента; JPEG; масштаб), `instructions.test.ts`.
