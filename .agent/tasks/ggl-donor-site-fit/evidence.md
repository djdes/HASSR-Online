# Проверка подбора площадок GoGetLinks

| Критерий | Результат | Доказательство |
| --- | --- | --- |
| AC1 | PASS | Числовые фильтры выполняются до чтения страниц. Тематическое совпадение приоритетнее совпадения по аудитории. В контрольном прогоне три площадки слота остались без рекомендации, Restoranoff подтвердил две публикации для рестораторов. |
| AC2 | PASS | Запросы идут к проверенным публичным IPv4 по HTTPS. Редиректы ограничены этим же доменом и его www, выборка ограничена по времени, количеству страниц и размеру ответа. |
| AC3 | PASS | Тест повторной обработки просроченного слота подтверждает сохранение посадочной, анкора и черновика. Основной донор и резерв привязаны к посадочной. Backend блокирует подтверждение без проверки. |
| AC4 | PASS | В интерфейсе показаны уровень соответствия и публикации, тексты добавлены в ru/en/uz. Целевой прогон дал 287/287. Свежая проверка типов завершилась с кодом 0. |

- `raw/live-review.json` — запуск по трём площадкам из слота и отраслевому контрольному сайту.
- `raw/verification-tests.txt` — полный вывод целевого прогона.
- `raw/spec.sha256` — контрольная сумма замороженной спецификации.
- `raw/verification-types.txt` — вывод npm run typecheck.
