# Спецрежим: всё «подрисовывание» журналов — только в нём (2026-11-05)

Задача руководителя: «Весь „криминал“, связанный с автозаполнением, корректировкой и т. п. в журналах
и документах, спрятать в спецрежим. Зашёл в него, включил/выключил что надо. Больше нигде не видно,
больше никто не знает)) Оставим это для личного контакта с покупателями.»

## Правило значений новых галочек

`catchUp` («Догнать пропуски») — новая галочка. У сохранённого выбора её ещё нет: при первом чтении
сервер решает `resolveAddedFeature` и записывает: **включено, если спецрежим сейчас включён И
организация пользовалась функцией** (в аудите есть `journal_entry.copy` с `via: dashboard.catch_up`);
иначе выключено. То же для организаций без сохранённого выбора (ветка `resolveLegacyAutomation`).
Остальные спрятанные функции привязаны к существующим галочкам (`autoFill`, `copyYesterday`) и
получают их значение — у работающих клиентов со спецрежимом ничего не пропадает.

## Критерии приёмки

- **AC1.** `AUTOMATION_FEATURES` содержит `catchUp`; окно спецрежима показывает его с честной
  подписью; тексты `autoFill`/`copyYesterday` перечисляют все места, где они появятся.
- **AC2.** «Догнать пропуски»: без галочки страница — 404, иконки на главной и пункта палитры нет,
  `GET`/`POST /api/dashboard/catch-up` — 403.
- **AC3.** Без галочки `autoFill`: `apply_auto_fill` кадровых журналов — 403; «Отметить всех «Здоров»»
  и «Заполнить по плану» не показываются; ИИ/MCP `fill_journal_cells` с `kind:"auto"` или массовым
  «Здоров» отказывает.
- **AC4.** Без галочки `copyYesterday`: `/api/task-fill/[id]/yesterday-prefill` данных не отдаёт,
  кнопки «Заполнить как вчера» нет.
- **AC5.** Правило значений новой галочки — в коде рядом с `resolveLegacyAutomation`, покрыто тестом;
  сохранённый выбор без ключа дополняется при чтении.
- **AC6.** Вне страницы спецрежима нет упоминаний спецрежима: нет пункта меню, шага на «Что делать
  сейчас», карточки в «Информации об организации», заметок в «Что нового», адреса `special-mode`.
  Вход — ссылка «Настройки раздела» внизу «Что делать сейчас» (те же права, что раньше).
- **AC7.** Подсказки, гайды, ИИ-помощник, тексты паузы и настроек, публичные страницы не рекламируют
  автозаполнение по графику/«как вчера»/догон пропусков; реальные источники (датчики, фото, учёт) остаются.
- **AC8.** Тесты рядом с изменениями и `npm run -s typecheck` проходят (кроме известных CRLF);
  в браузере: спецрежим выключен — ничего не видно; включена одна галочка — только её функция.
