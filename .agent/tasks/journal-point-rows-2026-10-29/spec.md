# Журналы точки — только сотрудники, помещения и оборудование этой точки

Владелец, 2026-10-29: «В журналы конкретной точки выводятся все помещения /
сотрудники / оборудование, зарегистрированные в организации». Видео
`IMG_0488.MOV`: QR-коды → точка «Одинцовская Лингвистическая Гимназия» →
QR «Все журналы» → «Гигиенический журнал» → вкладка «Допуск сотрудников»:
~60 человек (45 не отметились + 15 допущено) — вся организация.

## Правило точки

- Документ с `buildingId` при включённых точках (≥ 2) — документ этой точки.
- Сотрудники точки: `User.buildingIds` содержит точку или пуст (работает
  везде). QR — правило `worksAtQrPoint` (висящие id удалённых точек не
  отрезают людей), сайт и строки документа — `staffAtBuildingWhere`.
- Помещения точки: `Room.buildingId = точка`.
- Цеха точки: `Area.buildingId = точка` или цех без точки (общий).
- Оборудование точки: оборудование цехов точки и цехов без точки
  (`equipmentBuildingWhere`).
- Документ без точки или точки выключены — без фильтра, как раньше.

## Критерии приёмки

- AC1. QR гигиены/здоровья, вкладка «Допуск сотрудников»: строки, счётчики
  и пакетный «Подписать допуск» — только сотрудники точки документа (у
  общего документа, открытого с QR точки, — точки из QR). Сотрудник с
  другой точки, уже отметившийся сегодня в этом документе, остаётся в
  списке, чтобы его можно было допустить.
- AC2. Парный журнал (гигиена ↔ здоровье) берётся той же точки или общий,
  никогда — документ другой точки.
- AC3. Строки по умолчанию у документа точки, созданного автоматически, по
  первому QR, «назначить на сегодня» и при пересоздании
  (`fetchOrgDataForDefaults`): холодильники, климат, генуборки, поверка,
  ППР, стекло, цеха уборки и ответственные уборки — только по точке
  документа.
- AC4. Ручное «Создать документ» (`POST /api/journal-documents`) для
  активной точки: холодильники, поверка, ППР, стекло (цеха и оборудование),
  цеха и сотрудники уборки — по точке; «как прошлый» документ уборки —
  прошлый документ этой точки или общий.
- AC5. Документ УФ-лампы, создаваемый по наклейке лампы, получает точку
  цеха лампы.
- AC6. Страница документа: гигиенический журнал без строк и «добавить
  сотрудника» предлагают только сотрудников точки документа; журнал уборки
  показывает помещения точки документа.
- AC7. Тесты на правило точки и на каждый пункт выше, где он выражается без
  БД; `npm run typecheck`, eslint по изменённым файлам; проверка в браузере
  на e2e-базе: QR «Допуск сотрудников» точки показывает только её людей.

## Не входит

- TasksFlow: пул задач (`journal-task-pool.ts`) и строки адаптеров
  (`tasksflow-adapters/*`) — отдельная задача по spec интеграции.
- Уже созданные документы не переписываются: их строки собраны раньше.
  Новые периоды и пересоздание получат строки точки.
- Крон «не отметились» и «Отметиться во всех» (`listEmployeeDailyStatus`).
- Люди без точки (`buildingIds` пуст) по-прежнему видны во всех точках.
