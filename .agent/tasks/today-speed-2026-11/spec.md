# Spec (frozen 2026-11-08): быстрее по журналам за день — ещё 10 фич

Запрос владельца: «предложи ещё 10 фич и сразу в прод». Продолжение этапа «Удобство чтения» (PR #144/#145):
теперь — скорость ежедневной работы: открыть нужный журнал, понять, сколько осталось и сколько времени,
не искать заново.

## Исходное состояние (master e976a119)

- «Сегодня»: список журналов (незаполненные сверху, «Заполнено сегодня · N» ниже), поиск, «QR-коды», счётчик N/M в
  заголовке секции. Нет: недавно открытых журналов, перехода к следующему незаполненному, времени до конца дня,
  скрытия заполненных, печатного листа «что заполнить».
- Поиск журналов (`lib/journal-search.ts`) понимает «ё» и порядок слов, но не неверную раскладку («ububtyf»).
- «Избранное» (3 страницы на главной) и ярлыки приложения в манифесте уже есть — не дублируем.
- Во вкладке браузера и на значке приложения нет числа незаполненных. Кнопки «Наверх» нет. Поделиться ссылкой на журнал
  можно только копированием адреса. Горячие клавиши: ⌘K (палитра) и срочный журнал; «/» и «?» не заняты.
- У организации есть `timezone` и `shiftEndHour` (после этого часа день считается прошлым; 0 — полночь).

## Критерии приёмки

- **AC1. Недавние журналы.** Открытие `/journals/<код>` запоминается на устройстве (до 8, без повторов, свежие первыми).
  На «Сегодня» над списком — до 4 кнопок «Недавно открывали» из журналов этого списка (своё название организации).
  Тест модели (добавление, порядок, лимит, мусор в хранилище). Браузер: открыл журнал → на «Сегодня» он первый.
- **AC2. «Дальше: <журнал>».** На «Сегодня» кнопка к первому незаполненному журналу (порядок списка); на телефоне —
  закреплена внизу экрана. Нет незаполненных — кнопки нет. Браузер: ссылка ведёт на `/journals/<код>` первого незаполненного.
- **AC3. «До конца дня».** На «Сегодня» строка «До конца дня 3 ч 20 мин · осталось N»: конец дня — `shiftEndHour`
  организации (0 — полночь) в её часовом поясе; меньше часа — предупреждающий цвет; после конца дня — «День закрыт в
  HH:00»; обновляется раз в минуту; всё заполнено — «Всё заполнено». Тест расчёта (полночь, 23:00, после закрытия,
  часовой пояс, формат).
- **AC4. Счётчик во вкладке и на значке.** На «Сегодня» заголовок вкладки «(N) …», где N — незаполненные; значок
  установленного приложения (`navigator.setAppBadge`) — N, 0 — снять. Уход со страницы возвращает заголовок. Браузер:
  `document.title` начинается с «(N)».
- **AC5. Поиск понимает неверную раскладку.** `journalMatchesQuery`: запрос, набранный в английской раскладке
  («ububtyf» → «гигиен…»), и наоборот, находит журнал; везде, где он используется (Сегодня, Журналы, Настройки → журналы,
  названия, QR). Тест.
- **AC6. «Скрыть заполненные».** На «Сегодня», когда есть заполненные: переключатель прячет группу «Заполнено сегодня»;
  запоминается на устройстве. Браузер на базе с заполненным журналом.
- **AC7. Лист «Что заполнить сегодня» для печати.** С «Сегодня» — страница `/dashboard/today-print`: дата, организация,
  незаполненные журналы с клетками для отметки, без меню; кнопка «Распечатать». Только своя организация (вход
  обязателен). Браузер: страница открывается, список совпадает с незаполненными, печатная разметка без меню.
- **AC8. Кнопка «Наверх».** На телефоне в кабинете после прокрутки больше двух экранов — круглая кнопка «Наверх»;
  нажатие возвращает наверх (без плавности при «Без анимации»). Не перекрывает док плавающих кнопок.
- **AC9. «Поделиться журналом».** На странице журнала кнопка «Поделиться»: на телефоне — системное меню
  (`navigator.share`), иначе — ссылка в буфер и сообщение «Ссылка скопирована». Ссылка — адрес журнала без лишних
  параметров. Браузер (компьютер): буфер содержит адрес.
- **AC10. Горячие клавиши «/» и «?».** «/» (не в поле ввода) — фокус в поиск журналов на «Сегодня» и «Журналы»; «?» —
  окно со списком клавиш кабинета (⌘K/Ctrl+K, «/», «?» и существующие). Браузер: «/» фокусирует поиск, «?» открывает окно.
- **AC11. Ворота.** `npm run typecheck`, `npm run test:gate`, `npm run i18n:check`, eslint изменённых — зелёные; тексты
  ru/en/uz; `next build` (чистый кеш при смене CSS-конвейера не нужен — его не трогаем); PR влит в master (squash),
  выкладка прошла, `/api/build-info` — коммит; прод проверен без входа (страницы открываются, печатный лист без входа
  ведёт на вход).

## Вне объёма

Синхронизация недавних журналов между устройствами (это настройка устройства). Изменение схемы базы. Уведомления.
