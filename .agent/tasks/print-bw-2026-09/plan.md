# План: печатные документы без цвета (spec.md, 2026-09-27)

## 1. Инвентаризация (поиском, до правок)
- PDF jsPDF: `document-pdf.ts` (45 журналов; цвет: заливки выходных/сокращённых, шапка приложения «Подписи»,
  красная просроченная поверка), `pdf-page-labels.ts` (подвал партнёра — сине-серый), `pdf-journal-qr.ts`
  (строка копирайта шаблона — сине-серая; плитку QR не трогаю), `paper-journal-pdf.ts` (тёмно-синие линии/текст,
  голубая шапка), `pdf.ts` (отчёт: синяя шапка с белым текстом), `regulator-bundle.ts` (голубая шапка CAPA),
  `/api/inspector/[token]/pdf` (синяя «электронная отметка»), `invoices/pdf.ts`, `closing-documents/pdf.ts`
  (сине-серые заливки, красная пометка «ОБРАЗЕЦ»), сертификаты `/api/certificate`, `/api/certificate/staff`
  (индиго-рамка и акценты). Чек-листы и приказы — уже без цвета (проверить сканером).
- DOCX `document-docx.ts`: подпись в подвале сине-серая; стиль «Заголовок 2» библиотеки docx по умолчанию
  синий (2E74B5) — название журнала в Word печаталось синим.
- Печать браузером: ячейки дней с `data-print-keep-bg` (розовые/бежевые) и образцы легенды уборки;
  мобильные карточки уборки (розовые чипы выходных); `@media print` у инструкции (сине-серая ссылка);
  лист A4 для проверяющих (сине-серые оттенки).

## 2. Правки (только цвета, минимальный дифф)
- Выходной/праздник — серый #d4d4d4 (212), сокращённый — светло-серый #ebebeb (235): одинаково в PDF, на экране
  (`journal-grid.ts`, легенда и мобильные чипы уборки), в печати браузера; тёмная тема — нейтральные
  белые полупрозрачные заливки 16 % / 7 %.
- Смысловые цвета → серое + смысл без цвета: просроченная поверка — чёрный жирный на серой заливке;
  «ОБРАЗЕЦ» в УПД — чёрный в рамке; синяя отметка проверяющего — чёрная рамка и текст; синяя шапка отчёта —
  серая с чёрным текстом; акценты сертификатов — чёрный/серый.
- DOCX: цвета подвала — нейтральные серые; стили заголовков/ссылки — чёрные.

## 3. Проверка
- Сканер (`scan-colors.ts`): PDF — операторы `rg/RG/k/K/sc/scn/SC/SCN` с неравными компонентами вне плитки QR
  (геометрия по контент-потоку), растр 50 dpi — доля цветных пикселей вне QR; DOCX — XML-атрибуты цвета.
  Наборы: samples/blanks/long/paper/variants/portrait (как `journal-qr-header-2026-09/pages.ts`) + чек-листы +
  пакет проверяющего + приказы + счёт/УПД + сертификаты + отчёт + DOCX. До (master) и после.
- Печать браузером: dev-сервер :3142, `page.pdf()` страниц журналов (гигиена, здоровье, уборка, холодильники)
  и листа проверяющего → тот же сканер.
- `check-qr-overlap.ts` (все наборы), число страниц master vs после (`pages.ts`).
- Скриншоты до/после: гигиена (выходные), температура (холодильники), чек-лист, Word-шаблон (LibreOffice → PDF →
  растр), экранная сетка гигиены с выходными (светлая/тёмная), плюс имитация ч/б лазерного принтера
  (растр + полутон).
- Тесты: «в PDF журналов нет цветных операторов», заливки выходных — серые и различимые; typecheck, test:gate.
