# Страница журнала: вовлечение и SEO «Журнал уборки»

Task ID: `journal-page-engagement-2026-11` · заморожено 2026-11-17. Основа — анализ haccp-online / well-clean (сообщение от 2026-11-17), владелец согласен со всеми пунктами.

## Критерии приёмки
- AC1 (п.1): на телефоне — закреплённая нижняя полоса «Скачать PDF · Попробовать» после первого экрана; плавающие «Контакты»/«Чат» поднимаются над ней.
- AC2 (п.2): конструктор бланка на странице журнала: название, колонки (добавить/убрать/переименовать/переставить), число строк, предпросмотр; «Скачать PDF» — через то же окно с почтой; файл — PDF с этими колонками, шапкой организации и QR.
- AC3 (п.3): «Образец заполнения» строками (у журналов с описанным образцом) и видео «как это работает на кухне» (ru).
- AC4 (п.4): разделы «Кто обязан вести», «Текущая и генеральная», «Штрафы» и др. — из контента журнала (заполнено для уборки).
- AC5 (п.5): отзывы клиентов и «N организаций ведут этот журнал» (от порога).
- AC6 (п.6): предпросмотр бланка — картинкой (PNG первой страницы, кеш), со ссылкой «Открыть PDF целиком»; показывается и на телефоне.
- AC7 (п.7): чипы «Для кого» — страницы ниш, где журнал входит в набор сферы.
- AC8 (п.8): финальный блок с кнопками в конце страницы.
- AC9 (п.9): после скачивания с созданным кабинетом — QR журнала кабинета «Сделайте первую запись прямо сейчас».
- AC10 (SEO): объём текста и вхождения «журнал уборки» на /journals-info/cleaning — в пределах среднего по топу (собранному веб-поиском; Яндекс из облака закрыт капчей), таблица сравнения в evidence.
- AC11: тексты интерфейса — ru/en/uz; typecheck, eslint, затронутые тесты зелёные; e2e-скриншоты.
