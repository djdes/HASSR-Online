# Главная: правки владельца 19.11.2026 (первый экран и блок «QR-код»)

- **Task ID:** `landing-pravki-2026-11-19`
- **Base:** `origin/master` `08072abb4` (после `landing-mobile-polish-2026-11-18`)
- **Branch:** `claude/brave-cannon-5aodxd`
- **Источник:** четыре снимка главной с телефона и список правок владельца от 19.11.2026.

## Критерии приёмки

- **AC1.** Строки «14 дней бесплатно, далее от … в месяц» на первом экране нет (ни на телефоне, ни на ПК).
- **AC2.** Подсказки о почте — внутри поля справа: короткая плашка об ошибке, кнопка
  исправления опечатки домена, индикатор проверки, галочка. Под полем подсказок нет,
  кнопка отправки при вводе не сдвигается.
- **AC3.** Галка согласия остаётся на этом шаге: аккаунт создаётся сразу по нажатию,
  согласие нужно не позже отправки почты. Нажатие на «оферту» или «согласие»
  открывает вопрос «Открыть …?»: слева спокойная «Да», справа крупная яркая «Нет».
  «Да» открывает документ в новой вкладке, «Нет» возвращает к форме.
- **AC4.** Вместо строки о гарантии возврата — «До ДД.ММ.ГГГГ всё бесплатно, далее
  только 1 журнал. Подробнее», по центру. Дата — сегодня по Москве плюс пробный
  период (`TRIAL_DAYS`), «Подробнее» ведёт к тарифам.
- **AC5.** Блок QR: надстрочник «QR-код», заголовок «Скан — PIN — Запись», вместо
  абзаца — три шага. Слова «на оборудовании» нет ни здесь, ни в подсказке к видео.
- **AC6.** Презентация (PDF) — справа от кнопки видео; отдельной кнопки над роликом нет.
- **AC7.** По бокам вкладок-глав — стрелки «предыдущая / следующая глава».
- **AC8.** «Попробуйте сами»: кнопка 44 px с подписью на любой ширине; ползунки под
  палец (бегунок 28 px, зона 44 px); третий пример не про температуру — оценка масла
  во фритюре кнопками 1–5, итог виден в бланке журнала.
- **AC9.** В ролике организация по-русски — «ООО «БФС»» (шапка формы, наклейка, штамп бланка).
- **AC10.** Тексты — в `ru`, `en`, `uz`; `npm run i18n:types`, `npm run typecheck`,
  `npm run test:gate` зелёные.

## Не входит

- Отрендеренное видео со звуком и PDF-презентация (в них прежние тексты и название).
- Перенос согласия на шаг после создания аккаунта.
