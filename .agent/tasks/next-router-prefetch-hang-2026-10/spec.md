# Запрос страницы с `Next-Router-Prefetch: 1` висит без ответа

## Проблема
Запрос страницы (не RSC) с заголовком `Next-Router-Prefetch: 1` без
`RSC: 1` не получает ответа: >10 с на wesetup.ru и локально (curl ждёт до
тайм-аута). Любой может держать такими запросами соединения и рендеры
сервера.

Причина (Next 16.1.6): `app-render` берёт `isPrefetchRequest` из заголовка,
не проверяя, что это RSC-запрос. HTML страницы рендерится как предзагрузка:
сегменты ниже первого `loading.tsx` (а без него — вся страница под корневым
layout) не создаются, `layout-router` на сервере вызывает
`use(unresolvedThenable)`, и HTML-поток не завершается никогда.

Proxy исправить не может: адаптер Next вырезает служебные заголовки роутера
(`FLIGHT_HEADERS`) до proxy и возвращает их после с пометкой «not
overridable». Nginx на сервере без sudo не правится.

## Решение
`src/instrumentation.ts` (Node.js) один раз ставит перехват события
`request` у `http.Server` (Next создаёт сервер через `http.createServer`):
у запроса без `RSC: 1` и не на `.rsc`-путь удаляются `next-router-prefetch`,
`next-router-segment-prefetch`, `next-router-state-tree` — без RSC они
ничего не значат. RSC-запросы (настоящие переходы и предзагрузка) не
трогаются. Любая ошибка внутри перехвата не мешает запросу.

## Критерии приёмки
- AC1. Функция чистки: без `RSC: 1` — три заголовка удалены; с `RSC: 1` или
  на `.rsc`-пути — не тронуты; прочие заголовки не тронуты.
- AC2. Перехват на настоящем `http.Server`: обработчик видит запрос уже без
  заголовков; повторная установка не ставит второй перехват; ошибка внутри
  не ломает запрос.
- AC3. Production-сборка (`next build` + `next start`): до правки запрос
  `/login` с `Next-Router-Prefetch: 1` висит (воспроизведено), после —
  200 быстрее 2 с, тот же HTML, что без заголовка; RSC-предзагрузка
  (`RSC: 1` + `Next-Router-Prefetch: 1`) по-прежнему отдаёт `text/x-component`;
  клиентские переходы в браузере работают.
- AC4. `npm run typecheck`, `npm run test:gate` зелёные.
- AC5. После деплоя: на wesetup.ru запрос с заголовком отвечает 200.
