# QR-ролик лендинга: упростить подачу (по замечаниям владельца)

Дата: 2026-09-24. Исходное состояние: master b0acb1de (ролик от 23.09).

## Замечания владельца (дословно)

> «прям заметно разговорчивый… упростить эту страницу особенно по тексту оч
> много сверху снизу, сделать вкладки с оборудованием в строчку со слайдами,
> может под спойлер спрятать крутилку снизу или ещё как-то. Попроси покритиковать.»

Плюс из исходной постановки: подача — через QR-коды, в ролике — **как реально
заполняются наши журналы** (это уже выполнено: тексты сцен привязаны к
продукту тестом `qr-player.test.ts`, свойство сохранить).

## Диагноз (скрины «до»: shots/before-qr-*.png)

На 390px секция #qr — ~2700px скролла:
1. Абзац над роликом — 7 строк (260 знаков, 4 предложения).
2. Ряд управления: play + 2 skip + скраббер + время.
3. Чипы глав переносятся в 3 строки (3+2+1).
4. Подпись: 2 строки синего названия журнала + 4 строки абзаца.
5. Большая карточка «Попробуйте сами» со слайдером и вердиктом.

На 1440px: мёртвая зона слева-снизу сцены, блок в сумме ~2 экрана.

## Решение

Структура блока после правки:

```
[вкладки-главы: ОДНА строка, горизонтальный скролл со снапом, актив
 подъезжает сам; заливка-прогресс в активной вкладке = прогресс слайда]
[СЦЕНА (без изменений внутри)]
[тонкая полоса перемотки 6px вплотную под сценой, метки глав; бегунок
 проявляется на hover/focus]
[одна строка: ▶ · 0:04/0:36 · короткая подпись главы · «Попробуйте сами» ▸]
[спойлер (details, закрыт по умолчанию): оба слайдера — холодильник и
 термометр; сдвиг слайдера перематывает на итоговый кадр своей главы]
```

Изменения по файлам:

- `src/app/page.tsx` — абзац секции #qr: 4 предложения → 1–2 коротких
  («Пропустили — ответственный узнает» рассказывает глава 5, из шапки убрать).
- `src/components/landing/qr-player/chapters.ts` — новое поле `short`
  (видимая подпись главы, ≤ 80 знаков). Полный `caption` остаётся для
  скринридера и раскадровки reduced-motion.
- `src/components/landing/qr-player/qr-player.tsx` — новая раскладка:
  вкладки над сценой (одна строка, скролл, автоподвоз актива без прокрутки
  страницы), убрать кнопки SkipBack/SkipForward (вкладки + Shift+стрелки),
  тонкий скраббер, строка play+время+подпись, «Попробуйте сами» → `<details>`
  с ОБОИМИ слайдерами (не зависит от текущей главы). Клавиатура как была:
  Space — пауза (не на кнопках/summary/слайдерах), стрелки — перемотка,
  Shift+стрелки — главы.
- `src/app/globals.css` — `.qrp-tabs` (скролл без скроллбара, mask-fade по
  краям), `.qrp-range-thin` (трек 6px→компакт, тонкий бегунок с проявлением),
  стили `details/summary` спойлера.
- `src/components/landing/qr-player/qr-player.test.ts` — assert: у каждой
  главы есть `short`, короче `caption`, ≤ 80 знаков.

Не трогаю: scene.tsx (вся анимация), clock.ts, qr-matrix/qr-sticker, нижний
блок #start, секцию «Автоматизация».

## Acceptance criteria

- AC1: на 390px вкладки глав — одна строка (горизонтальный скролл), без
  переноса; активная видна при автопереключении глав.
- AC2: видимый текст под сценой — не больше одной короткой подписи главы
  (+ время); полный caption остаётся в sr-only/раскадровке.
- AC3: «Попробуйте сами» по умолчанию свёрнут; в развёрнутом виде оба
  слайдера работают и перематывают на итоговый кадр своей главы.
- AC4: скраббер остаётся доступным (input[type=range], aria-valuetext),
  но визуально — тонкая полоса под сценой.
- AC5: абзац секции над роликом ≤ 2 предложений.
- AC6: `npm test` и `npm run typecheck` зелёные; тексты сцен по-прежнему
  сверяются с продуктом.
- AC7: высота секции #qr на 390px сокращается ≥ 25% против «до».
