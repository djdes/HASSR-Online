# Офис при одной торговой точке — spec (frozen)

Повод (2026-11-12): клиент создал торговую точку, но на «Моя компания → Офис»
видит «Офис появится вместе с торговыми точками» и не может завести
сотрудников и журналы офиса. Причина: страница и `POST /api/settings/office`
требуют `perLocationJournals = true`, а тумблер на «Торговых точках»
включается только при двух зданиях — с одной точкой путь закрыт.

## Acceptance criteria

- AC1. Если в организации есть хотя бы одна торговая точка (не офис), страница
  «Офис» показывает блок «Выделите офис» с кнопкой — независимо от
  `perLocationJournals`. Без точек — пояснение «сначала добавьте торговую точку»
  со ссылкой на «Торговые точки».
- AC2. `POST /api/settings/office` при ≥1 точке создаёт офис (если его нет) и
  включает `perLocationJournals` (офис + точка = журналы раздельно, в шапке
  появляется переключатель «Офис / точка»). Без точек — 400 с понятной ошибкой.
  Офис уже есть, но деление выключено, — кнопка снова включает деление.
- AC3. Блок «Выделите офис» говорит, что журналы офиса и точек будут раздельными,
  в шапке появится переключатель, уже заполненные документы останутся общими.
- AC4. Тексты в ru/en/uz, `npm run i18n:types` актуален.
- AC5. Логика выбора состояния страницы — чистая функция с тестом;
  `npm run typecheck` и `npm run test:changed` зелёные.
