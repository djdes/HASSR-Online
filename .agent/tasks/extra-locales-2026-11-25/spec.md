# Дополнительные языки: таджикский, армянский, киргизский, немецкий, французский

Запрос владельца (2026-11-25): «добавить доп. языки — узбекский, таджикский, армянский,
киргизский, немецкий, французский — во все части сайта через переводы, продумать, сделать, засидить».
Узбекский уже был (полный словарь), добавляются tg, hy, ky, de, fr.

## Критерии приёмки
- AC1. `LOCALES`/`OFFERED_LOCALES` содержат ru, en, uz, tg, hy, ky, de, fr; все переключатели языка их предлагают.
- AC2. У каждого нового языка полный каталог `messages/<locale>.json` (+ pricing, confirm, errors):
  переведённые строки из `messages/translated/<locale>.json`, непереведённые — из языка-подстраховки
  (`FALLBACK_LOCALE`: ru для tg/hy/ky, en для de/fr). Сырые ключи нигде не показываются.
- AC3. Каталоги собирает `npm run i18n:locales` (scripts/i18n-seed-locales.ts); `--check` в тесте ловит устаревшие;
  `--ai` досеивает недостающие строки через очередь AI-диспетчера; редактор переводов и
  `/api/translations/auto` работают со всеми языками.
- AC4. Переведены вручную ключевые разделы на всех 5 языках: навигация, общее, вход/регистрация,
  оболочка кабинета, лендинг, публичная шапка/меню, главная, дашборд, мини-приложение, уведомления, ошибки, цены.
- AC5. Публичные адреса `/tg`, `/hy`, `/ky`, `/de`, `/fr` работают; в hreflang и sitemap — только ru/en/uz
  (частичные переводы не отдаются в индекс).
- AC6. PDF/DOCX и контент, существующий только на ru/en/uz, берут язык-подстраховку (`baseLocale`).
- AC7. `npm run typecheck` и `npm run test:changed` зелёные.

## Доработка 2026-11-26: без полных копий каталогов
Деплой #355 упал на сборке Next (heap ~8 ГБ). Полные `messages/{tg,hy,ky,de,fr}.json` (≈11 МБ,
87% — копия ru/en) удалены; в сборку идут только `translated/<locale>.json` (≈0,3 МБ каждый),
недостающее накладывает `loadBaseMessages` (`overlay-messages.ts`) из языка-подстраховки.
- AC8. Полных копий нет; `loadBaseMessages(tg|hy|ky|de|fr)` даёт каталог без расхождений с ru (validateCatalog).
- AC9. `npm run i18n:locales --check` ловит неочищенные translated-файлы; confirm/errors для новых языков не меняются.
