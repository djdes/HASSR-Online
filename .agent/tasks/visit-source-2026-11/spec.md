# Источник визита: коротко во всех TG-уведомлениях и в карточке клиента

Task ID: visit-source-2026-11 · Заморожено до реализации.

## Критерии приёмки
- AC1. Первое касание посетителя (посадочная, referrer без query, utm, метка клика yclid/gclid) запоминается на любой странице сайта в cookie `wesetup_src` на 180 дней. Касание «прямой заход» заменяется первым содержательным (поиск, реклама, соцсети).
- AC2. Каналы различают: Яндекс Директ, Google Ads, utm, поиск Яндекса/Google/Bing/Mail.ru/другой поисковик, ИИ-ассистенты, Telegram, VK, MAX, соцсети, другие сайты, прямой заход, партнёр, рекомендация.
- AC3. Во всех уведомлениях о действиях клиентов через `notifyPlatformAdmin(..., { client })` и в уведомлении о скачивании шаблона есть короткая строка `Источник: Поиск Яндекса` (`Яндекс Директ · кампания`, `ИИ-ассистент · chatgpt.com`). Без данных строки нет. Строка не дублируется.
- AC4. Источник сохраняется: в `Organization.signupSourceJson` (регистрация с лендинга, /register, быстрая регистрация из окна шаблона, заявка на показ без источника у организации), в новое поле `CrmContact.visitSourceJson` (скачивание шаблона, заявка на показ). Первое касание не перезаписывается.
- AC5. Источник виден в админке: карточка организации (шапка) и карточка CRM-контакта.
- AC6. Тексты UI на ru/en/uz; typecheck и тесты гейта зелёные (кроме уже красного на master `no-blank-word`).
