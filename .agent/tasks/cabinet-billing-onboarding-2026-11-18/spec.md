# Spec (frozen 2026-11-18): счета и выгрузки, точки только в шапке, мастер первого входа, оборудование без автонабора

Запрос владельца:
1) Протестировать все выгрузки и выставление счетов в личном кабинете — визуально и технически, на реальных
   данных, потом удалить данные.
2) Смена точек — только сверху (шапка) по всему сайту, без дублей на страницах.
3) При первой регистрации после первого окна (анкета) — шаг 2 объекты, шаг 3 сотрудники, шаг 4 оборудование;
   необязательные, с кнопкой «Пропустить», но вести пользователя.
4) Оборудование «по образцу» не должно создаваться «автоматом» — только явной кнопкой.

## Исходное состояние (master b62f03e5c)

- Счета: `PaymentOrder` (`paymentMethod="invoice"`), `POST /api/payments/invoice`, PDF `GET /api/payments/invoice/[id]/pdf`,
  пополнение баланса счётом `POST /api/balance/topup {method:"invoice"}`, УПД `GET /api/closing-documents/[orderId]/pdf`.
  Реквизиты продавца — `PlatformSetting legal.requisites`. Выгрузки: архив журналов (ZIP Excel), аудит CSV, сотрудники XLSX,
  отчёты PDF/XLSX, пакет для проверки ZIP/PDF, PDF документов журналов, премии CSV, ПК пакет ZIP/PDF.
- Точки: кроме переключателя в шапке, выбор точки есть на страницах: чипы «Где работает» (/settings/users),
  чипы мест (/settings/areas, /settings/equipment), чипы точек (/journals/points), ряд точек (/monitoring),
  ряд точек (ПК → плакаты), выбор точки в «Реквизитах для документов» (/settings/organization/documents),
  выбор точки в карточке значка (public-badge-card).
- Анкета `CompleteProfileModal` (complete-profile-nudge.tsx): шаг анкеты, при «Объектов ≥ 2» — «Назовите точки».
  Шагов «Сотрудники» и «Оборудование» нет.
- Мастер «+ Добавить точку» (`/settings/buildings/new`): на шаге «Оборудование» уже выставлено 1 холодильник и
  1 морозильник (`TYPICAL_EQUIPMENT`), помещения типового набора отмечены — нажав «Дальше», человек создаёт
  оборудование «по образцу» не выбирая его.

## Критерии приёмки

- **AC1. Счета и выгрузки проверены на реальных данных.** Локальный полный стек (PostgreSQL + next dev): тестовая
  организация зарегистрирована через интерфейс, анкета заполнена, реквизиты продавца заполнены. Проверено и
  задокументировано в `evidence.md` со скриншотами/файлами в `raw/`: (a) счёт за тариф из «Подписки» — PDF
  открывается, сумма/реквизиты/ИНН покупателя верны, повторный запрос не плодит счёт; (b) счёт на пополнение
  баланса — PDF; (c) отметка «оплачен» root-ом → история платежей показывает оплату и УПД скачивается;
  (d) выгрузки кабинета (архив журналов ZIP, аудит CSV, сотрудники XLSX, отчёт PDF и XLSX, пакет для проверки,
  PDF документа журнала) отдают 200 и валидные файлы. Найденные ошибки исправлены (или вынесены в отчёт, если
  вне объёма). После проверки тестовые данные удалены из БД (проверка запросом: 0 строк).
- **AC2. Точки — только в шапке.** На /settings/users, /settings/areas, /settings/equipment, /journals/points,
  /monitoring, ПК-плакатах, /settings/organization/documents и в карточке значка нет своего выбора точки;
  списки и формы берут точку из шапки («Вся организация» в шапке — всё). Переключатель в шапке есть на этих
  страницах. Кнопки-действия («Открыть в точке», «Перейти в точку объекта») остаются — это не выбор, а переход.
  Mini App не меняется.
- **AC3. Мастер первого входа из 4 шагов.** После «Готово» в анкете окно не закрывается, а ведёт дальше с
  индикатором «Шаг N из 4»: шаг 2 «Объекты» (названия и адреса точек; можно добавить ещё объект), шаг 3
  «Сотрудники» (добавить сотрудника: ФИО + должность; список добавленных), шаг 4 «Оборудование» (типовое
  оборудование — ничего не отмечено заранее, человек сам выбирает; объект, если их несколько). У каждого шага
  кнопки «Пропустить» и «Далее»/«Готово»; крестик закрывает мастер. Данные создаются через существующие API
  (`/api/settings/buildings`, `/api/staff`, `/api/positions`, `/api/areas`, `/api/equipment`), ошибки тарифа
  показываются тостом и не ломают мастер. Тексты — в ru/en/uz, `message-contract.d.ts` перегенерирован.
  Проверено в браузере (компьютер и телефон) на свежей регистрации.
- **AC4. Оборудование только по явной кнопке.** В мастере «+ Добавить точку» на шаге «Оборудование» все
  количества по умолчанию 0; типовой набор (холодильник + морозильник) добавляется только кнопкой
  «Добавить типовой набор». Тест фиксирует нулевые значения по умолчанию.
- **AC5. Проверки.** `npm run typecheck` и `npm run test:changed` зелёные; затронутые тесты обновлены.

## Уточнение к AC2 (до реализации этой части, 2026-11-18)

«Реквизиты для документов» (/settings/organization/documents) и карточка значка (/settings/organization) — разделы
всей компании: шапка там принудительно стоит на «Организации» (`point-section-sync.ts`, COMPANY_WIDE_SECTIONS).
Выбор объекта в этих формах — это не смена рабочей точки, а выбор, чьи реквизиты править / для какой точки печатать
табличку; без него реквизиты остальных точек стали бы недоступны. Эти два места остаются как есть и в AC2 не входят.
