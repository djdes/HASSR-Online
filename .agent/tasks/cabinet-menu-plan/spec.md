# Меню профиля «Мой кабинет» + блок «Ваш план» (2026-10-01)

Задача оркестратора (ветка `feat/cabinet-menu-plan-2026-10-01`). Dev-серверы, сборку и браузеры владелец запретил —
проверка только `npm run typecheck`, `npm test`, юнит-тесты; экраны владелец смотрит на проде.

## Правка 1 — меню профиля (`profile-sheet.tsx`, `header.tsx`)
- AC1. Под именем и почтой — карточка «Мой кабинет»: тариф («Подписка» / «Бесплатный» / «Подписка — бесплатно по 10 октября» /
  «Нужно выбрать тариф»), строка «N организаций · M сотрудников», сумма в месяц с расшифровкой превышения
  («4 790 ₽/мес: 1 990 ₽ + 28 × 100 ₽ сверх 10», со скидкой навсегда/акцией — итог со скидкой), ссылка «Изменить тариф»
  (на бесплатном — «Подключить подписку») → `/settings/subscription`, пометка «сейчас»; нажатие — в свой кабинет (`/dashboard`).
- AC2. Строка тарифа из шапки меню убрана (не дублируется).
- AC3. Ниже — «Организации этого кабинета» (переключатель с шестерёнкой), затем «Другие кабинеты» (партнёрский, мастер-кабинеты,
  создание мастер-кабинета). Пункт «Моя организация» убран.
- AC4. Цифры только из существующих источников: места и сотрудники — `loadBillingUnit` (мастер-кабинет +1 в пищеблоке),
  цена — `quoteSubscription` + акция (`getDisplayOffer` → `applyPromotion`) + скидка навсегда (`readActiveLifetimeDiscount`).
- AC5. Кто что видит: сотрудник без права на тариф — только название; в приложении WeSetup — только название, без цены и ссылки;
  ROOT «войти как» — как сейчас (видит как руководитель).

## Правка 2 — `/settings/subscription`, «Ваш план»
- AC6. Название — «Подписка» (не «Платный»).
- AC7. Расчёт строками: «Подписка до 10 сотрудников — 1 990 ₽», «Сверх 10: 28 × 100 ₽ — 2 800 ₽», «Итого 4 790 ₽/мес»;
  со скидкой — старая сумма зачёркнута (`PromoPrice`); при ≤ 10 строки превышения нет; на бесплатном — «1 сотрудник бесплатно;
  для команды — подписка …» с расчётом для нынешнего числа.
- AC8. «Перейти на бесплатный» (активных > 1) — окно выбора, кто остаётся (по умолчанию текущий руководитель), затем
  подтверждение; остальные в архив, записи сохраняются. Переиспользует `billing-transition-gate.tsx` и
  `/api/settings/subscription/transition`. API разрешает добровольный переход (те же проверки прав), аудит
  `billing.transition.voluntary_free`, лог `[billing] voluntary downgrade …`.
- AC9. Реально оплачено (срок в будущем) — в окне: оплаченный срок до <дата> не сохранится, автопродление выключится,
  вернуть неиспользованную часть — по заявлению (п. 6.2 оферты). В приложении WeSetup кнопки нет.
