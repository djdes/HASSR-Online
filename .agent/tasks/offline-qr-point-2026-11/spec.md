# Spec (frozen 2026-11-10): QR точки без связи открывает сотрудников своей точки

Запрос владельца (проверка на планшете): «На планшете авторизовался, выключил интернет, отсканировал QR код
который есть в одной из точек в режиме без интернета, показывает 1 пользователя не сотрудника. Если тот же QR
отсканировать с телефона с камеры где есть интернет, то показывает правильных пользователей. Глобально надо
исправить.»

## Причина

Данные для работы без связи (`buildOfflinePack`) собирались только по точке, выбранной в кабинете у вошедшего
(на планшете — «Офис»): документы журналов и объекты других точек в данные не попадали. Адрес QR разбирался без
точки: токен плаката точки (`journal:<орг>:<код>:b~<точка>`) на устройстве не читался. Плакат «Д/с №68» открывал
документ «Офис», в «Кто вы?» — сотрудники офиса (один администратор). Страница с интернетом берёт точку из
токена: документы этой точки и общие, сотрудники этой точки.

## Критерии приёмки

- **AC1.** Данные содержат журналы, документы и объекты всех точек организации, список точек (кто работает, какие
  журналы выключены) и точку, выбранную в кабинете.
- **AC2.** Плакат журнала точки без связи открывает документы этой точки и общие — как страница с интернетом
  (`scopeDocumentsToBuilding`); в «Кто вы?» — сотрудники этой точки. Общий документ, открытый плакатом точки, —
  сотрудники этой точки. Дополнительный QR документа открывает свой документ. Короткий QR из шапки печатного
  журнала точки (`/qj/<точка>/…`) — документы этой точки.
- **AC3.** Наклейка холодильника, помещения, лампы, фритюрницы другой точки без связи открывается (раньше —
  «объекта нет в сохранённых данных»).
- **AC4.** «Все журналы» точки открывает главный экран этой точки. На главном экране при нескольких точках —
  выбор точки (по умолчанию выбранная в кабинете; выбор запоминается на устройстве); журнал, выключенный на
  точке, на её экране не показывается.
- **AC5.** Данные, сохранённые прежней версией, обновляются сами при первом выходе в сеть (версия пакета 2);
  до обновления экран работает как раньше.
- **AC6.** `npm run typecheck`, `npm run test:gate`, `npm run i18n:check` зелёные; прежний сквозной сценарий
  работы без связи проходит.

## Что НЕ входит

- Проверка подписи токена на устройстве: секрет есть только у сервера; запись проверяется при отправке, как раньше.
- Перенос документа на новый период без сети (первый скан 1-го числа) — делает сервер.

## Что меняет выкат

Только код сайта. База и переменные сервера не меняются. Новая сборка APK не нужна: экран работы без связи
приложение берёт с сайта. Планшету нужно один раз открыть приложение с интернетом — данные обновятся.
