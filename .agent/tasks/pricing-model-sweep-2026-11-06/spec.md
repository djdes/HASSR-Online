# Финансовая модель по всему сайту: «ВИП» и шкала скидок везде, где перечислены тарифы

Задача владельца 06.11.2026: утвердить модель — Стандарт 1990/2990, Премиум 3990/4990, ВИП 8990/12990 ₽/мес
(за год / помесячно), шкала скидок за организации и точки 1–4 / 5–9 −5 % / 10–14 −10 % / 15–34 −20 % /
35–49 −25 % / от 50 — индивидуально; «сделай так по всему сайту, если ещё не сделано».

Что уже сделано до задачи (05.11, коммиты 586666c, 96edc70) и проверено на проде 06.11:
- `DEFAULT_PLAN_RATES`, `POINTS_DISCOUNT_STEPS`, `POINTS_INDIVIDUAL_FROM = 50`, тариф «ВИП» в оплате, КП, счёте;
- живые цены `/pricing`: standard 2990/1990, premium 4990/3990, vip 12990/8990; витрина с колонкой «ВИП»,
  горячая линия «до 10 часов в месяц», расширенный банк данных, личный консультант;
- состав тарифов на витрине совпадает с формулировкой владельца.

Остаток (эта задача): тексты, где тарифы перечислены без «ВИП», устаревшее «Три тарифа», нет «от 50 —
индивидуально» в подсказке выбора точек, нет «ВИП» в SEO-разметке главной и в счётчике оплативших в ROOT.

Решения:
- Строки, где «Премиум» назван как минимальный тариф для возможности или мест («Перейти на „Премиум“»),
  не трогаем — они верны и для «ВИП».
- Исторические заметки «Что нового», объявления, тексты Яндекс Директа и подтверждённая акция `/vizitka`
  («Стандарт» и «Премиум», решение 04.11) не меняем — сказать в отчёте.
- Граница «от 5» трактуется как 5 точек и больше (решение владельца 05.11, код не меняется).

## Критерии приёмки

- AC1. Заголовок тарифов на главной — «Четыре тарифа» (ru/en/uz); подсказка выбора точек на витрине
  заканчивается «от 50 — индивидуальное предложение» (ru/en/uz).
- AC2. SEO-разметка главной (Product.offers) содержит «ВИП» с ценой «от» (за год, с акцией) и описанием
  (`landing.seo.vipDescription` ru/en/uz).
- AC3. Перечисления платных тарифов включают «ВИП»: CTA каталога журналов, лимит журналов и загрузки
  документов, окно после пробного (подсказка и тексты писем «от … ₽/мес»), восстановление из архива,
  прежний тариф, правило мест, перевод партнёрской организации, ошибка ROOT про дату, ошибка `upgrade`,
  SEO-лендинг. ru/en/uz.
- AC4. «Тарифы» в ROOT показывают число оплативших «ВИП» рядом со «Стандартом» и «Премиумом».
- AC5. Цены и шкала не меняются: `DEFAULT_PLAN_RATES` и `POINTS_DISCOUNT_STEPS` совпадают с моделью (тест).
- AC6. `npm run typecheck`, `npm run test:gate`, `npm run i18n:check`, eslint по изменённым файлам — зелёные.
