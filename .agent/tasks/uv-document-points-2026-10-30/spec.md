# УФ-лампы одной точки видны во всех точках (2026-10-30)

Владелец, скриншот: точка «Одинцовская Лингвистическая Гимназия», журнал учёта
работы УФ бактерицидной установки — в «Активных» лампы «Рециркулятор "Гелиос"
№1–3» 4 гимназии. «Исправь прямо сейчас, чтобы не нужно было пересоздавать
документы или что-то менять, и чтобы такого больше не повторялось. Найди
ошибки в коде».

## Причина (по коду; прод-БД прочитать не дали — классификатор)

Список документов точки = документы точки + документы без точки
(`buildingWhere`). Документы ламп без точки висят во всех точках.

1. `ensureUvDocumentForLamp` (QR «Я включил») до 2026-10-29 создавал документ
   лампы без точки. Исправление 10-29 касалось только новых документов:
   найденный документ месяца (связанный или по номеру) оставался без точки.
2. Связь «по номеру» могла взять документ одноимённой лампы другой точки.
3. Новый период (`loadCarriedStructure`, автосоздание по точкам) копировал
   конфиг УФ из последнего документа «точки или общего» — лампу чужой точки
   или общего цеха в документ точки (журнал лампы размножался по точкам).
4. Перенос лампы в другой цех / цеха на другую точку не трогал её документы.
5. Список УФ не показывал пометку «Общий» у документов без точки.

## Правило

Документ журнала УФ-лампы живёт на точке цеха лампы
(`src/lib/uv-document-points.ts`):
- без точки или на удалённой точке → на точку цеха лампы;
- активный на другой точке → тоже;
- закрытый на живой точке → не трогаем (история);
- лампа в цехе без точки или удалена → как есть.
Лампа документа — `config.equipmentId`, иначе номер = название ровно одной лампы.

## Критерии

- AC1. Чистая функция `uvDocumentPointFixes` реализует правило; юнит-тесты.
- AC2. Открытие журнала УФ переносит документы до выборки — без «Пересоздать».
- AC3. Часовой крон `uv-lamp-running` переносит по всем организациям.
- AC4. QR лампы: найденный документ получает точку лампы; при нескольких
  документах лампы берётся документ её точки; «по номеру» не берёт документ
  другой точки.
- AC5. Новый период не копирует лампу чужой точки / общего цеха в документ
  точки; тест в `journal-structure-carry.test.ts`.
- AC6. Смена цеха у лампы или точки у цеха — документы ламп следом.
- AC7. Список УФ показывает «Общий» у документа без точки.
- AC8. «Что нового» обновлено; typecheck и тесты зелёные; проверка на e2e-БД.
