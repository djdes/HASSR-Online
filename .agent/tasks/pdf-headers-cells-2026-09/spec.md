# Spec (frozen 2026-09-25): печать журналов — рамки шапок, выравнивание по центру, жирный, короче текст

Замечания владельца по печати (фото гигиенического журнала): «Исправить во всех журналах бордеры у заголовков. Должно быть красиво всё везде. Посмотри централизацию в ячейках текста — где-то по центру, где-то сверху; надо, чтобы везде по центру. Добавим жирности на некоторых словах, где уместно. Сократим текст про смены».

Всё — в `src/lib/document-pdf.ts` (и связанных модулях шапки/таблиц), для всех 45 журналов каталога:
1. **Рамки шапок**: шапка бланка (блок «организация | СИСТЕМА ХАССП | название журнала | начат/окончен | СТР. X ИЗ N | периодичность контроля») — одинаковая толщина линий, без двойных и наезжающих линий, углы сходятся, ширина шапки совпадает с шириной таблицы под ней, одинаковые отступы. Найти общий код шапки; если шапки рисуются по-разному в разных журналах — привести к одному виду, не меняя содержание.
2. **Выравнивание в ячейках**: весь текст в ячейках шапки и таблиц — по центру по вертикали (autoTable `valign: "middle"` по умолчанию для всех таблиц, ручные ячейки шапки — вертикальное центрирование по высоте ячейки). Горизонтальное выравнивание не ломать там, где оно осмысленно (длинный текст — слева), но однострочные короткие значения и заголовки столбцов — по центру.
3. **Жирный**: название журнала, «СИСТЕМА ХАССП», подписи шапки («Периодичность контроля», «Начат/Окончен», «СТР.»), заголовки столбцов таблиц — жирным, если шрифт это поддерживает (проверить, что у Unicode-шрифта журнала реально есть жирное начертание; если нет — подключить жирный TTF, лёгкий, того же семейства; проверить, что кириллица печатается).
4. **Короче текст про смены** (периодичность в шапке гигиенического и других журналов, где он длинный): например вместо «Ежесменно перед началом смены — всех для сотрудников производства; для других сотрудников компании — при визите на производственный участок (однократно перед проходом на участок)» — «Перед каждой сменой — сотрудники производства; остальные — перед входом на участок». Смысл сохранить, найти и сократить все подобные длинные тексты периодичности.
5. Не менять состав граф и официальные названия журналов/форм.
