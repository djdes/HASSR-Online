# Evidence: печать журналов — рамки шапок, центрирование, жирный, короче периодичность

Спека: `spec.md` (заморожена, коммит 1e94cd57). Проверки — на текущем коде ветки, 2026-09-25.

## Что сделано

- `src/lib/pdf-journal-font.ts` (новый) — «JournalUnicode» с настоящим жирным: `DejaVuSans-Bold.ttf` 2.37,
  урезан fontTools до латиницы/кириллицы/пунктуации/знаков (°, №, ₽, стрелки, ✓) — 197 КБ, лицензия та же
  (`pdf-fonts/LICENSE-DejaVu.txt`). Раньше bold/italic регистрировались ТЕМ ЖЕ файлом, что normal, —
  «жирный» печатался тонким. Общий регистратор используют document-pdf и оба чек-листа.
- `src/lib/pdf-journal-table.ts` (новый) — `journalAutoTable`, через который идут ВСЕ таблицы бланков
  (document-pdf, чек-лист уборки/проветривания, чек-лист санитарного дня):
  valign `middle` у каждой ячейки; одна толщина рамок 0,2 мм (тема `grid` рисовала шапку таблиц с
  `lineWidth: 0` — у таблиц без явной толщины заголовки столбцов были без рамок); заголовки столбцов —
  жирные и по центру на светло-сером (без цвета тема красила шапку бирюзой); столбцы только из коротких
  значений (числа/даты/время/«+»/«—»/≤3 символа) — по центру. Разметка ширин/переносов шапки считается
  обычным начертанием (как было), жирным текст рисуется при отрисовке с подгонкой кегля (≥80 %),
  поэтому число страниц не растёт.
- `drawJournalHeader` (единая шапка ХАССП): линии 0,2 мм = толщина таблиц; горизонталь под «СИСТЕМА ХАССП»
  одной линией; текст ячеек по центру по вертикали (раньше базовая линия ставилась в центр ячейки —
  надписи «висели» у верхней рамки); «СИСТЕМА ХАССП», название журнала (вместо курсива), «Начат/Окончен»,
  «Периодичность контроля», «СТР. X ИЗ N» — жирным; высоты строк — по числу строк текста.
  `drawTitle` (крупное название) — жирным, не заходит правее рамки шапки.
- 6 бланков со «своими» шапками переведены на общую `drawJournalHeader`, ширина = ширине таблицы:
  перечень стекла, карточка поломок, журнал аварий, дезинсекция/дератизация, мойка оборудования
  (была таблица-штамп, заголовок стоял по центру книжного листа x=105), интенсивное охлаждение
  («СТР. 1 ИЗ 1» наезжала на рамку); плюс чек-листы уборки/проветривания и санитарного дня (drawHeader
  передаётся из document-pdf). Таблицы с жёсткими ширинами — те же пропорции на всю ширину шапки.
- Периодичность: 31 длинный дефолт + гигиенический сокращены (все ≤ 100 символов; гигиена —
  «Перед каждой сменой — сотрудники производства; остальные — перед входом на участок»).
  Документы, у которых в config сохранён СТАРЫЙ дефолт этого журнала, читают новый короткий
  (`LEGACY_DEFAULT_CONTROL_PERIODICITY`); свой текст владельца не трогается.

  (клиент он в 7-й версии не генерирует), затем `npx tsx prisma/seed.ts`.
