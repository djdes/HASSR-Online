# Документы журналов: доступ по точке (2026-11-01)

Источник: детальный аудит «точка видит только своё» (группа docs). Общая
модель точек — `src/lib/building-scope.ts`, `src/lib/active-building.ts`.

## Критерии приёмки

- **AC1. Документ чужой точки по прямой ссылке — «не найден».** Все
  обработчики `src/app/api/journal-documents/[id]/**`, страница документа,
  её layout (крошки), страница проверки, `api/print/jobs`,
  `api/journals/[id]/row-form`, `api/journals/cleaning/documents/[id]/room-scopes`
  проверяют точку документа общим правилом `canSeeDocumentPoint`
  (`src/lib/document-point-access.ts`): документ точки виден, только если
  она среди доступных человеку точек (как переключатель в шапке —
  `allowedBuildingsForUser`). Общий документ и выключенные точки — без
  ограничения. Назначенный проверяющий документ видит.
- **AC2. Записи журналов без документа (`JournalEntry`).** Список на
  `/journals/[code]` — по точке из шапки (`journalEntryPointWhere`); карточка
  записи, смена статуса и фото к записи (`api/mini/attachments`) — «не
  найдена» для записи цеха / оборудования чужой точки. Новая запись не
  принимает цех / оборудование чужой точки.
- **AC3. «Вся организация» больше не значит «офис или первая точка».**
  Списки документов (`/journals/[code]`, `GET /api/journal-documents`,
  крошки, `/api/journals/[code]/documents-menu`), бейджи `/journals`,
  «Прогресс журналов» (`today-status`), «Догнать пропуски» (`catch-up`, по
  строке на точку) и место отклонения в `POST /api/journals` берут точку из
  шапки (`getViewedPointId` / `viewedPointId`), а не `getActiveBuildingId`.
- **AC4. Создание документа.** `POST /api/journal-documents` принимает явную
  `buildingId` только из доступных точек; в режиме «Вся организация» без
  офиса просит выбрать точку в шапке вместо молчаливой записи на первую
  точку. «Создать все» и автосоздание — только для доступных точек.
- **AC5. Люди и источники документа точки.** Диалоги списка журнала на
  точке предлагают её сотрудников; бракераж готовой продукции — ростер
  документа; протокол / отчёт аудита — планы и протоколы своей точки и
  общие; автозаполнение уборки, климата, холодильников, УФ — люди и цеха
  точки документа; `GET /api/journal-documents/[id]` — сотрудники точки и
  те, кто уже в записях.
- **AC6.** Снимок журнала (`journal-previews?b=`) чужой точки не отдаётся.
- **AC7.** Тесты и проверка типов проходят.

## Вне задачи (решения владельца)

- Печать на принтер точки: у `PrintAgent` нет точки — задание берёт любой
  агент организации. Нужна схема (`PrintAgent.buildingId`) и маршрутизация.
