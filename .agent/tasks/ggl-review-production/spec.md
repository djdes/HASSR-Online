# Проверка площадок GoGetLinks в рабочем интерфейсе

- AC1. Страница передаёт клиенту переводы проверки площадок в текущей локали. Слот без актуальной оценки отображается как ожидающий проверки, отсутствует в очереди и счётчиках ручного подтверждения и не показывает отказ по правам.
- AC2. Стандартный деплой обеспечивает запуск существующего GoGetLinks cron каждые 10 минут без дублей. Запрос использует секрет приложения и локальный адрес. Маршрут самостоятельно перепроверяет старые слоты.
- AC3. Предыдущие слоты остаются доступны, закупки требуют ручного подтверждения, целевые тесты и проверка типов проходят.
