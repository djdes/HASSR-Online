# Spec (frozen 2026-11-11): новое меню по умолчанию, навигация при переключении точек без «выбросов»

Запрос владельца: «Меню по умолчанию сделай новое, слева снизу переключатель убрать. Походи по сайту, потестируй
переключение точек: логично ли меню, не прыгает ли слишком далеко, всегда ли есть кнопка назад. Исправить и сразу
мердж и прод».

## Критерии приёмки

- **AC1. Меню «Новый» у всех.** Шаблон меню кабинета — «Новый» у всех; сохранённый на устройстве «стандартный»
  больше не действует; блок «Вид меню» внизу слева убран.
- **AC2. «Назад» возвращает и точку.** С точки зашли в раздел всей компании (выбор стал офисом) и вернулись назад —
  стрелкой страницы или браузера — точка возвращается. Переход дальше по меню точку не возвращает.
- **AC3. Нажал не туда — одно нажатие назад.** В подсказке об автосмене на офис есть кнопка «Вернуться на „точку“»:
  возвращает точку и страницу, с которой пришли.
- **AC4. Автосмена — на каждый заход.** После возврата точки повторный заход в раздел компании снова переключает
  на офис (раньше защита от петель срабатывала навсегда).
- **AC5. На точке ссылки не выбрасывают в офис.** Звено «Журналы» и запасной «назад» в журнале, «записи ждут
  проверки» и «Все журналы» на «Сегодня» при выбранной точке не ведут на страницу всей организации.
- **AC6. Кнопка назад есть.** На страницах кабинета, кроме главной, есть стрелка «назад» и цепочка разделов.
- **AC7. Проверки.** `npm run typecheck`, `npm run test:gate`, `npm run i18n:check`; обход в браузере.
