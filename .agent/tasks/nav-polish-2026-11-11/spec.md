# Spec (frozen 2026-11-11): подсказка, порядок и вид меню, верхняя строка, мобильное меню

Запрос владельца (7 пунктов, по скриншотам боевого сайта).

## Критерии приёмки

- **AC1. Подсказка об автосмене на офис.** Вёрстка не ломается длинной кнопкой (текст не встаёт столбиком): кнопка
  переносится под текст и обрезается многоточием — правило для всех подсказок кабинета. Сама подсказка короткая,
  живёт 5 секунд, вместо значка — кольцо-отсчёт.
- **AC2. «Моя компания» открывает «Офис».** Раздел главного меню «Моя компания» ведёт на первую строчку своего
  меню — «Офис», а не «Реквизиты».
- **AC3. «Ещё».** «Остальное» переименовано в «Ещё», стоит последним в «Моей компании», серое, с иконкой ромбиков.
  Порядок: Офис, Торговые точки, Мастер-кабинет, Реквизиты, Ещё.
- **AC4. Раздел не про точку ⇒ офис.** Поведение из прошлой задачи сохранено и проверено (раздел всей компании
  при выбранной точке переключает на офис; «назад» возвращает точку).
- **AC5. Иконки меню проще.** В меню «Новый» плашка плоская: мягкая подложка и иконка в цвет пункта, без градиента,
  блика, колец и качания. Выбранный «Мастер-кабинет» остаётся в одну строку.
- **AC6. Верхняя строка в один ряд.** Компактнее; что не помещается по ширине — в выпадающее «Ещё» справа,
  выбранный пункт всегда на виду. 1024–1920px — одна строка.
- **AC7. Телефон — новое меню.** Лист меню — те же два уровня, что слева на компьютере (плоские иконки), список
  прокручивается внутри листа, нажатие на раздел раскрывает его пункты, переход закрывает лист. Третий уровень —
  строка над страницей, прокручивается вбок. Выбор точки — полоса во всю ширину под шапкой; в списке точек офис
  отделён, у точек адреса.
- **AC8. Проверки.** `npm run typecheck`, `npm run i18n:check`, `npm run test:gate`; браузер: компьютер 1024–1920px,
  телефон 390px.
