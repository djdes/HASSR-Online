- Подготовка первого выпуска из ветки `codex/mobile-first-release-2026-10` (07–08.10.2026: проверка перед

  удалена. Единственный запуск «Выпуск приложений» (07.10) упал на шаге секретов: в GitHub нет ключей выпуска.
- Ссылки, которые открываются в приложении (App Links / Universal Links), не знают новых QR-адресов сайта:
  `/q/<токен>` (личный QR-вход), `/qj/...` (QR в шапке печатного журнала), `/pair/<токен>` (настройка входа

  у приложений — тёмно-синий векторный знак. На iPhone у установленного кабинета нет заставки (белый экран при
  запуске), у web-push значок-силуэт — полноцветная иконка (на Android это белый квадрат).
- Скриншоты для магазинов (`docs/mobile/screenshots`) сняты 26.09 со старым интерфейсом.

## Критерии приёмки

### Приложения Android и iOS
- **AC1. Версия 1.1.0.** `mobile/package.json` → `1.1.0`; из неё берутся User-Agent `WeSetupApp/1.1.0 (android|ios)`,
  `versionName` Android и `MARKETING_VERSION` iOS (fastlane). Плагины подняты до проверенных патч-версий
  (вышли ≥ 2 недель назад): `@capacitor/app` 8.1.2, `@capacitor/share` 8.0.3, `@capacitor/status-bar` 8.0.4;
  `package-lock.json` пересобран `npm install`. Остаются как есть, с причиной в README: core/cli/android/ios 8.5.2
  (8.5.3 — правка только для SPM, 8.6.0 вышла 28.10), `@capacitor/filesystem` 8.1.3 (8.1.4–8.1.5 меняли пути на
  iOS, а печать и «Поделиться» пишут файлы через него), `@capacitor-firebase/messaging` 8.5.2 (8.6.0 вышла сегодня).
- **AC2. Ссылки в приложение.** Набор путей — один источник правды `APP_LINK_PATHS` (`src/lib/app-links.ts`, его
  отдаёт `/.well-known/apple-app-site-association`) — дополнен `/q/*`, `/qj/*`, `/pair/*`, `/invite/*`.
  `AndroidManifest.xml` содержит ровно тот же набор: точные пути через `android:path`, разделы — `android:pathPrefix`
  со слешем на конце. Тест падает, если наборы расходятся, и проверяет, что `/journals-info/x`, `/qb/x`, `/b/x`,
  `/inspector/x`, `/pricing`, `/mini-sw.js` не попадают в приложение, а `/mini`, `/mini/today`, `/q/abc`,
  `/qj/a/b/c`, `/pair/t`, `/invite/t`, `/journal-fill/o/c`, `/delete-account` попадают — на обеих платформах.
- **AC3. Выпуск без сюрпризов.** Перенесена подготовка из ветки Codex (переводы строк LF):
  `mobile/scripts/release-preflight.mjs` + тест, `release-manifest.mjs`; выпуск блокируется без ключа подписи,
  паролей, Firebase-файлов или с тестовым адресом сайта, значения секретов в сообщения не попадают.
  «Выпуск приложений»: входы `platform`, `track` (по умолчанию `none`), `play_status` (по умолчанию `draft`),
  `upload_ios` (по умолчанию `false`), `build_number`; Android собирает подписанные AAB и APK, проверяет подписи
  (apksigner, jarsigner), кладёт `release-manifest.json` с SHA-256 и сертификат загрузки; iOS собирает IPA,
  проверяет подпись, bundle id, номер сборки и манифест приватности, загрузка в TestFlight — отдельным шагом.
  Gradle-проверка перед release-сборкой — без устаревшего `project.exec`. `npm run test:release` зелёный.
- **AC4. Манифест приватности iOS.** `mobile/ios/App/App/PrivacyInfo.xcprivacy` (FileTimestamp, причина C617.1)
  входит в ресурсы цели App (`project.pbxproj`); «Проверка приложений» проверяет его в собранном приложении.
- **AC5. Сборки проходят.** Android: `assembleDebug` и подписанный тестовым ключом `bundleRelease assembleRelease`
  с проверкой preflight собираются локально; «Проверка приложений» (Android APK + iOS для симулятора) зелёная на
  ветке задачи.

### PWA (кабинет на домашнем экране)
- **AC6. Иконки.** Новые файлы из того же векторного знака, что у приложений (тёмно-синий фон `#0b1024`):
  `public/icons/app-192.png`, `app-512.png` (purpose `any`), `app-maskable-512.png` (знак внутри безопасной зоны
  80 %), `src/app/apple-icon.png` 180×180 без прозрачности, монохромный значок для push `public/icons/push-badge.png`
  (белый силуэт на прозрачном). Новые имена — чтобы закешированные старые иконки не держались. Манифесты
  ru/en/uz ссылаются на новые иконки; `mini-sw.js` показывает push с новой иконкой и значком-силуэтом.
- **AC7. Заставка iPhone.** В `src/app/mini/layout.tsx` — `apple-touch-startup-image` для портретных экранов
  актуальных iPhone (от SE до 17 Pro Max / Air); картинки — знак на `#0b1024`; тест сверяет, что размер каждой
  картинки равен `device-width × DPR` и `device-height × DPR` из её media-запроса и что файлы существуют.
- **AC8. Манифест.** `categories`, иконки у ярлыков «Сегодня»/«Журналы», `screenshots` (form_factor `narrow`, из
  новых скриншотов) — для расширенного окна установки Android. Локализованные `manifest-en.json`/`manifest-uz.json`
  совпадают с русским во всём, кроме текстов (тест). Существующие проверки манифеста (scope, start_url, цвета)
  остаются зелёными; добавлена проверка, что все файлы иконок/скриншотов существуют и их размеры совпадают с
  заявленными.
- **AC9. Экран «Нет связи» в PWA** — в стиле экрана приложений (фон `#0b1024`, свечение, значок), сам повторяет
  при появлении сети; правило «авторизованный HTML не кешируется» и ручное применение обновления воркера не
  меняются (тесты `service-worker-scope` зелёные).
