# Problems

## AC14 — запуск «Выпуска приложений» после слияния: BLOCKED (права), не код

- `POST /repos/djdes/HASSR-Online/actions/workflows/mobile-check.yml/dispatches` из этой сессии →
  **403 Resource not accessible by integration**: у интеграции GitHub нет права запускать workflow вручную
  (`actions: write`). «Выпуск приложений» запускается только вручную (`workflow_dispatch`), поэтому запустить его
  отсюда нельзя. Добавлять ему автоматический запуск на push неправильно: выпуск подписывает сборки ключами
  магазинов и должен запускаться осознанно.
- Обход для проверки сборок: «Проверка приложений» теперь запускается и на `pull_request` (как
  `setup-helper-check.yml`) — Android (отладочный APK + пробный подписанный выпуск) и iOS (симулятор + манифест
  приватности) проверяются на PR #75 без ручного запуска.
- Что остаётся владельцу: GitHub → Actions → «Выпуск приложений» → Run workflow (ветка `master`, `platform=both`,
  `track=none`, `play_status=draft`, `upload_ios=false`). Первый шаг каждого задания перечислит, каких секретов
  нет; если все на месте — в артефактах будут подписанные AAB, APK, IPA и паспорта с SHA-256.
- Последний известный факт о секретах: запуск 07.10.2026 (#1) остановился на `ANDROID_KEYSTORE_BASE64` и
  `ASC_KEY_P8_BASE64` — их не было.
