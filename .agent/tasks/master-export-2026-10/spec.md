# Spec (frozen 2026-10-19): мастер-кабинет — выгрузка вместо справочника блюд, по правкам партнёра

Источник: два PDF партнёра от владельца (19.10): «Мастер кабинет.pdf» (экран мастер-кабинета) и «Мастер кабинет 2.pdf» (окно «Справочник блюд»). Ветка `feat/master-export` от `origin/master` (`3dc90b30`), worktree `D:/wt/release`.

## Правки партнёра → что делаем
1. «Код справочника» в шапке — «видимо уже не нужно, раз подключаем пищеблоки кодом» → плашку кода из шапки убрать (пищеблоки подключаются кодом журнала объекта во вкладке «Подключённые объекты»).
2. «Подключено объектов: N» и вкладка «Подключённые объекты» — «объединить в одну вкладку сверху» → плашку из шапки убрать, остаётся вкладка со счётчиком.
3. Вкладки: «Справочник блюд» → «Мастер-справочник журнала бракеража готовой продукции»; «Сырьё → Скоропорт» → «Мастер-справочник журнала бракеража скоропортящейся продукции». На телефоне — короткие подписи.
4. «Время для всех строк» и «Проставить всем» — «пока уберём» → убрать из окна выгрузки (стрелка «проставить всем ниже» у строки остаётся).
5. «Можно без двоеточия: 0830 → 08:30» — «двоеточие по умолчанию» → поле времени само ставит двоеточие при наборе («8» → «08:», «0830» → «08:30», «15» → «15:»), стирание работает как обычно; подсказку про «без двоеточия» убрать.
6. «Не вижу смысла сохранять список… открыл выгрузку, в пустые строчки написал, вставил из Excel, подгрузил из файла или ИИ распознал с фото, поставил дату и выгрузил» → вкладка блюд = выгрузка: окно открывается с пустыми строками; заполнение — вручную, вставкой из Excel в ячейку, загрузкой Excel/CSV (в окне и с вкладки), «С фото»; дата; «Выгрузить». Сохранённый список блюд в интерфейсе больше не показывается и не редактируется (данные в БД не удаляем).
7. «Галочкой — в какие пищеблоки выгрузка, по умолчанию все» → в окне выгрузки список подключённых пищеблоков с галочками, все отмечены; выгрузка и предпросмотр — только в отмеченные.

## Не делать
- Не менять вкладку сырья по сути (сохраняемый список, рассылка в журналы скоропорта) — только подпись.
- Не удалять `SharedDirectoryItem` с kind=dish и серверные чтения (подсказки названий у пищеблоков) — вопрос к владельцу в отчёте.
- Не трогать исправление прошлых выгрузок (история, «Исправить выгрузку») кроме общего окна.

## Критерии приёмки
- **AC1** Шапка: нет «Код справочника» и «Подключено объектов»; «Доступ» и переименование кабинета на месте.
- **AC2** Вкладки: «Мастер-справочник журнала бракеража готовой продукции», «Мастер-справочник журнала бракеража скоропортящейся продукции», «Подключённые объекты (N)»; на 390 px вкладки не уходят за край без прокрутки полосы и подписи читаемы.
- **AC3** Вкладка блюд: заголовок и пояснение про выгрузку; кнопки «Выгрузить в журналы», «Загрузить Excel/CSV», «С фото» открывают окно выгрузки (файл и фото — с заполненными строками); нет таблицы сохранённого списка, «Вставить списком» и окна «Справочник блюд»; без подключённых пищеблоков — понятная подсказка «подключите пищеблоки».
- **AC4** Окно выгрузки: пустые строки при каждом открытии (новая выгрузка); нет «Взять из справочника», «Время для всех строк», «Проставить всем строкам»; есть «Загрузить Excel/CSV»; время обязательно у каждой строки с наименованием (понятная подсказка); список пищеблоков с галочками, все отмечены, «Отметить все / снять»; без отмеченных — кнопка неактивна; надпись кнопки «Выгрузить в N пищеблоков».
- **AC5** API `POST /api/master/brakerage`: `organizationIds` (необязательно) — только из пула мастера; пустой список → 400 «Отметьте хотя бы один пищеблок»; чужие id игнорируются, если не осталось ни одного → 400; без поля — как раньше (все). Предпросмотр и запись идут только в выбранные. Сообщение о времени — про строки, без «Время для всех строк». Тесты на фильтр пула.
- **AC6** Поле времени: функция маски с тестами (набор по цифрам, стирание, «25» → «02:5», вставка «0830», текст с точкой/пробелом не ломается); `typingHint` RU/EN/UZ без «без двоеточия».
- **AC7** «Что нового» — категория мастер-кабинета дополнена с точки зрения пользователя.
- **AC8** Проверки: tsc, тесты (гейт), i18n, eslint по изменённым файлам; смоук в браузере (руководитель мастер-кабинета на локальной базе): вкладки, окно выгрузки, галочки, предпросмотр в выбранный пищеблок, запись, снимки.
