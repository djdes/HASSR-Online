This method returns a list of locations.
HTTP Request
GET https://joinposter.com/api/spots.getSpots
Response Parameters for spots.getSpots
Parameter	Description
response	Array of objects
Inside the response parameter, there is an array where each element contains the following parameters:
Parameter	Description
spot_id	Location ID
name	Location name
address	Location address
