# Касса: меню → справочник и бракераж, подключение Poster

- **Task ID:** `pos-menu-poster-2026-11-21`
- **Base:** `origin/master` `b1123dee` (#291)
- **Frozen:** 2026-11-21, before implementation.

## Запрос владельца (21.11.2026)

«Сделай все кроме 6,7» — пункт 2: интеграция с кассами (iiko / r_keeper / Poster): меню → продукты и бракераж.

## Что уже есть

- iiko (iikoServer): приходные накладные → «Входящие накладные» → «Принять» в журнал приёмки; акты списания →
  «Потери»; номенклатура → справочник продуктов, но только товары и заготовки (`GOODS`, `PREPARED`), и все —
  с видом «Сырьё» по умолчанию. Блюда меню (`DISH`) не загружаются.
- Подсказки блюд в журнале бракеража (`/api/name-suggestions?scope=dish`): своя память, пул, меню мастер-кабинета.
  Справочник продуктов (вид «Готовая продукция») в них не участвует — только в чек-листе раздачи.
- Склады iiko сопоставляются с точками (`SupplyConnection.storePoints`).
- Poster и r_keeper — нет.

## Документация Poster (прочитана 21.11.2026, выдержки — `raw/poster-docs/`)

- `GET https://joinposter.com/api/{method}?token=…&format=json`; токен личной интеграции — «Доступ → Интеграции →
  Личная интеграция», вид `номер_аккаунта:ключ`, действует 2 года. Ошибка — `{"error":{"code":11,"message":…}}`
  (10/11/12 — нет/неверный/просрочен токен, 700 — ограничение частоты).
- `storage.getSupplies` (`dateFrom`/`dateTo` в `Ymd`) → поставки (`supply_id`, `storage_id`, `supplier_id`,
  `supplier_name`, `date`, `delete`); `storage.getSupplyIngredients?supply_id` → строки (`ingredient_name`,
  `supply_ingredient_num`, `ingredient_unit` kg/p/l, `supply_ingredient_sum` в копейках).
- `storage.getWastes` (`dateFrom`/`dateTo`) → списания (`waste_id`, `storage_id`, `date`, `reason_name`, `delete`);
  `storage.getWaste?waste_id` → `elements` (тип, `product_id`, `count`, `ingredients` с `weight`, `unit`, `cost`
  в копейках).
- `menu.getProducts` → `product_id`, `product_name`, `type` (1 — полуфабрикат, 2 — блюдо, 3 — товар), `unit`,
  `hidden`; `menu.getIngredients` → `ingredient_id`, `ingredient_name`, `ingredient_unit`.
- `storage.getStorages` → склады; `storage.getSuppliers` → поставщики (`supplier_tin`).

## Решения

- Р1. iiko → справочник с видом продукции: товары (`GOODS`) — «Сырьё», заготовки (`PREPARED`) — «Полуфабрикат»,
  блюда (`DISH`) — «Готовая продукция». Добавляются только недостающие по имени — заведённое руками не трогаем.
- Р2. Подсказки блюд бракеража: после своей памяти — «Готовая продукция» своего справочника (активные), затем
  пул и мастер, как было; без повторов.
- Р3. Poster — новый источник рядом с iiko (`SupplyConnection.provider = "poster"`): подключение по токену
  личной интеграции (проверка запросом складов, токен — только зашифрованным); что забирать: поставки →
  «Входящие накладные» (дальше та же приёмка), списания → «Потери», меню и ингредиенты → справочник с видом
  (блюдо — готовая продукция, полуфабрикат — полуфабрикат, товар и ингредиент — сырьё). Загрузка — тем же
  кроном и кнопкой «Забрать сейчас», что iiko. Склады Poster → точки — тем же сопоставлением, что у iiko.
- Р4. r_keeper не подключаем: открытого API для своего аккаунта у него нет (обмен — через лицензируемые
  интерфейсы у дилера). Записать в документацию.

## Критерии приёмки

- **AC1.** iiko: виды продукции по типам, блюда загружаются, удалённые — нет (тест на чистой функции).
- **AC2.** Подсказки блюд включают «Готовую продукцию» справочника после своей памяти, без повторов и в пределах
  лимита (тест на чистой функции слияния).
- **AC3.** Клиент Poster: адрес и токен по документации, даты `Ymd`, разбор поставок, строк, списаний, меню,
  ингредиентов, складов, поставщиков; ошибки токена и сети понятным текстом без токена (тесты на подменённом fetch).
- **AC4.** Загрузка Poster: поставки → документы «Входящих» (пропуск загруженных и удалённых, склад «не
  загружать» — пропуск), списания → строки потерь без повторов, справочник с видами (тест на подменённом клиенте).
- **AC5.** Настройки Poster: подключить / забрать сейчас / отключить, что забирать, склады → точки; «Входящие
  накладные» и «Потери» показывают источник Poster; карточка в настройках; тексты ru/en/uz, `i18n:types`;
  документация (Poster и почему нет r_keeper).
- **AC6.** typecheck, test:changed, eslint (без новых ошибок), палитра — зелёные.
