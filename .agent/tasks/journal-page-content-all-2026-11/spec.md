# Spec — journal-page-content-all-2026-11 (frozen 2026-11-17)

Запрос владельца: «Сделай такие же разделы для гигиенического журнала и остальных».

Страница `/journals-info/<код>` уже умеет показывать блоки из `JOURNAL_PAGE_CONTENT`
(PR djdes/HASSR-Online#244): образец заполнения строками, тематические разделы, штрафы.
Сейчас контент есть только у `cleaning`.

## Критерии приёмки
- AC1: у каждого из 45 журналов `JOURNAL_INFO` есть блоки: образец (3–8 колонок, 3–6 строк, строки = колонкам, подпись),
  4–6 разделов (кто обязан / как и когда заполнять / на что смотрит проверяющий / типичные ошибки / электронно вместо бумаги — по смыслу журнала),
  блок штрафов (1–4 пункта, только проверенные статьи и суммы КоАП).
- AC2: объём нового текста 380–900 слов на журнал; ключевая фраза (название журнала) — не чаще 3 раз в новом тексте (без переспама).
- AC3: нормативы — только из `JOURNAL_INFO[code].normative` и действующих документов сайта; нет СанПиН 2.3/2.4.3590-20; суммы штрафов — из утверждённого списка.
- AC4: тексты не повторяют то, что уже есть на странице (whatToFill, tips, FAQ «что писать / как часто / норматив / электронно / сколько хранить»).
- AC5: контент разнесён по файлам групп `src/content/journal-page-content/*.ts`; тест `journal-page-content.test.ts` проверяет форму и объём для всех журналов.
- AC6: typecheck, eslint, затронутые тесты зелёные; страницы гигиенического и ещё 3 журналов открываются локально, блоки видны (e2e).
