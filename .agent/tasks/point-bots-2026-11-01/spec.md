# Боты, ИИ-помощник, Mini App и QR — только своя точка (аудит 2026-11-01)

Задача: закрыть утечки между торговыми точками, найденные аудитом «боты /
Mini App / внешние входы». Правило — как в шапке сайта
(`allowedBuildingsForUser`): закреплённый за точками видит только их и
общие объекты; сотрудник офиса и человек без точек — всю компанию.

## Критерии приёмки

- AC1. `managerPointScope` / `loadManagerPointScope` (worker-point-scope.ts):
  офис и без точек → null (вся компания), закреплённый за точками → его
  точки, в организации с офисом и без. Сводка Max руководителя офиса больше
  не сужается до офиса (ошибка прошлой правки #78).
- AC2. ИИ-помощник: в задании только люди и документы точек человека;
  страница документа чужой точки — «не найден»; `fill_journal_cells`
  отказывает в документе чужой точки (превью и исполнение); `add_staff`
  руководителя точки создаёт сотрудника на его точках. То же для
  `/api/assistant/*` (context) и ключей MCP / REST v1 (list_journals,
  get_journal_document, list_employees, add_employee через общие действия).
- AC3. Отчёт ИИ за период, ХАССП-план и СОП считают по точке из шапки.
- AC4. Telegram: `/today`, `/missing`, `/stats`, `/losses`, `/staff`,
  `/who_late` и сводка `/start` руководителя точки — только его точки и
  люди; `/edit` — документы своих точек, без выключенных журналов (набор
  точек человека); инлайн-поиск оборудования — своих точек, ответ
  `is_personal`.
- AC5. Max: сводка и напоминания — по области руководителя; экран
  приглашений и выдача ссылки — только люди своих точек (чужому — 403);
  список журналов и запуск заполнения — набор журналов точек сотрудника.
- AC6. `POST /api/journal-task-claims` — ключ задачи только из подборки
  точек человека (иначе 403); GET — только задачи этой подборки;
  `assign` — задача своих точек и исполнитель, работающий на точке задачи;
  тревога о температуре — точка холодильника из ключа задачи.
- AC7. `/api/journal-task-pool/[code]` и `/api/mini/home` — точки из шапки
  (`getPoolBuildings` / `viewedPointId`), а не офис/первая точка.
- AC8. Наклейки: `qr-fill/pass`, `qr-fill/pin-request`, фото показаний —
  только сотрудник точки объекта (403 «работает на другой точке»);
  превью QR объекта — только объекты своих точек.
- AC9. Бейдж «N записей сегодня» в task-fill — записи точки документа.
- AC10. `npm run typecheck` — 0 ошибок; затронутые тесты зелёные.

Без изменений схемы. Не входит: троттлинг напоминаний Max на организацию
(нужно поле на точку), CAPA и партии без точки (нет поля).
