# Spec (frozen 2026-11-09): памятка по заполнению журналов на одном листе А4

Запрос владельца: «Во вкладке „Журналы“ добавить памятку по заполнению всех журналов на одном листе А4. Кнопка —
в разделе „Сегодня“, между двух кнопок справа („Автозаполнить“ и „QR-коды“). При нажатии отобразить инфу по
каждому журналу и регламент: как часто заполнять, в строчку. Слева логотип, справа — Wesetup. Слева название
журнала, справа — как часто заполнять».

## Исходное состояние (master b1747297)

- «Журналы → Сегодня» (`/dashboard`): в панели над списком две кнопки — «Автозаполнить» и «QR-коды»
  (`CloseDayCard`); при выключенном автозаполнении — одна ссылка «QR-коды».
- Периодичность по каждому журналу каталога уже есть: `DEFAULT_CONTROL_PERIODICITY` (текст шапки документа),
  переводы — `journalWidgets.periodicity.<code>` в ru/en/uz, запасной текст — `fallback`. Тест
  `control-periodicity.test.ts` следит, что текст есть у каждого кода каталога.
- Лист на печать уже есть рядом: `/dashboard/today-print` («Что заполнить сегодня»).

## Критерии приёмки

- **AC1. Кнопка «Памятка».** На «Сегодня» между «Автозаполнить» и «QR-коды» стоит ссылка на
  `/dashboard/journals-memo`. На компьютере — с подписью «Памятка», на телефоне (< 640px) — квадратная кнопка
  с иконкой между двумя кнопками, одна строка, без горизонтальной прокрутки на 360px. Доступное имя —
  «Памятка по заполнению журналов». При выключенном автозаполнении ссылка стоит рядом с «QR-коды».
- **AC2. Лист-памятка.** `/dashboard/journals-memo`: шапка — слева логотип организации (нет логотипа —
  название), справа — знак WeSetup; заголовок «Памятка по заполнению журналов»; далее по строке на журнал:
  слева название (своё название организации, если задано), справа — как часто заполнять. В списке — журналы,
  которые ведёт организация (точка из шапки): активные шаблоны минус отключённые, по алфавиту, как на «Сегодня».
  Журналов нет — понятная строка вместо таблицы.
- **AC3. Один лист А4.** При печати — только лист (меню, шапка кабинета, кнопки «Назад»/«Распечатать» скрыты).
  Кегль печати подбирается по числу строк; полный каталог (46 журналов) помещается на одну страницу А4
  (проверка: PDF из Chromium — 1 страница).
- **AC4. Языки.** Новые подписи — в ru/en/uz, `npm run i18n:check` проходит; периодичность берётся из
  существующих переводов.
- **AC5. Проверки.** `npm run typecheck`, `npm run test:gate`, `npm run lint` (по изменённым файлам) — без новых
  ошибок; есть unit-тест на подбор плотности листа.

## Вне задачи

- Своя (изменённая в документе) периодичность организации: памятка показывает регламент по умолчанию.
- Бумажные журналы сферы (у них нет периодичности в системе).
- Изменения схемы БД — нет.
