# Public WeSetup About page

Frozen before implementation on 2026-11-18.

- AC1. The public journal catalog and shared public footer expose a regular localized link to the dedicated About page. Anonymous readers can reach it at /about, /en/about and /uz/about. The private journal workspace is outside scope.
- AC2. The server renders original, localized copy explaining what WeSetup does, who uses it, and how to start. The page shows a real product screenshot, verified WeSetup contacts and company details, and links to relevant journals, product resources and registration. The page uses the public design system, responsive layout and semantic headings.
- AC3. Each language has a distinct title and description, a self-canonical URL, reciprocal ru/en/uz and x-default alternates, shared social-card conventions, AboutPage and BreadcrumbList structured data, public crawler access, and sitemap inclusion. Structured data matches the site identity and visible content.
- AC4. The translation contract is generated and targeted tests, typecheck and rendered HTTP checks verify the result.

Reference: https://haccp-online.ru/about. Use its product-overview structure as inspiration. Use only WeSetup's own copy, product material and company details.
