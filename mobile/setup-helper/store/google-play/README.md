# «Сетап помощник» в Google Play — что готово и как загрузить

Всё для публикации лежит в этой папке:

| Файл | Что внутри |
|---|---|
| `listing-ru.md` | название, краткое и полное описание, категория, контакты, «Что нового» |
| `data-safety.md` | ответ для анкеты «Безопасность данных» («Нет» — данные не собираются) |
| `app-content.md` | остальные пункты раздела «Контент приложения»: доступ без ограничений, реклама, рейтинг, аудитория, разрешения |

Ссылка для анкеты:

## Сборка для Play

Приложение собирается в двух вариантах (`../../README.md`, раздел «Сборка»):
- **`play`** идёт в Google Play: формат AAB, нет ни самообновления, ни сетевых разрешений (`INTERNET`, `ACCESS_NETWORK_STATE`).
- **`site`** раздаётся на wesetup.ru и проверяет наличие свежей версии APK.

В обоих вариантах **нет авторизации и входа**: приложение открывает сразу главный экран со всеми шаблонами и предпросмотром этикеток, поэтому проверяющим Google Play не нужны учётные данные.

Готовый AAB собирает GitHub:
1. Откройте Actions → «Сетап помощник — проверка».
2. Скачайте артефакт `setup-helper-play-aab-N` — это файл `app-play-release.aab`.

## Порядок загрузки

1. В «Контент приложения → Доступ к приложению» выберите **«Все функции приложения доступны без специальных прав доступа»** (`app-content.md`).
2. В «Контент приложения → Безопасность данных» выберите **«Нет»** — приложение не собирает и не передаёт данные (`data-safety.md`).
3. Заполните карточку магазина текстами из `listing-ru.md` / `listing-en.md` и графикой из `graphics/`.
4. Загрузите `app-play-release.aab` в нужный трек тестирования или в рабочую версию и отправьте на модерацию.
