# Карточка Google Play — «Сетап помощник» (русский, язык по умолчанию)

Скопировать в Play Console → «Развитие» → «Представление в магазине» → «Основная страница».

## Краткое описание (до 80 знаков)

```
Этикетки для кухни на Bluetooth-принтер: шаблоны, сроки годности, история печати
```

## Полное описание (до 4000 знаков)

```
«Сетап помощник» печатает этикетки для кухни и пищевого производства на Bluetooth-принтер — быстро, крупно и без интернета. Приложение входит в WeSetup — электронные журналы СанПиН и ХАССП для общепита.

ЧТО МОЖНО НАПЕЧАТАТЬ
• Маркировка продукта: название, дата и время изготовления, срок годности, ответственный
• Полуфабрикат и готовое блюдо
• Разморозка и заморозка
• Суточная проба
• Приёмка сырья
• Аллергены
• Вскрытая упаковка
• Брак — не использовать
• Произвольный текст

КАК ЭТО РАБОТАЕТ
1. Войдите под учётной записью WeSetup своего заведения.
2. «Добавить оборудование» — приложение найдёт принтер рядом и подключит его. PIN для сопряжения подставляется сам, если Android это позволяет.
3. Выберите шаблон, заполните поля — сроки годности считаются сами — и нажмите «Печать».

УДОБНО НА КУХНЕ
• Крупные кнопки шаблонов, стрелки для перелистывания.
• Предпросмотр: на экране ровно та этикетка, которая выйдет из принтера.
• История печати: повторите вчерашнюю этикетку одним нажатием или поправьте и напечатайте снова.
• Последние введённые значения запоминаются — не нужно набирать заново.
• Работает без интернета: печать идёт напрямую на принтер, отметки для кабинета отправятся, когда появится связь.
• Кириллица печатается на любом принтере: этикетка уходит картинкой.

ПРИНТЕРЫ
Проверено на AIYIN IP-802BT (этикетки 58×40 мм, команды TSPL). Подойдут и другие Bluetooth-принтеры этикеток с TSPL. Размер этикетки, зазор, плотность и поворот настраиваются.

ДЛЯ РУКОВОДИТЕЛЯ
В кабинете WeSetup на сайте видно, какие принтеры подключены и с каких телефонов, когда печатали в последний раз. Ненужный телефон можно отключить с сайта.

Нужна учётная запись WeSetup (wesetup.ru) — у заведения или его руководителя. Вопросы и подключение: support@wesetup.ru.
```
