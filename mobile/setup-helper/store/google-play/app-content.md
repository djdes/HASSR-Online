# Раздел «Контент приложения» — ответы

Play Console → «Политика» → «Контент приложения». Кроме «Безопасности
данных» (`data-safety.md`) там такие пункты.

## Политика конфиденциальности
`https://wesetup.ru/setup-helper/privacy`

## Доступ к приложению
**Доступ к части функций или ко всем функциям ограничен.**
Инструкция для проверяющих Google (вставить в поле «Инструкции»):

```
Приложение работает только под учётной записью заведения WeSetup.
1. Откройте приложение и введите почту и пароль ниже, нажмите «Войти».
2. На главном экране — подключённое оборудование. Bluetooth-принтер для проверки не нужен:
   «Печать по шаблону» открывает шаблоны и предпросмотр этикетки без принтера.
Почта: <демо-аккаунт>
Пароль: <пароль>
Код из Telegram для этого аккаунта отключён.
```

Демо-аккаунт: отдельная организация «Google Play — проверка» с
руководителем; вход по почте без кода Telegram. Создать перед отправкой на
проверку (см. `README.md`, шаг 4).

## Разрешения, которые требуют объяснения
Google отдельной декларации для наших разрешений не требует, но на вопросы
проверяющих отвечаем так:

| Разрешение | Зачем |
|---|---|
| `BLUETOOTH_SCAN` (с `neverForLocation`), `BLUETOOTH_CONNECT` | найти Bluetooth-принтер этикеток, подключиться и отправить этикетку |
| `BLUETOOTH`, `BLUETOOTH_ADMIN`, `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` (только `maxSdkVersion=30`) | на Android 11 и старше система даёт искать Bluetooth-устройства только с разрешением на геолокацию; координаты не читаются |
| `INTERNET`, `ACCESS_NETWORK_STATE` | вход и отправка отметок, когда появится сеть |

Разрешения на установку пакетов (`REQUEST_INSTALL_PACKAGES`) в версии для
Play нет: обновления приходят только из магазина.
